## v1 Requirements — Final Status

### Campaign Input

| ID | Description | Phase | Status | Outcome |
|----|-------------|-------|--------|---------|
| INPT-01 | User can enter product name, price/offer, and short description | Phase 2 | ✅ Complete | Campaign input form with productName (text, max 60), discountedPrice (BRL mask, required), originalPrice (BRL mask, optional), description (textarea, max 120). |
| INPT-02 | User can upload a product image | Phase 2 | ✅ Complete | CampaignImageUpload with dropzone, format validation (PNG/JPG/WEBP), size check (≤5MB), object URL preview, revoke on change/unmount. |
| INPT-03 | User can provide/store minimal store info (name, segment/subsegment) | Phase 1 | ✅ Complete | StoreIdentityForm with name (2-60 chars) and segment dropdown (10 options). POST/PATCH to `/api/store`. Supabase persistence. |
| INPT-04 | User can set basic visual identity (colors, logo, name style) | Phase 1 | ⚠️ Partial | Brand color picker + hex input works. Name-based fallback via `resolveStoreIdentity`. **Logo upload UI not implemented** — intentionally deferred per Phase 1 spec. |

# Requirements: Vendeo V3

**Defined:** 2026-05-24
**Last updated:** 2026-07-03 (v1.1 close-out)
**Core Value:** Gerar uma campanha profissional de Produto + Oferta que o lojista tenha confiança de publicar e que ajude a vender mais.

## Milestone v1.0 ✅ (shipped 2026-05-25)

### Campaign Input

- [x] **INPT-01**: User can enter product name, price/offer, and short description
- [x] **INPT-02**: User can upload a product image
- [x] **INPT-03**: User can provide/store minimal store info (name, segment/subsegment)
- [x] **INPT-04**: User can set basic visual identity (colors, logo, name style)

### Design Constraints

- [x] **DSGN-01**: No free-form visual editor — adjustments via predefined controls and presets only
- [x] **DSGN-02**: UI/UX Pro Max used for design exploration, not as runtime rendering dependency
- [x] **DSGN-03**: Campaign composition rules derived from Vendeo's own templates and tokens
- [x] **DSGN-04**: V1 scope guardrail — focused solely on Produto + Oferta campaign core; auth, dashboard, plans, analytics, multi-format, and full SaaS structure excluded

## Milestone v1.1 ✅ (shipped 2026-07-03) — Motor de Campanhas

### AI Intelligence

- [x] **AI-01**: AI interprets product/offer/store context and generates structured campaign specification
- [x] **AI-02**: AI generates commercial copy (title, subtitle, CTA) tailored to product and offer
- [x] **AI-03**: AI output includes visual parameters: palette, hierarchy, layout direction, badge style
- [x] **AI-04**: AI provider abstraction layer allows swapping between OpenAI/Anthropic
- [x] **AI-05**: AI output is structured JSON, validated before rendering

### Visual Rendering

- [x] **REND-01**: Programmatic renderer composes final image from structured spec (CSS legacy, IA-generated primary)
- [x] **REND-02**: Template system provides safe, professional layout variations for Produto + Oferta
- [x] **REND-03**: Store identity tokens (name, logo, colors, fonts) applied to campaign
- [x] **REND-04**: Campaign maintains minimum visual quality (hierarchy, readability, contrast, balance)
- [x] **REND-05**: Identity fallback: name-based identity with safe defaults when logo/colors not provided

### Review & Export (re-scoped during close-out)

- [x] **REVW-01**: User can preview generated campaign before export
- [~] **REVW-02**: Guided adjustments (palette, font, layout) → ❌ **Removido** — não é requisito do motor (MC-01)
- [~] **REVW-03**: Regenerate with adjusted parameters → 🔄 **Redefinido** como "novo artefato a partir de briefing revisado" (MC-02)
- [~] **REVW-04**: Campaign exportable as PNG/JPG → ➡️ **Movido** para infraestrutura SaaS (MC-03)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Free-form visual editor | Product must be guided, not a Canva clone |
| Weekly plan / smart calendar | Post-SaaS capability |
| Analytics | Post-SaaS capability |
| Billing / plans | Usage free during validation |
| Reels / video | High complexity, not in core scope |
| Multiple campaign types | Focus on Produto + Oferta validation |
| Multiple stores / team | Enterprise features, future phases |
| AI image generation (DALL-E, etc) | Reduces text control, consistency, and predictability |

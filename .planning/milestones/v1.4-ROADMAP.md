## Milestone Summary

### Key Decisions

- PT-BR como língua padrão da interface (rotas, labels, datas)
- Empty states em vez de redirects para melhor UX de onboarding
- Dashboard adaptativo com 3 estados, reaproveitando F19 onboarding helper
- Busca ILIKE server-side + client-side debounce para performance
- Touch targets ≥44px como padrão de acessibilidade mobile
- focus trap manual (sem lib externa) para drawer mobile

### Issues Resolved

- Rotas PT-BR consistentes em toda a aplicação
- AuthHeader removido, substituído por App Shell
- localStorage("store_id") não usado (herdado de v1.2/v1.3)
- Placeholder do dashboard substituído por conteúdo real
- Redirects para /loja substituídos por empty states contextuais
- Sessão de campanha em sessionStorage removida (consumer P14)

### Technical Debt Incurred

- `Skeleton` component — criado mas nunca importado em produção (dead export)
- `DASHBOARD_PLACEHOLDER` — constante exportada mas nunca consumida
- `getCampaignSuccessRate()` — testada mas dashboard calcula taxa inline
- `countCampaignsFiltered()` — testada mas SSR usa listCampaigns com count query

# 20-01: Métricas e Recentes

Criar o módulo centralizado de métricas de campanha (`src/lib/campaign/metrics.ts`) com `countCampaigns`, `countReadyCampaigns`, `getCampaignSuccessRate`, `getRecentCampaigns` e `RecentCampaignItem`. Reescrever `src/lib/onboarding/count.ts` como reexport para manter compatibilidade com F19.

## Tasks

### 1.1 Criar `src/lib/campaign/metrics.ts`

<read_first>
- openspec/changes/fase-20-dashboard/design.md (D1, D4)
- openspec/changes/fase-20-dashboard/specs/campaign-metrics/spec.md
- src/lib/campaign/types.ts (CampaignStatus type)
- src/lib/supabase/server.ts (createServerClient pattern)
</read_first>

<action>
Create `src/lib/campaign/metrics.ts` with `"server-only"`:

**`countCampaigns(storeId: string): Promise<number>`**
- Uses `createServerClient()` from `@/lib/supabase/server`
- Calls `.from("campaigns").select("*", { count: "exact", head: true }).eq("store_id", storeId).in("status", ["ready", "error"])`
- Returns `count ?? 0`
- Throws `Error` on query failure

**`countReadyCampaigns(storeId: string): Promise<number>`**
- Same pattern as `countCampaigns` but uses `.eq("status", "ready")` instead of `.in()`

**`getCampaignSuccessRate(storeId: string): Promise<number>`**
- Calls `countCampaigns` and `countReadyCampaigns` in parallel with `Promise.all`
- If `total === 0`, returns `0`
- Otherwise returns `Math.round((ready / total) * 100)`

**`getRecentCampaigns(storeId: string, limit = 5): Promise<RecentCampaignItem[]>`**
- Selects `id, product_name, status, created_at` from campaigns
- Filters `.eq("store_id", storeId).in("status", ["ready", "error"])`
- Orders by `created_at` descending, limited by `limit`
- Maps response to `RecentCampaignItem[]` (camelCase fields)

**`RecentCampaignItem` interface**
- `id: string`, `productName: string`, `status: CampaignStatus`, `createdAt: string`
- Export at top level, import `CampaignStatus` from `./types`
</action>

<acceptance_criteria>
- `src/lib/campaign/metrics.ts` exists with `"server-only"` import
- `countCampaigns` counts campaigns with status IN ('ready', 'error')
- `countReadyCampaigns` counts only 'ready' status
- `getCampaignSuccessRate` uses `Promise.all` for parallel queries
- `getCampaignSuccessRate` returns 0 when total is 0
- `getCampaignSuccessRate` returns `Math.round(ready / total * 100)`
- `getRecentCampaigns` returns RecentCampaignItem[] ordered by created_at desc
- `RecentCampaignItem` has id, productName, status, createdAt (no storagePath)
- TypeScript compiles without errors
</acceptance_criteria>

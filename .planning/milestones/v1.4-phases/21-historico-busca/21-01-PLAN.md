### 1.4 Criar `src/lib/campaign/search-params.ts`

<action>
Create `src/lib/campaign/search-params.ts` with:

```typescript
export interface ValidatedSearchParams {
  page: number;
  pageSize: number;       // sempre 10 (fixo)
  q: string | undefined;
  status: Array<"ready" | "error">;
  dateFrom: string | undefined;
  dateTo: string | undefined;
  sortBy: "created_at" | "product_name";
  sortOrder: "asc" | "desc";
}

export function parseCampaignListSearchParams(
  raw: Record<string, string | string[] | undefined>,
): ValidatedSearchParams
```

**Validation rules:**
- `page`: ParseInt ≥ 1; inválido/NaN → 1
- `pageSize`: Sempre 10 (ignorado da URL)
- `q`: `.trim()`, limite 100 chars; vazio → `undefined`
- `status`: Split por `,`, cada valor contra whitelist `["ready","error"]`; fora ignorado; array vazio → `["ready","error"]`
- `date`: Contra whitelist `["7d","30d","90d","year","all"]`; inválido → `"all"`; `"all"` → `dateFrom`/`dateTo` = `undefined`; caso contrário resolve para ISO string:
  - `"7d"`: `dateFrom` = now - 7 days, `dateTo` = now
  - `"30d"`: `dateFrom` = now - 30 days, `dateTo` = now
  - `"90d"`: `dateFrom` = now - 90 days, `dateTo` = now
  - `"year"`: `dateFrom` = Jan 1 current year, `dateTo` = now
- `sort`: Contra whitelist `["created_at","product_name"]`; `"status"` rejeitado; inválido → `"created_at"`
- `order`: Contra whitelist `["asc","desc"]`; inválido → `"desc"`

**IMPORTANTE:** `parseCampaignListSearchParams` resolve date presets para `dateFrom`/`dateTo` ISO strings. O caller (page.tsx) passa `dateFrom`/`dateTo` diretamente para `listCampaigns` — não precisa resolver date preset novamente.
</action>

    **Create `src/lib/formatters.ts`:**
    Export two functions:

    1. `formatCurrencyBRL(valueCents: number): string`
       - Takes raw numeric value in cents (e.g. 4990 for R$ 49,90)
       - Returns "R$ 49,90" format (Brazilian locale: R$ prefix, comma decimal separator, 2 decimal places)
       - Uses `Intl.NumberFormat("pt-BR", { style: "currency", currency: "BRL" })` — do NOT hand-roll formatting
       - Handles 0, negative values, and fractional cents via NumberFormat rounding rules

    2. `parseCurrencyBRL(masked: string): number`
       - Takes a masked string (e.g. "R$ 49,90" or "49,90" or "1.234,56")
       - Strips non-numeric characters except comma and period
       - Handles Brazilian format: period as thousands separator, comma as decimal
       - Returns numeric value in cents (e.g. 4990)
       - Returns 0 for empty/whitespace-only input
       - Returns 0 for NaN after parsing (defensive)

    No `"use client"` directive — these are pure utility functions usable in server components.
  </action>

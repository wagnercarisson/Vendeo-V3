    Create `src/components/flow/use-campaign-form.ts` as a `"use client"` hook.

    **Exported types:**

    1. `CampaignFormFields` — the raw form data interface:
       - `productName: string` — required, max 60 chars, trimmed
       - `description: string` — optional, max 120 chars
       - `originalPriceCents: number` — optional price in cents, 0 = unset
       - `discountedPriceCents: number` — required price in cents, must be > 0
       - `badge: string` — required, must be one of BADGE_OPTIONS
       - `imageFile: File | null` — required file object

    2. `FieldErrors` — `Partial<Record<"productName" | "description" | "originalPriceCents" | "discountedPriceCents" | "badge" | "imageFile", string>>`

    3. `UseCampaignFormReturn` — the hook return type:
       - `fields: CampaignFormFields`
       - `fieldErrors: FieldErrors`
       - `touched: Record<keyof CampaignFormFields, boolean>`
       - `setField(field: keyof CampaignFormFields, value: string | number | File | null): void`
       - `handleBlur(field: keyof CampaignFormFields): void`
       - `displayPriceOriginal: string` — formatted BRL string for display
       - `displayPriceDiscounted: string` — formatted BRL string for display
       - `handlePriceOriginalChange(raw: string): void` — parses mask, updates field
       - `handlePriceDiscountedChange(raw: string): void` — parses mask, updates field
       - `imagePreviewUrl: string | null` — object URL for preview
       - `isSubmitting: boolean`
       - `submitSuccess: boolean`
       - `handleSubmit(): void` — validates all, sets submitSuccess on pass
       - `resetSubmit(): void` — clears submitSuccess for re-editing
       - `isValid: boolean` — derived, true when all required fields have values and no errors

    **Hook implementation:**

    **State initialization:**
    - All fields start empty/false/null
    - touched starts as all false
    - submitting and submitSuccess start false

    **setField logic:**
    - Generic setter accepting field + value
    - For imageFile: also create object URL via URL.createObjectURL if file provided, revoke previous URL
    - For string fields: set directly
    - For numeric fields: coerce via Number(value)

    **Validation functions (pure, file-scoped, do not close over state):**

    1. `validateProductName(value: string): string | null`
       - trimmed required → "Nome do produto é obrigatório"
       - max 60 chars → "Máximo de 60 caracteres"

    2. `validateDiscountedPrice(value: number): string | null`
       - <= 0 → "Preço deve ser maior que zero"

    3. `validateOriginalPrice(value: number, discounted: number): string | null`
       - If value > 0 and value <= discounted → "Preço com desconto deve ser menor que o preço original"
       - (Non-negative: 0 is OK = not provided)

    4. `validateBadge(value: string): string | null`
       - Empty or not in BADGE_OPTIONS → "Selecione um badge promocional"

    5. `validateImage(file: File | null): string | null`
       - Null → "Imagem do produto é obrigatória"
       - Invalid type (not PNG/JPG/WEBP) → "Formato não suportado. Use PNG, JPG ou WEBP"
       - Size > 5MB → "Arquivo muito grande. Máximo 5MB"

    6. `validateField(field: keyof CampaignFormFields, fields: CampaignFormFields): string | null`
       - Dispatcher to above validators

    **handleBlur:**
    - Marks field as touched
    - Runs validateField for that field

    **handlePriceOriginalChange / handlePriceDiscountedChange:**
    - Take raw string from input
    - Parse via parseCurrencyBRL
    - Call setField with numeric value
    - The display values are derived: formatCurrencyBRL(field.valueCents)

    **imagePreviewUrl:**
    - Derived from fields.imageFile via URL.createObjectURL when file changes
    - Store as separate state (not derived on every render to avoid creating new URLs)
    - Revoke previous URL when file changes or component unmounts (useEffect return cleanup)

    **handleSubmit:**
    - Set isSubmitting true
    - Validate all fields
    - If any errors → set fieldErrors, set all touched to true, set isSubmitting false, return
    - If all valid → set submitSuccess true, set isSubmitting false
    - No API call, no localStorage write (per CONTEXT.md submit behavior decision)

    **resetSubmit:**
    - Sets submitSuccess to false, clears errors

    **isValid:**
    - Derived: productName trimmed not empty, discountedPriceCents > 0, badge non-empty and in BADGE_OPTIONS, imageFile non-null

    **Return** all state and handlers.

    Follow the exact export pattern from use-store-form.ts: named export `useCampaignForm`, export the return type and fields type.

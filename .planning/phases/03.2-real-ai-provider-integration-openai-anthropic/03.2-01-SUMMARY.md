## Decisions Made
- **createDefaultProvider() made async** — Dynamic imports for both MockProvider and OpenAIProvider require async. Route was already in an async POST handler, so impact is minimal.
- **Structured Outputs primary, json_object fallback** — `zodResponseFormat` converts CampaignSpecSchema to OpenAI json_schema. Falls back to json_object only for model capability errors (not auth/rate-limit/network).
- **Second-layer Zod validation** — Even with Structured Outputs, CampaignSpecSchema.safeParse runs on every response as defense-in-depth against schema drift or partial output.
- **No static MockProvider import** — Both providers are dynamically imported inside the factory function, keeping module-level imports clean.

## User Setup Required

**External services require manual configuration.** To use the real OpenAI provider:
1. Get an API key from https://platform.openai.com/api-keys
2. Set it in `.env.local`: `OPENAI_API_KEY=sk-...`
3. Optionally set: `OPENAI_MODEL=gpt-4o-mini` (default)

Without these env vars, the app falls back to MockProvider in development and throws a clear configuration error in production.

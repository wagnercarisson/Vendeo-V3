## Files Created

- `prompts/campaign-image-director.md` — Marketing director/art director persona prompt with 22 `{{variable}}` placeholders for campaign data interpolation; creative brief style with brand color palette, pricing display, and composition guidelines; all text in Brazilian Portuguese
- `prompts/campaign-image-reviewer.md` — Quality review prompt with 7 detection categories (wrong_price, wrong_product_name, wrong_store_name, illegible_text, invented_information, deformed_product, weak_visual_quality); strict JSON-only response with `passed` boolean and `issues[]` array
- `prompts/campaign-input-visual-check.md` — Pre-generation conflict detection prompt with 4-classification output (match, auto-fix, conflict, low-confidence); strict JSON-only response with confidence scoring
- `src/lib/image-generation/prompt-loader.ts` — PromptLoader class with constructor (defaults to `<cwd>/prompts`), `load(name, variables?)` method with readFileSync + cache, and `clearCache()` method; default + named exports
- `src/lib/image-generation/schema.ts` — `GenerateImageRequestSchema` (full campaign input with Zod validation), `GenerateImageSuccessResponseSchema`, `GenerateImageNeedsUserActionResponseSchema`, `InputValidationResult` (discriminated union), `ImageReviewResult`/`ReviewIssue` interfaces, `ImageGenerationErrorCode`/`ImageGenerationError` types
- `src/lib/image-generation/config.ts` — `IMAGE_GENERATION_MODEL` (default: gpt-image-2), `VISION_REVIEW_MODEL` (default: gpt-4o), `IMAGE_GENERATION_QUALITY`, `IMAGE_GENERATION_SIZE`, `MAX_PRODUCT_IMAGE_BASE64_SIZE`, `MAX_PRODUCT_IMAGE_FILE_SIZE`

## Decisions Made

- Prompt files stored as plain Markdown without YAML frontmatter or template engine — editable by non-developers, versioned in git, locatable in root `prompts/`
- `PromptLoader` uses synchronous `fs.readFileSync` (server-side only, Next.js App Router) with `Map<string, string>` in-memory cache for the lifetime of the server instance
- All Zod schemas exported with inferred TypeScript types using `z.infer<>` — single source of truth for API contract validation
- Model names and size limits centralized in `config.ts` with environment variable overrides — no hardcoded model strings in service files

    Create `src/lib/brand-assets/text-only-inference-service.ts`:

    Class `BrandTextOnlyInferenceService`:
    - Method `async infer(input: TextOnlyInferenceInput): Promise<TextOnlyInferenceResult>`
    - Uses `PromptLoader` to load `store-brand-inference.md` (same pattern as brand-director.ts)
    - Fills template with store data and optional user colors
    - Calls OpenAI `gpt-4o` with `response_format: { type: 'json_object' }` and `max_tokens: 2000`
    - Validates output: checks hex color format (`/^#[0-9A-Fa-f]{6}$/`), checks required fields exist
    - Returns validated `TextOnlyInferenceResult`
    - Does NOT persist data or update store state (route handles that)

    Error handling:
    - In `production` (NODE_ENV): if OPENAI_API_KEY missing, throw descriptive error
    - In development: if OPENAI_API_KEY missing, create and return a mock TextOnlyInferenceResult with generic/default values and `confidence_score: 0.1`

    Follow the exact same mock pattern and dev/prod detection pattern from `BrandDirectorService`.

  <action>
    Create `src/app/api/store/[id]/brand-profile/infer/route.ts`:

    1. `POST` handler, synchronous
    2. Accept body: `{ textOnlyOrigin: 'explicit' | 'implicit', userChosenColors?: string[], manualColorOverride?: boolean }`
    3. In-memory lock per store_id using `Map<string, boolean>` — if lock exists, return 429 with `{ error: "Inferência já em andamento para esta loja. Aguarde." }`
    4. Timeout of 30 seconds (configurable)
    5. Instantiate `BrandTextOnlyInferenceService`
    6. Call `service.infer(input)` with store data loaded from GET /api/store/[id]
    7. **On success:**
       - Insert into `store_brand_profiles`: source='text_only', status='synced', all result fields (safe_color_tokens, visual_style, etc.), brand_colors_chosen from user input, manual_color_override.enabled based on user color choice
       - PATCH `stores`: identity_state='text_only', text_only_origin from body, logo_status='explicit_none', manual_color_override based on user choice, brand_color = safe_color_tokens.primary
       - Return profile data with 200
    8. **On failure (service throws):**
       - Insert into `store_brand_profiles`: source='text_only', status='failed', with metadata about the error
       - Still PATCH `stores`: identity_state='text_only', text_only_origin from body, logo_status='explicit_none'
       - Return non-blocking 200 with `{ success: false, message: "..." }`
    9. Finally block: release the in-memory lock

    Use Supabase server client (`createServerClient`) same as existing routes.
  </action>

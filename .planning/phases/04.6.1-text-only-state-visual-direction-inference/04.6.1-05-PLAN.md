      1. Save colors via saveBrandColors() if chosen
      2. Set identityState = 'text_only', textOnlyOrigin = 'implicit'
      3. POST to `/api/store/${storeId}/brand-profile/infer` with `{ textOnlyOrigin: 'implicit', userChosenColors: [...] if any, manualColorOverride: true/false }`
      4. Same success/failure handling as above

    **Loading state rendering:**

    - Disable buttons during inference

    - When identityState = 'text_only' AND synced profile exists:
      - Drop zone present, "Enviar logotipo" button present, "Não tenho logo" button present
      - "Continuar sem logo" link REMOVED

      - Color pickers pre-filled with brand_colors_chosen if non-empty, else safe_color_tokens.primary/inferred_accent_color
      - Color chips from safe_color_tokens displayed below pickers
    - When identityState = 'text_only' AND profile failed:
      - Drop zone present, both buttons present
      - "Continuar sem logo" link REMOVED
      - Warning message + "Gerar direção visual agora" button (re-triggers inference)
    - When identityState = null (initial state):
      - Existing behavior: all buttons and "Continuar sem logo" link present

    **Color change handler:**
    - When user changes colors after inference: PATCH /api/store/[id]/brand-profile with `{ colors: [...] }`

    ```typescript
    }
    ```

    - `logos: LogoHistoryItem[]` — loaded from API
    - `loading: boolean` — initial load
    - `error: string | null` — fetch/restore error
    - `restoringId: string | null` — currently restoring asset_id (for button loading state)

    - Fetch `GET /api/store/${storeId}/logo/history`
    - Set logos from response
    - Handle loading, empty (no archived logos), and error states

    - Modal overlay (semi-transparent backdrop)
    - Modal container with title "Logotipos anteriores" and close [X] button
    - Scrollable version list, each card shows:
      - Logo thumbnail (from asset.url or asset.storage_path)
      - Date formatted (dd mmm aaaa) and version label (v1, v2, etc.)
      - Visual style text
      - Palette (safe_color_tokens colors as small swatches)
      - Drift badge:
        - `'none'` → "✓ Dados inalterados" (green)
        - `'drift'` → "⚠ Requer realinhamento" (amber)
        - `null` → "— Sem direção associada" (gray, asset órfão sem profile)
      - Action button:
        - If drift 'none': "Restaurar" (calls restore with no realignment)
        - If drift 'drift': "Restaurar c/ realinh" (calls restore, will realign)
        - If null: "Restaurar logo (sem direção)" (restaura apenas o asset, sem direção vinculada — POST /logo/restore tratará como sem profile associado)
      - Disabled state: button shows spinner while restoring
    - Bottom: "Cancelar" button

    **On restore (handleRestore function):**
    1. Set `restoringId = assetId`
    2. Fetch `POST /api/store/${storeId}/logo/restore` with `{ asset_id: assetId }`
    3. On success:
       - Call `onRestored()` callback
       - Call `onClose()` to dismiss modal
    4. On failure: set error state

    **Edge cases:**
    - Loading state: spinner or skeleton
    - Empty state: "Nenhum logotipo anterior encontrado"
    - Error state: error message with retry option
    - API failure on restore: error toast/message within modal

### 5. Restore com drift — realinhamento + cores corretas
expected: Escolher versão com badge "⚠ Desatualizado" → clicar "Restaurar" → modal fecha → sistema realinha → card do logo aparece. Color picker e preview mostram a mesma cor (a escolhida pelo realinhamento, não a anterior).
result: pass — realinhamento e cores corretas confirmados. Observação: badge "Desatualizado" não apareceu no history para store com campos alterados, mas o restore detectou drift corretamente. Causa raiz: após restore com drift, múltiplos profiles passam a ter o mesmo `active_logo_asset_id`, e o `.maybeSingle()` no history sem `.order()` pode retornar o profile mais novo (snapshot igual aos dados atuais), mascarando o drift. Fix: adicionado `.order('created_at', { ascending: true })` na query do history (route.ts:64).

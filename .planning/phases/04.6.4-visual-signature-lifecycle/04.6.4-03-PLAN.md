<action>
Create `src/app/api/store/[id]/visual-signature/restore/route.ts`:

1. Accept `{ signature_id: string }` in body
2. Validate signature belongs to requesting store (can be `archived` or `active`)
3. If already `active`: return `{ success: true }` (no-op)
4. Validate `identity_state`:
   - `'text_only'` or `'visual_signature'` → permitted
   - `'logo'` → return 409 `{ error: 'Remova o logotipo ativo antes de restaurar uma assinatura visual.', requires_logo_removal: true, current_identity_state: 'logo' }`
 5. Validate drift using shared `validateDrift()` from Plan 01's drift-validator.ts:
   - Load `input_snapshot` from `signature.metadata.input_snapshot`
   - Load `content_used` from `signature.metadata.artDirectorOutput.content_used`
   - Call `validateDrift({ input_snapshot, content_used, currentStoreData })`
   - Use the returned `DriftValidationResult` for the response
 6. If drift detected: return `{ success: false, drift: { critical: true, fields: result.fields, requires_regeneration: true, reason: result.reason } }`
7. If no drift:
   a. Archive currently active signature (if any)
   b. Set chosen signature as `active`
   c. Update stores: `identity_state = 'visual_signature'`, `logo_status = 'generated'`
   d. Search for brand profile linked to signature (`visual_signature_id`, `source = 'without_logo'`)
   e. If profile exists: call `reconcileProfiles()` with `markIncompatibleAsOutdated=true, activateProfileIds=[profileId]`
   f. If no profile (draft never approved): execute `BrandProfilerWithoutLogoService.generate()`, then reconcile
   g. Return `{ success: true, signature: { id, assetUrl } }`
</action>
<acceptance_criteria>
- Restore validates signature belongs to store
- Restore is no-op if signature already active
- Restore rejected with 409 if identity_state='logo'
- Drift on name blocks restore with `fields: ['name']`
- Drift on city blocks restore only if content_used.city=true
- Missing metadata blocks restore with `reason: 'missing_metadata'`
- Successful restore archives previous active, activates chosen, syncs identity_state
- Profile reconciliation marks incompatible profiles as outdated
- Draft without profile triggers BrandProfilerWithoutLogoService
- Restore does NOT increment visual_signature_attempts
- `npm run typecheck` passes with no errors
</acceptance_criteria>
</task>

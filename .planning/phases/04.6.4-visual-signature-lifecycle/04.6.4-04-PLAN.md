Create `src/components/flow/visual-signature-history-modal.tsx` (separate from `logo-restore-modal.tsx`):

1. Title: "Assinaturas anteriores", close button (X) top right
2. On mount: fetch `GET /api/store/[id]/visual-signature` (filter archived/active)
3. Render each signature as a card with:
   - Thumbnail from `asset_url`
   - Date: formatted `created_at`
   - Visual direction from `art_direction.visual_direction`
   - Color palette summary
   - Status label
   - "Restaurar" button for archived signatures
4. Restore button state based on `restore_eligibility.reason`:
   - `'ok'` → enabled
   - `'critical_drift'` → disabled with tooltip "Os dados da loja mudaram desde esta assinatura. Gere uma nova versão."
   - `'missing_metadata'` → disabled with tooltip "Assinatura antiga não pode ser restaurada. Gere uma nova versão."
5. On "Restaurar" click: call `POST /api/store/[id]/visual-signature/restore` with `{ signature_id }`
6. Loading state: spinner while fetching
7. Empty state: "Nenhuma assinatura anterior encontrada"
8. Error state: dismissible error banner
9. "Cancelar" button at bottom
</action>

- Successful restore updates parent state (identity_state becomes visual_signature)
- Loading, empty, and error states handled

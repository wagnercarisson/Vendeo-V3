<action>
Create `src/lib/identity-transitions.ts` with:

1. **TransitionResult type** — `{ success: true } | { success: false; error: string; partialState?: Record<string, unknown> }`

2. **`TransitionAlreadyInProgressError`** — custom error class for concurrent transition detection

3. **In-memory lock per store_id** — prevent concurrent transitions using a `Map<string, Promise<boolean>>`

4. **`transition(storeId: string, type: IdentityTransition, options?: { assetId?: string }): Promise<TransitionResult>`** implementing the lifecycle:

   **Validation phase:**
   ```typescript
   function validateTransition(currentState: IdentityState, target: IdentityTransition): { valid: boolean; error?: string }
   ```
   | Current State | Transition | Valid |
   |---|---|---|
   | `text_only` | `text_only_to_logo` | ✅ |
   | `text_only` | `text_only_to_visual_signature` | ✅ |
   | `logo` | `logo_to_text_only` | ✅ |
   | `visual_signature` | `visual_signature_to_text_only` | ✅ |
   | Any other combination | Any | ❌ (blocked) |

   **Persistence phase:** Accept callbacks for the route-specific persistence:
   ```typescript
   async function transition(storeId, type, { onActivate, onArchive }) {
     // 1. Validate current identity_state
     // 2. Call onArchive() if removal transition (route archives the asset)
     // 3. Call onActivate() if activation transition (route activates the asset)
     // 4. If either fails: return error, state unchanged
     // 5. Update stores.identity_state + logo_status (dual-population)
     // 6. If DB update fails: attempt compensation (reverse archive/activation)
   }
   ```

5. **Dual-population in DB update**: Single UPDATE statement setting both `identity_state` and `logo_status` from the `IDENTITY_TO_LOGO_STATUS` mapping.

6. **Compensation**: If the DB update fails after persistence, call compensation callbacks. Log partial state if compensation also fails. Always return error (never success).

**Orchestrator scope limitation:** The orchestrator does NOT call BrandDirector, generate VS, analyze logos, manage colors, or execute advanced lifecycle. It only validates transitions and coordinates minimum state/asset persistence.
</action>

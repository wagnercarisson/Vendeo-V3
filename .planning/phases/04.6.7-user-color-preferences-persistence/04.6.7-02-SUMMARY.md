## Changes Made

- **PATCH handler**: Accepts `Array<string | null>`, rejects single-element arrays (400), removes `manual_color_override` writes, handles `#RRGGBB` placeholder as null, requires synced profile (404)
- **Infer route**: Accepts `userChosenColors: Array<string | null>`, preserves existing `brand_colors_chosen` from previous profile, ignores `manualColorOverride`, removes `manual_color_override` from store update
- **Realign route**: Preserves `brand_colors_chosen` from previous profile in text-only path (was hardcoded to `[]`)
- **Logo upload route**: Preserves `brand_colors_chosen` from previous synced profile instead of setting `[]` unconditionally
- **Logo restore route**: Preserves `brand_colors_chosen` from current profile
- **VS approval route**: Reads `previousBrandColors` from `brand_colors_chosen` directly instead of gating on `manual_color_override.enabled`

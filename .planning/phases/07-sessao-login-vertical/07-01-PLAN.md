# Plan 07-01: Supabase SSR Foundation

Wave 1 — Foundation (no dependencies)

## Objective

Instalar `@supabase/ssr`, refatorar os 3 módulos de cliente Supabase (browser, server, middleware), remover o barrel file e validar ambiente.

---

## Must Haves

- `@supabase/ssr` instalado com versão fixa
- `src/lib/supabase/client.ts` exporta `createBrowserClient()` como factory usando `@supabase/ssr`
- `src/lib/supabase/server.ts` exporta `createServerClient()` como factory + mantém `supabaseAdmin` nomeado
- `src/lib/supabase/middleware.ts` exporta `updateSession(request)` retornando `{ response, claims }`
- `src/lib/supabase.ts` (barrel) removido e nenhum import residual para `@/lib/supabase`
- 3 ENV vars validadas nos módulos respectivos

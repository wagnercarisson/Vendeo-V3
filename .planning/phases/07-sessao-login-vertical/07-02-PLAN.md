### Task 01: Create `src/lib/auth/require-user.ts`

<action>
Criar módulo com:
- `class UnauthorizedError extends Error` — exportada, catchable, com mensagem descritiva padrão
- `async function requireUser(): Promise<AuthenticatedUser>` — cria server client via `createServerClient()`, chama `supabase.auth.getClaims()`, valida `claims.sub` presente e não vazio, retorna `{ userId: claims.sub, claims }` ou throw `UnauthorizedError`
- `async function requirePageUser(): Promise<AuthenticatedUser>` — wrapper que catch `UnauthorizedError` e chama `redirect("/login")` do Next.js
- `requireApiUser()` — wrapper que throw `UnauthorizedError` (handler captura → 401 JSON)
</action>

### Task 02: Create `src/lib/auth/redirect.ts` with `sanitizeRedirectPath`

<action>
Criar módulo com função `sanitizeRedirectPath(path: string): string`:
1. Parse com URL constructor (base relativa → "/")
2. Valida pathname contra allowlist: `=== "/"`, `=== "/store"`, `.startsWith("/campaign/")`
3. Rejeita: URLs absolutas (`http://`, `https://`), protocol-relative (`//`), backslashes, caminhos de auth (`/login`, `/signup`, `/auth/*`)
4. Preserva query string como dados opacos (parsing seguro com URL)
5. Descarta fragmentos (`#`)
6. Fallback: `"/"`
</action>

<read_first>
- openspec/changes/fase-7-sessao-login-vertical/specs/auth-redirect/spec.md
- openspec/changes/fase-7-sessao-login-vertical/design.md (D5)
</read_first>

<acceptance_criteria>
- `sanitizeRedirectPath("/campaign/preview")` → `"/campaign/preview"`
- `sanitizeRedirectPath("/campaign/preview?foo=bar")` → `"/campaign/preview?foo=bar"`
- `sanitizeRedirectPath("https://evil.com")` → `"/"`
- `sanitizeRedirectPath("//evil.com")` → `"/"`
- `sanitizeRedirectPath("/login")` → `"/"`
- `sanitizeRedirectPath("/campaign/preview#section")` → `"/campaign/preview"`
- `sanitizeRedirectPath("")` → `"/"`
- `npx tsc --noEmit` passa
</acceptance_criteria>

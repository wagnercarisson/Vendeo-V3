# Plan 07-03: Auth Middleware

Wave 2 — depends on Wave 1 (middleware.ts helper available)

## Objective

Criar `src/middleware.ts` com matcher positivo que protege páginas e rotas de API, usando `updateSession()` para renovação de sessão e decisão de rota.

---

## Must Haves

- `src/middleware.ts` com matcher positivo: `"/"`, `"/login"`, `"/store/:path*"`, `"/campaign/:path*"`, `"/api/:path*"`
- Páginas protegidas sem sessão → redirect `/login?redirect=<path>`
- `/api/*` sem sessão → `401 { error: "Unauthorized" }`
- `/login` com sessão → redirect `/`
- Toda resposta preserva cookies de `updateSession()`
- Middleware não consulta banco de dados

---

## Tasks

### Task 01: Create `src/middleware.ts`

<action>
Criar `src/middleware.ts` no diretório raiz do Next.js com:
1. Matcher exportado positivo: `["/", "/login", "/store/:path*", "/campaign/:path*", "/api/:path*"]`
2. `export async function middleware(request: NextRequest)` que:
   - Chama `updateSession(request)` de `@/lib/supabase/middleware`
   - Extrai `claims` do resultado
   - Se `!claims?.sub`: páginas protegidas (não `/login`, não `/api/*`) → redirect `/login?redirect=<pathname>`, `/api/*` → return `Response.json({ error: "Unauthorized" }, { status: 401 })`, `/login` → `return response`
   - Se `claims.sub`: `/login` → redirect `/`, demais → `return response`
   - Toda resposta (redirect, 401, next) usa `response` de `updateSession()` como base para preservar cookies
3. `export const config = { matcher: [...] }`
</action>

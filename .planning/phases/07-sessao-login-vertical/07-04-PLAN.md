# Plan 07-04: Login Page & Logout

Wave 3 — depends on Waves 1+2 (SSR clients, helpers, middleware available)

## Objective

Criar a página de login com formulário email+senha dentro de route group `(auth)` e o fluxo de logout com limpeza de storage.

---

## Must Haves

- Route group `(auth)` com layout isolado (sem navegação principal)
- Página `/login` com formulário email+senha, loading state, erro genérico
- Logout via `POST /auth/signout` com limpeza de storage e redirect
- Botão "Sair" no header da aplicação
- Integração de `sanitizeRedirectPath()` no login para redirect pós-login

### Task 02: Test `sanitizeRedirectPath()`

<action>
Criar testes para `sanitizeRedirectPath()`:
1. `sanitizeRedirectPath("/campaign/preview")` → `"/campaign/preview"`
2. `sanitizeRedirectPath("/campaign/preview?foo=bar")` → `"/campaign/preview?foo=bar"`
3. `sanitizeRedirectPath("https://evil.com")` → `"/"`
4. `sanitizeRedirectPath("//evil.com")` → `"/"`
5. `sanitizeRedirectPath("\\evil")` → `"/"` (backslash)
6. `sanitizeRedirectPath("/campaign-evil")` → `"/"` (não é startsWith("/campaign/"), é prefixo)
7. `sanitizeRedirectPath("/login")` → `"/"`
8. `sanitizeRedirectPath("/campaign/preview#section")` → `"/campaign/preview"`
9. `sanitizeRedirectPath("")` → `"/"`
</action>

### Task 03: Test middleware

<action>
Criar testes simulando `Request` objects para o middleware:
1. Request para `/` sem sessão → redirect `/login?redirect=/`
2. Request para `/campaign/preview` sem sessão → redirect `/login?redirect=/campaign/preview`
3. Request para `/campaign/preview?foo=bar` sem sessão → redirect `/login?redirect=%2Fcampaign%2Fpreview%3Ffoo%3Dbar`
4. Request para `/api/store` sem sessão → 401 JSON
5. Request para `/login` sem sessão → pass-through (200, NextResponse.next)
6. Request para `/login` com sessão → redirect `/`
7. Request para `/` com sessão → pass-through (NextResponse.next)
8. Redirect e 401 preservam cookies e headers da resposta de `updateSession()` (verificar set-cookie, cache-control, expires, pragma)
</action>

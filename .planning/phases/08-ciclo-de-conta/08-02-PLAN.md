# Plan 08-02: Pages & Route Handler

Wave 2 — Core pages (depends on Wave 1 middleware expansion)

## Objective

Criar todas as novas páginas do ciclo de conta e modificar o formulário de login existente para incluir links de navegação. Inclui signup, check-email, auth/confirm handler, forgot-password e update-password.

---

## Must Haves

- Formulário de login exibe link "Criar conta" → `/signup` e "Esqueci minha senha" → `/forgot-password`
- `/signup` renderiza formulário com email + senha + confirmar, valida client-side, sempre redirect `/check-email?type=signup`
- `/check-email` renderiza copy contextual por `?type=signup|recovery`, sem revelar email
- `GET /auth/confirm` processa `token_hash` + `type` via `verifyOtp()`, valida `next` contra allowlist
- `/forgot-password` renderiza formulário de email, sempre redirect `/check-email?type=recovery`
- `/update-password` renderiza formulário de nova senha, `updateUser({ password })`, redirect `/`
- `NEXT_PUBLIC_SITE_URL` validada em módulo compartilhado (build/load time)

### Task 04: Criar route handler /auth/confirm

<action>
Criar `src/app/auth/confirm/route.ts` — GET handler (fora do route group `(auth)`, sem HTML):

```typescript
import { createServerClient } from "@/lib/supabase/server";
import { NextRequest, NextResponse } from "next/server";

const VALID_NEXT = ["/", "/update-password"] as const;

export async function GET(request: NextRequest) {
  const { searchParams } = request.nextUrl;
  const tokenHash = searchParams.get("token_hash");
  const type = searchParams.get("type");
  const rawNext = searchParams.get("next") || "/";
  const safeNext = VALID_NEXT.includes(rawNext as typeof VALID_NEXT[number])
    ? rawNext
    : "/";

  if (!tokenHash || !type) {
    return NextResponse.redirect(new URL("/login?error=confirmation_failed", request.url));
  }

  const supabase = await createServerClient();
  const { error } = await supabase.auth.verifyOtp({ type: type as any, token_hash });

  if (error) {
    const errorParam = type === "recovery" ? "recovery_failed" : "confirmation_failed";
    return NextResponse.redirect(new URL(`/login?error=${errorParam}`, request.url));
  }

  const redirectTo = type === "recovery" ? safeNext : "/";
  return NextResponse.redirect(new URL(redirectTo, request.url));
}
```

Usar `verifyOtp()` com `token_hash` — **não** `exchangeCodeForSession()`.
</action>

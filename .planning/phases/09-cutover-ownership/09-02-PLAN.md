# Plan 09-02: API Routes — Ownership

Wave 1 — API ownership (depends on 09-01 auth helpers)

## Objective

Aplicar ownership nas 4 rotas CRUD de store: POST com `claims.sub`, GET /api/store (atalho), GET/PATCH /:id com `requireOwnership()`.

---

## Must Haves

- `POST /api/store` com `requireUser()` + `claims.sub` — 201 ou 409 (UNIQUE)
- `GET /api/store` (atalho) — `requireApiUser()` + `getCurrentStore()` + `buildStoreResponse()`
- `GET /api/store/:id` — `requireUser()` + `requireOwnership()` + `buildStoreResponse()`
- `PATCH /api/store/:id` — `requireUser()` + `requireOwnership()`
- Contrato de erro D10: UnauthorizedError → 401 JSON, StoreNotFoundError → 404 JSON

### Task 02: Adicionar GET /api/store (atalho semântico) — D6

<action>
Adicionar handler `GET` em `src/app/api/store/route.ts`:

1. Exportar `GET` function no mesmo arquivo (Next.js suporta múltiplos exports por arquivo de rota)
2. Chamar `requireApiUser()` — captura UnauthorizedError e retorna 401 JSON
3. Chamar `const store = await getCurrentStore(user.userId)` — userId do requireApiUser
4. Se store for null: `NextResponse.json({ error: "Store not found" }, { status: 404 })`
5. Se store encontrada: `const enriched = await buildStoreResponse(store)` e retornar 200

```typescript
export async function GET(request: NextRequest) {
  try {
    const user = await requireApiUser();
    const store = await getCurrentStore(user.userId);
    if (!store) {
      return NextResponse.json({ error: "Store not found" }, { status: 404 });
    }
    const data = await buildStoreResponse(store);
    return NextResponse.json(data);
  } catch (error) {
    if (error instanceof UnauthorizedError) {
      return NextResponse.json({ error: "Unauthorized" }, { status: 401 });
    }
    throw error; // 500
  }
}
```
</action>

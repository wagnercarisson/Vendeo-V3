# Plan 09-03: Server Components & Client Refactoring

Wave 2 — Pages and refactoring (depends on 09-01 helpers)

## Objective

Transformar 3 páginas em server components com `requirePageUser()` + `getCurrentStore()`, refatorar client components progressivamente para receber store via props, remover `localStorage("store_id")` de todos os componentes.

---

## Must Haves

- `/store` é server component: requirePageUser + getCurrentStore → render StorePageClient
- `/` é server component: requirePageUser + getCurrentStore → se null redirect /store, render CampaignPageClient
- `/campaign/preview` é server wrapper: requirePageUser + getCurrentStore → se null redirect /store, render CampaignPreviewClient
- `store-page-client.tsx` recebe initialStore prop, remove localStorage
- `campaign-page-client.tsx` recebe store prop, remove localStorage e loading states
- `use-store-form.ts` recebe initialStore param, remove localStorage
- `logout-button.tsx` remove `localStorage.removeItem("store_id")`
- Zero referências a `localStorage` em `src/components/flow/` e `src/components/auth/`

---

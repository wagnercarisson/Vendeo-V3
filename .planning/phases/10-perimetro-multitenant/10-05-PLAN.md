# Plan 10-05: Matriz de Testes Parametrizados

Wave 3 — Matriz parametrica base + CSRF (depends on 10-01, 10-02, 10-03, 10-04)

## Objective

Implementar matriz de testes parametrizados: base (~24 endpoints x 4 cenarios), current-store, POST /api/store, e CSRF (mutacoes x 3 cenarios).

---

## Must Haves

- Matriz base storeId-scoped: ~20 endpoints x 4 cenarios (401, 404 alien, 404 inexistente, 200)
- Matriz base current-store: POST /api/campaign/generate x 4 cenarios
- Matriz base POST /api/store: x 5 cenarios (403 CSRF, 401, 409 duplicata, 200, user_id ignorado)
- Matriz CSRF: todas as mutacoes POST/PATCH/DELETE x 3 cenarios (cross-origin com sessao 403, cross-origin sem sessao 403, mesma origem sem sessao 401)
- Precedencia CSRF: cross-origin sem sessao retorna 403 (nao 401)
- Store alheia e inexistente retornam 404, nunca 403 (invariante #4)
- `npx vitest run` — todos verdes

---

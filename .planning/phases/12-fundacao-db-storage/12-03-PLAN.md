Create `scripts/verify-phase12.sql` with 9 blocks `DO $$`:

Block 1: Tabela `public.campaigns` existe
- Query `SELECT to_regclass('public.campaigns')`
- RAISE EXCEPTION 'FAIL: campaigns table does not exist' if null
- RAISE NOTICE 'PASS: ...' if exists

Block 2: RLS ativa em `public.campaigns`
- Query `SELECT relrowsecurity FROM pg_class WHERE oid = 'public.campaigns'::regclass`
- RAISE EXCEPTION 'FAIL: RLS not enabled' if false
- RAISE NOTICE 'PASS: ...' if true

Block 3: CHECK constraint `chk_campaigns_error_message` existe
- Query `SELECT 1 FROM pg_constraint WHERE conname = 'chk_campaigns_error_message' AND conrelid = 'public.campaigns'::regclass`
- RAISE EXCEPTION 'FAIL: chk_campaigns_error_message not found' if not found
- RAISE NOTICE 'PASS: ...' if found

Block 4: Trigger `trg_campaigns_updated_at` existe
- Query `SELECT 1 FROM pg_trigger WHERE tgname = 'trg_campaigns_updated_at' AND tgrelid = 'public.campaigns'::regclass`
- RAISE EXCEPTION 'FAIL: trg_campaigns_updated_at not found' if not found
- RAISE NOTICE 'PASS: ...' if found

Block 5: Bucket `campaign-images` existe e é privado
- Query `SELECT id, public FROM storage.buckets WHERE id = 'campaign-images'`
- RAISE EXCEPTION 'FAIL: bucket not found' if not found
- RAISE EXCEPTION 'FAIL: bucket is public' if public = true
- RAISE NOTICE 'PASS: ...' if private

Block 6: Policy `owner_select_campaign_images` existe
- Query `SELECT 1 FROM pg_policies WHERE policyname = 'owner_select_campaign_images' AND tablename = 'objects' AND schemaname = 'storage'`
- RAISE EXCEPTION 'FAIL: policy owner_select_campaign_images not found' if not found
- RAISE NOTICE 'PASS: ...' if found

Block 7: Policy `service_insert_campaign_images` existe
- Query `SELECT 1 FROM pg_policies WHERE policyname = 'service_insert_campaign_images' AND tablename = 'objects' AND schemaname = 'storage'`
- RAISE EXCEPTION 'FAIL: policy service_insert_campaign_images not found' if not found
- RAISE NOTICE 'PASS: ...' if found

Block 8: Policy `service_delete_campaign_images` existe
- Query `SELECT 1 FROM pg_policies WHERE policyname = 'service_delete_campaign_images' AND tablename = 'objects' AND schemaname = 'storage'`
- RAISE EXCEPTION 'FAIL: policy service_delete_campaign_images not found' if not found
- RAISE NOTICE 'PASS: ...' if found

Block 9: NENHUMA policy `service_update_campaign_*` existe
- Query `SELECT count(*) FROM pg_policies WHERE policyname LIKE 'service_update_campaign%' AND tablename = 'objects' AND schemaname = 'storage'`
- RAISE EXCEPTION 'FAIL: UPDATE policy found (violates imutability)' if count > 0
- RAISE NOTICE 'PASS: ...' if count = 0

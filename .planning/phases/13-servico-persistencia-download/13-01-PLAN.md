<action>
In `src/lib/campaign/persistence.ts`, implement `dataUrlToCampaignImage(dataUrl: string): { buffer: Buffer; mimeType: string }`:

- Validate data URL format: must match `data:image/(png|jpeg|webp);base64,` prefix
- Extract MIME type from the data URL prefix
- Extract base64 payload after the comma
- Reject empty payload (after decoding)
- Accepted MIME types: `image/png`, `image/jpeg`, `image/webp`
- Return `{ buffer: Buffer.from(base64Payload, 'base64'), mimeType }`
- Throw descriptive Error for: unsupported MIME, malformed data URL, empty payload
- No transcodificação — esta é uma função de parser puro
</action>

<acceptance_criteria>
- Accepts `image/png` data URL → returns `{ buffer, mimeType: "image/png" }`
- Accepts `image/jpeg` data URL → returns `{ buffer, mimeType: "image/jpeg" }`
- Accepts `image/webp` data URL → returns `{ buffer, mimeType: "image/webp" }`
- Rejects MIME not in `image/png|jpeg|webp` with error
- Rejects empty string with error
- Rejects malformed data URL (no comma, no prefix) with error
- Buffer is a valid Buffer instance
</acceptance_criteria>

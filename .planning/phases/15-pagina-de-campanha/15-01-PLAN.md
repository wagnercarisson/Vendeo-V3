  <action>
  Create `src/lib/campaign/display.ts` with `import "server-only"` and three exported functions:

  **A. `getCampaignForDisplay(id: string): Promise<CampaignRecord | null>`**
  - Validar que `id` é UUID v4 usando regex `/^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i` — retornar `null` se não for UUID válido (sem consultar o banco)
  - Chamar `createServerClient()` de `@/lib/supabase/server`
  - Consultar `supabase.from("campaigns").select("*").eq("id", id).maybeSingle()`
  - Retornar `data as CampaignRecord | null` (null se não existir ou RLS filtrar)
  - Se houver erro, lançar `new Error(error.message)`

  **B. `generateSignedPreviewUrl(storagePath: string): Promise<string | null>`**
  - Se `storagePath` for vazio (`!storagePath`), retornar `null`
  - Importar `supabaseAdmin` de `@/lib/supabase/server`
  - Chamar `supabaseAdmin.storage.from("campaign-images").createSignedUrl(storagePath, 3600)`
  - Se houver erro, lançar `new Error(error.message)`
  - Retornar `data.signedUrl` como string
  - NÃO validar status da campanha — responsabilidade do caller (`page.tsx`)

  **C. `computeDisplayStatus(campaign: { status: CampaignStatus; updated_at: string }): "ready" | "generating" | "stale" | "error"`**
  - Importar `IMAGE_GENERATION_GLOBAL_TIMEOUT_MS` de `@/lib/image-generation/config`
  - Se `campaign.status === "ready"` → retornar `"ready"`
  - Se `campaign.status === "error"` → retornar `"error"`
  - Se `campaign.status === "generating"`:
    - Calcular `staleThreshold = IMAGE_GENERATION_GLOBAL_TIMEOUT_MS + 30_000`
    - Calcular `elapsed = Date.now() - new Date(campaign.updated_at).getTime()`
    - Se `elapsed > staleThreshold` → retornar `"stale"`
    - Senão → retornar `"generating"`
  - Se nenhum dos acima → retornar `"error"` (fallback)

  **D. Mapeamento com fallback (helper function para page.tsx usar):**
  Criar uma função `mapCampaignToProps(campaign: CampaignRecord, id: string)` que retorna um objeto serializável com:

  ```typescript
  {
    imageUrl: /* signed URL ou null */,
    caption: campaign.publication_copy_snapshot?.caption ?? "",
    hashtags: campaign.publication_copy_snapshot?.hashtags ?? [],
    ctaPost: campaign.publication_copy_snapshot?.cta_post ?? "",
    displayStatus: computeDisplayStatus(campaign),
    productName: campaign.product_name ?? "",
    createdAt: campaign.created_at ?? new Date().toISOString(),
    updatedAt: campaign.updated_at ?? new Date().toISOString(),
    downloadUrl: `/api/campaign/${id}/download`,
  }
  ```

  Note: `imageUrl` é `null` por padrão — o caller (`page.tsx`) preenche `generateSignedPreviewUrl` separadamente quando `status === "ready"`.

- src/lib/auth/store-ownership.ts
</read_first>

<action>
Create `src/lib/onboarding/state.ts` with `"server-only"`:
- `export async function getUserOnboardingState(userId: string): Promise<OnboardingState>`
- Calls `getCurrentStore(userId)` from `@/lib/auth/store-ownership`
- If store is null, returns `"no_store"` (MUST NOT call `countCampaigns`)
- Calls `countCampaigns(store.id)`

- Import `OnboardingState` from `./types`
</action>

- Returns `"no_store"` when no store (without calling countCampaigns)
- Returns `"has_store_no_campaigns"` when store exists but count is 0
- Returns `"has_store_with_campaigns"` when store exists and count > 0
- TypeScript compiles without errors
</acceptance_criteria>

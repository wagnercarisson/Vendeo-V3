<action>
Create `src/components/ui/pagination.tsx`:

```typescript
import { Button } from "./button";
```

**Props:**
```typescript
interface PaginationProps {
  currentPage: number;
  totalPages: number;
  onPageChange: (page: number) => void;
}
```

**Layout algorithm:**

- "Anterior" button → `onPageChange(currentPage - 1)` — disabled when `currentPage === 1`. Use `variant="secondary"`.
- "Próximo" button → `onPageChange(currentPage + 1)` — disabled when `currentPage === totalPages`. Use `variant="secondary"`.
- Page number buttons between:
  - Show first page always
  - Show last page always
  - Show current page and ±1 adjacent
  - Show ellipsis (`...` as text, not a button) for gaps > 1
  - When `totalPages <= 5`, show all pages without ellipsis
  - Current page highlighted (use `variant="secondary"` or differentiate from `variant="ghost"`)
- `onPageChange(N)` called when clicking any page number or nav button
- No `onPageChange` call when clicking a disabled button

**Visual structure (flex row, centered):**
```
<div className="flex items-center justify-center gap-1">
  <Button variant="secondary" disabled={currentPage === 1} onClick={...}>
    << Anterior
  </Button>
  {/* page 1 */}
  <Button variant={currentPage === 1 ? "secondary" : "ghost"} onClick={...}>
    1
  </Button>
  {/* ellipsis if needed */}
  {/* pages around current */}
  {/* ellipsis if needed */}
  {/* last page */}
  <Button variant={currentPage === totalPages ? "secondary" : "ghost"} onClick={...}>
    {totalPages}
  </Button>
  <Button variant="secondary" disabled={currentPage === totalPages} onClick={...}>
    Próximo >>
  </Button>
</div>
```

Componente puro — sem `useState`. Totalmente controlado pelo pai.
</action>

<acceptance_criteria>

- "Anterior" disabled when `currentPage === 1`
- "Próximo" disabled when `currentPage === totalPages`
- Page number buttons with `variant="ghost"` (current page uses distinguished variant)
- Shows first page, last page, current page ±1, with ellipses for gaps
- When `totalPages <= 5`, shows all pages without ellipsis
- `onPageChange(N)` called on page click
- `onPageChange` NOT called when clicking disabled button
- TypeScript compiles without errors
</acceptance_criteria>


Render `Pagination` below the campaign card list, only when `totalPages > 1`:

```tsx
{totalPages > 1 && (
  <Pagination
    currentPage={page}
    totalPages={totalPages}
    onPageChange={(newPage) => {
      const sp = new URLSearchParams(searchParams as Record<string, string>);
      sp.set("page", String(newPage));
      if (newPage === 1) sp.delete("page");
      router.replace(`/campanhas?${sp.toString()}`);
    }}
  />
)}
```

`onPageChange` → `router.replace()` preservando outros filtros. Remove `page` da URL quando for 1 (default).

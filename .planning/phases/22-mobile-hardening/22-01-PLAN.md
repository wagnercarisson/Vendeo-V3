### 1.2 Implementar focus trap manual

<read_first>
- openspec/changes/fase-22-mobile-hardening/specs/accessible-drawer/spec.md (Requirement: Focus trap manual dentro do drawer)
- openspec/changes/fase-22-mobile-hardening/design.md (D2 — requisitos de focus trap)
- src/components/shell/sidebar-drawer.tsx (current implementation)
</read_first>

<action>
Adicionar `useEffect` com keydown listener no drawer aberto:

```typescript
const focusableSelector = 'a[href], button:not([disabled]), textarea, input, select, [tabindex]:not([tabindex="-1"])'

useEffect(() => {
  if (!isOpen) return
  const panel = panelRef.current
  if (!panel) return
  const focusable = panel.querySelectorAll<HTMLElement>(focusableSelector)
  const first = focusable[0]
  const last = focusable[focusable.length - 1]
  first?.focus()

  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key !== 'Tab') return
    if (e.shiftKey && document.activeElement === first) {
      e.preventDefault()
      last?.focus()
    } else if (!e.shiftKey && document.activeElement === last) {
      e.preventDefault()
      first?.focus()
    }
  }
  panel.addEventListener('keydown', handleKeyDown)
  return () => panel.removeEventListener('keydown', handleKeyDown)
}, [isOpen])
```

Precisa de um `useRef` para o panel (`panelRef`), atachado à div do painel. O foco move-se ao primeiro elemento focável ao abrir (foco inicial).
</action>

<acceptance_criteria>
- Ao abrir drawer, foco está no primeiro link de navegação
- Tab循环: Tab no último elemento retorna ao primeiro
- Shift+Tab no primeiro elemento vai ao último
- Foco não vaza para elementos fora do drawer
- `panelRef` atachado à div do painel deslizante
- TypeScript compila sem erros
</acceptance_criteria>

### 1.7 Implementar body scroll lock com save/restore

<read_first>
- openspec/changes/fase-22-mobile-hardening/specs/accessible-drawer/spec.md (Requirement: Body scroll lock com save/restore)
- openspec/changes/fase-22-mobile-hardening/design.md (D2 — scroll lock)
- src/components/shell/sidebar-drawer.tsx (current implementation)
</read_first>

<action>
Usar `useLayoutEffect` para sincronia DOM:

```typescript
const originalOverflowRef = useRef<string>('')

useLayoutEffect(() => {
  if (isOpen) {
    originalOverflowRef.current = document.body.style.overflow
    document.body.style.overflow = 'hidden'
  } else {
    document.body.style.overflow = originalOverflowRef.current
    originalOverflowRef.current = ''
  }
  return () => {
    if (isOpen) {
      document.body.style.overflow = originalOverflowRef.current
    }
  }
}, [isOpen])
```

O `return` cleanup garante restauro mesmo se componente desmontar com drawer aberto.
</action>

<acceptance_criteria>
- Abrir drawer: `document.body.style.overflow` salvo antes de setar `"hidden"`
- `originalOverflowRef` armazena valor original (não assume `""`)
- Fechar drawer: `document.body.style.overflow` restaurado ao valor salvo
- Se body tinha `overflow: auto` antes, restaura `auto`, não `""`
- Se componente desmontar com drawer aberto, overflow é restaurado
- TypeScript compila sem erros
</acceptance_criteria>

### 1.8 Implementar `prefers-reduced-motion` no drawer

<read_first>
- openspec/changes/fase-22-mobile-hardening/specs/accessible-drawer/spec.md (Requirement: prefers-reduced-motion remove transição)
- src/components/shell/sidebar-drawer.tsx (current implementation)
</read_first>

<action>
Usar `window.matchMedia('(prefers-reduced-motion: reduce)')` para detectar preferência:

```typescript
const [reducedMotion, setReducedMotion] = useState(false)

useEffect(() => {
  const mq = window.matchMedia('(prefers-reduced-motion: reduce)')
  setReducedMotion(mq.matches)
  const handler = (e: MediaQueryListEvent) => setReducedMotion(e.matches)
  mq.addEventListener('change', handler)
  return () => mq.removeEventListener('change', handler)
}, [])
```

No className da transição do drawer, substituir `duration-300` condicionalmente:
`${reducedMotion ? 'duration-0' : 'duration-300'}`
</action>

<acceptance_criteria>

- `prefers-reduced-motion` não ativo → drawer usa `duration-300` (comportamento normal)

<action>
Criar `src/lib/copy/copy-director-service.ts` com:

1. Classe `CopyDirectorService`:
   - Constructor recebe `provider: TextProvider` e `promptLoader?: PromptLoader` (default: `new PromptLoader()`)
   - Método `async generateCopy(input: CopyDirectorInput): Promise<CopyDirectorResult>`:
     - Valida input com `CopyDirectorInputSchema.parse(input)`
     - Mapeia campos do input para variáveis do template
     - Chama `this.promptLoader.load("campaign-copy-director", { productName, description, offer, storeName, segment, toneOfVoice, positioning, shortDescription, slogan, brandPersonality, campaignGuidelines })`
     - Chama `this.provider.generateText(prompt, { system: "Você é um copywriter especialista em marketing para lojas físicas.", temperature: 0.7, maxTokens: 1000 })`
     - Chama `this.parseResult(result.content)` e retorna

2. Método privado `parseResult(raw: string): CopyDirectorResult`:
   **Camada 1 — JSON:** Tenta `JSON.parse(raw)` + `CopyDirectorResultSchema.parse(result)`. Se sucesso, retorna.
   **Camada 2 — Regex:** Se JSON falhar, tenta extrair campos com regex:
     - `title`: match após `"title"[:：]\s*"([^"]+)"`
     - `caption`: match após `"caption"[:：]\s*"([^"]+)"`
     - `hashtags`: match array entre `[` e `]`
     - `cta_post`: match após `"cta_post"[:：]\s*"([^"]+)"`
     - Valida com `CopyDirectorResultSchema.parse(extracted)`. Se sucesso, retorna.
   **Camada 3 — Determinístico:** Se ambos falharem, usa `raw` como `caption`, `title` extraído de `raw` ou "Promoção Especial", `hashtags: []`, `cta_post: "Saiba mais!"`
</action>

<acceptance_criteria>

- `generateCopy(input)` com input completo retorna `CopyDirectorResult` com `title` não vazio, `caption` não vazio, `hashtags` com ao menos 3 itens, `cta_post` não vazio
- `generateCopy(input)` com input mínimo funciona sem erros
- `generateCopy(input)` com `toneOfVoice` vazio não quebra
- `parseResult()` com JSON válido retorna `CopyDirectorResult` correto
- `parseResult()` com texto malformatado usa regex fallback e retorna resultado válido
- `parseResult()` com texto completamente inválido usa fallback determinístico (raw como caption)
- TypeScript compila sem erros

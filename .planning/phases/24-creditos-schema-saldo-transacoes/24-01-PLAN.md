1. Validar `p_amount > 0` — se não, `RAISE EXCEPTION 'amount_invalido'`

7. `UPDATE credit_balances SET balance = balance_after WHERE store_id = p_store_id`
8. Retornar `tx_id`

REVERT: `DROP FUNCTION IF EXISTS public.grant_credits CASCADE;`
</action>

<acceptance_criteria>

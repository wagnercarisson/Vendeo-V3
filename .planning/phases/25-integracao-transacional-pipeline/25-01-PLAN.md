<action>
Criar `src/lib/rate-limit/rate-limit.ts`:

1. Import `supabaseAdmin` de `@/lib/supabase/server` e `RateLimitResult`, `GenerationRateEvent` de `./types`

2. `async function checkRateLimit(storeId: string): Promise<RateLimitResult>`:
   - Fazer duas consultas SQL com `supabaseAdmin.rpc` ou `supabaseAdmin.from(...)` com filtro de tempo:
     - Contagem na última hora: `WHERE store_id = $1 AND event_type = 'generation_attempt' AND created_at > NOW() - INTERVAL '1 hour'`
     - Contagem nas últimas 24h: `WHERE store_id = $1 AND event_type = 'generation_attempt' AND created_at > NOW() - INTERVAL '24 hours'`
   - Se contagem_hora >= 10 → `{ allowed: false, reason: "hourly_limit_exceeded" }`
   - Se contagem_dia >= 30 → `{ allowed: false, reason: "daily_limit_exceeded" }`
   - Caso contrário → `{ allowed: true, remaining: { hourly: 10 - count1h, daily: 30 - count24h }, resetTime: ... }`

3. `async function recordGenerationAttempt(storeId: string, userId: string, campaignId?: string): Promise<void>`:
   - INSERT em `generation_rate_events` com `event_type = 'generation_attempt'`, `campaign_id = null` (ou o valor fornecido)
</action>

<acceptance_criteria>
- `checkRateLimit(storeId)` retorna `{ allowed: true }` quando ambas as janelas estão abaixo do limite
- `checkRateLimit(storeId)` retorna `{ allowed: false, reason: "hourly_limit_exceeded" }` quando >= 10 na última hora
- `checkRateLimit(storeId)` retorna `{ allowed: false, reason: "daily_limit_exceeded" }` quando >= 30 nas últimas 24h

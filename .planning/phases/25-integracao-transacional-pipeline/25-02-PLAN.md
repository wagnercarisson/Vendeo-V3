- [ ] `mandatoryArtworkText?: string` no `GenerateImageRequestSchema`
- [ ] Componente `MandatoryArtworkField` no formulario de campanha

- [ ] Rate limit guard no PRE-STREAM (429 se excedido)
- [ ] Registro de tentativa em `generation_rate_events` apos guard
- [ ] Saldo check no PRE-STREAM (402 se insuficiente)

**File:** `src/app/api/campaign/generate-image/route.ts`

- `src/lib/text-provider/factory.ts` — createTextProvider
- `src/lib/image-generation/config.ts` — COST_PER_GENERATION
</read_first>

<action>
Reestruturar o handler POST em 3 zonas:

**ZONA PRE-STREAM (sincrono, fora do ReadableStream):**
Manter os passos existentes ate store identity (parse JSON, legacy check, productImage check, payload size, Zod, auth+ownership, store identity). Apos store identity, inserir controle de custo ANTES de qualquer operacao que consuma IA:

1. Rate limit guard: `checkRateLimit(storeId)` → 429 se excedido (sem IA, sem stream)
2. Record attempt: `recordGenerationAttempt(storeId, userId)` com `campaign_id = null`
3. Saldo check: `creditService.getBalance(storeId) < COST_PER_GENERATION` → 402 (sem IA, sem stream)

Depois (custo ja verificado):
4. [EXISTENTE] Input validation (pode consumir IA paga — rate limit + saldo ja verificados)
5. [EXISTENTE] Create campaign (generating status)
6. [NOVO] Reservar credito: `creditService.reserveCredit(storeId, COST_PER_GENERATION, { campaignId, idempotencyKey: reserve_${campaignId} })`

Se reserva falhar com saldo_insuficiente → delete campanha + 402.

**ZONA PARALELO (dentro do ReadableStream):**
Substituir a geracao sequencial por `Promise.all` com duas tasks:

1. `copyTask()`:
   - Construir `CopyDirectorInput` via `mapBriefToCopyDirectorInput`
   - Instanciar `CopyDirectorService` com provider primario (openai)
   - Tentativa 1: `copyDirector.generateCopy(input, { signal })`
   - Se erro retryable E `TEXT_FALLBACK_PROVIDER=gemini`: tentativa 2 com `GeminiTextProvider`
   - Se erro nao retryable: falha imediata
   - Emitir NDJSON `phase` events para copy_generation e copy_retry

2. `imageTask()`:
   - Se `mandatoryArtworkText` existe, montar `briefComMandatoryArtwork` com o campo no `campaignInput`
   - `imageService.generateImage(effectiveBrief, emit, signal)` — sem retry externo
   - Emitir NDJSON `phase` events

3. Execucao: `Promise.all([copyTask(), imageTask()])` com `AbortController`
4. Se um ramo falha: `abortController.abort()` aborta o remanescente

**ZONA POS-PARALELO (dentro do ReadableStream):**

1. Se ambos OK → Merge:
   - `publicationCopySnapshot = copyResult` (substitui buildPublicationCopySnapshot deterministico)
   - Transcode JPEG + Upload Storage + updateCampaignReady com snapshot do Copy Director
   - Confirmar credito (no-op)
   - Emit NDJSON result com `campaignId` e `campaignUrl`

2. Se falha → Estorno:
   - Se uploadSucceeded, limpar imagem do storage
   - updateCampaignError
   - `creditService.refundCredit(txId, reason, { idempotencyKey: refund_${txId} })`
   - Emit NDJSON error

3. Excecoes:
   - AbortError (timeout/abort) → estorno
   - Erro nao tratado → estorno + emit error
   - `finally`: clearTimeout, close stream
</action>

<acceptance_criteria>
- Rate limit excedido → 429 (sem IA, sem stream, sem campanha criada)
- Saldo insuficiente → 402 (sem IA, sem stream)
- Saldo OK + rate OK → stream inicia com Copy Director e Image Director em paralelo
- Copy falha retryable (com fallback configurado) → retry Gemini → ready ou estorno
- Copy falha nao retryable → estorno imediato
- Image falha → estorno + abort copy via AbortController
- Persistencia falha apos merge → estorno + limpa storage
- Timeout global → estorno
- `publication_copy_snapshot` contem resultado do Copy Director (title + caption + hashtags + cta_post)
- `publication_copy_snapshot` NAO contem mandatoryArtworkText
- TypeScript compila sem erros
</acceptance_criteria>

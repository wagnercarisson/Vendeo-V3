## Objective

## Must Haves

- [ ] Migration `20260717000003_create_admin_tables.sql` com `admin_users` + `admin_audit_log` + trigger append-only + índices + RLS
- [ ] Migration com RPC `admin_grant_credits()` — atômica (grant + audit log), idempotente via operationId
- [ ] Migration com RPC `admin_create_store_for_user()` — atômica (verificação + store + audit log)

- [ ] `npm run lint` — zero erros

<action>
Criar migration `supabase/migrations/20260717000003_create_admin_tables.sql` com:

1. **admin_users table:**
   - `user_id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - RLS habilitado
   - GRANT SELECT/INSERT/DELETE apenas para `service_role`

2. **admin_audit_log table:**
   - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `actor_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE`
   - `action TEXT NOT NULL` com CHECK constraint: `action IN ('credit_grant', 'credit_adjustment', 'store_create_invite', 'manual_refund')`
   - `target_type TEXT NOT NULL` com CHECK constraint: `target_type IN ('store', 'user', 'campaign')`
   - `target_id UUID NOT NULL`
   - `reason TEXT NOT NULL`
   - `operation_id UUID`
   - `metadata JSONB DEFAULT '{}'::jsonb`
   - `created_at TIMESTAMPTZ NOT NULL DEFAULT now()`
   - RLS habilitado
   - GRANT SELECT, INSERT apenas para `service_role`
   - Índices: `idx_admin_audit_log_actor (actor_id, created_at DESC)`, `idx_admin_audit_log_target (target_type, target_id, created_at DESC)`, `idx_admin_audit_log_operation UNIQUE (operation_id) WHERE operation_id IS NOT NULL`
   - Trigger `trg_admin_audit_log_immutable` BEFORE UPDATE OR DELETE
   - Função `prevent_admin_audit_log_mutation()` que lança `RAISE EXCEPTION 'admin_audit_log é append-only. Nenhum UPDATE ou DELETE é permitido.'`

3. RPC `admin_grant_credits(p_actor_id UUID, p_store_id UUID, p_amount INTEGER, p_reason TEXT, p_operation_id UUID, p_metadata JSONB DEFAULT '{}'::jsonb) RETURNS JSONB`:
   - SECURITY DEFINER com SET search_path = ''
   - Passo 1: Idempotência — SELECT operation_id existente em admin_audit_log. Se encontrado, retorna dados sem executar
   - Passo 2: Chama `grant_credits(p_store_id, p_amount, p_reason, 'admin_grant_' || p_operation_id, p_metadata)` e captura transaction_id
   - Passo 3: INSERT em admin_audit_log com actor_id, action='credit_grant', target_type='store', target_id=p_store_id, reason=p_reason, operation_id=p_operation_id, metadata={amount, transaction_id}
   - Passo 4: Se qualquer passo falhar → ROLLBACK

4. RPC `admin_create_store_for_user(p_admin_id UUID, p_user_id UUID, p_name TEXT, p_segment TEXT) RETURNS JSONB`:
   - SECURITY DEFINER com SET search_path = ''
   - Passo 1: Verifica se usuário já possui loja via SELECT em stores WHERE user_id = p_user_id. Se existir, lança exceção `usuario_ja_possui_loja`
   - Passo 2: Chama RPC existente `create_store_with_initial_grant(p_name := p_name, p_segment := p_segment, p_user_id := p_user_id)` e captura dados da loja criada
   - Passo 3: INSERT em admin_audit_log com actor_id=p_admin_id, action='store_create_invite', target_type='user', target_id=p_user_id, reason='Criação de loja via admin (convite beta)', metadata contendo storeId e storeName
   - Passo 4: Se qualquer passo falhar → ROLLBACK

5. RPC `admin_get_users_summary(p_search TEXT DEFAULT NULL, p_page INTEGER DEFAULT 1, p_page_size INTEGER DEFAULT 20) RETURNS JSONB`:
   - SECURITY DEFINER com SET search_path = ''
   - Consulta `auth.users` diretamente (privilégio de SECURITY DEFINER) e faz LEFT JOIN com `stores`, `credit_balances`, `campaigns`
   - Campos retornados: `user_id`, `email`, `store_id`, `store_name`, `segment`, `balance`, `total_campaigns`, `error_campaigns`, `last_campaign_at`, `created_at`
   - Se `p_search` não for nulo, filtra por `au.email ILIKE '%search%'` OR `s.name ILIKE '%search%'` OR `s.segment ILIKE '%search%'`
   - Retorna JSON com `{ data: jsonb, total: bigint }` — paginação via LIMIT/OFFSET
   - Inclui usuários SEM loja (LEFT JOIN, store_id null) — essencial para convite beta
   - Ordenação padrão: `au.created_at DESC`
   - Motivo: `auth.users` não é acessível via cliente anônimo; SECURITY DEFINER na RPC permite acesso com privilégios de service_role sem expor a tabela diretamente

7. Seção REVERT no final com comandos na ordem reversa
</action>

- CHECK constraints em `action` e `target_type`
- Índices: `idx_admin_audit_log_actor`, `idx_admin_audit_log_target`, `idx_admin_audit_log_operation` (UNIQUE)

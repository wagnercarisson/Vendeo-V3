# 26-02: API Routes e Páginas Admin

## Objective

Implementar todas as API routes e páginas admin: concessão de créditos, criação de loja, diretório de usuários, detalhe de lojista, triagem de erros e audit log.

## Must Haves

- [ ] `POST /api/admin/credits/grant` — grant atômico com idempotência + audit log
- [ ] `POST /api/admin/stores` — criação de loja para usuário sem loja (convite beta)
- [ ] `GET /api/admin/users` — listagem paginada com busca (email, storeName, segment)
- [ ] `GET /api/admin/users/[id]` — detalhe completo (user, store, balance, history, campaigns)
- [ ] `GET /api/admin/campaigns/errors` — campanhas com erro paginadas
- [ ] `GET /api/admin/audit-log` — audit log paginado com filtros
- [ ] `/admin` — dashboard operacional com visão geral
- [ ] `/admin/users` — diretório com busca SSR e paginação
- [ ] `/admin/users/[id]` — detalhe com saldo, extrato, grant form e store creation
- [ ] `/admin/campaigns/errors` — lista de campanhas com erro
- [ ] `/admin/audit-log` — histórico paginado com filtros
- [ ] `npm run typecheck` — zero erros
- [ ] `npm run lint` — zero erros

## Dependencies

26-01 (Migration, requireAdmin, Middleware, Admin Layout).

## Verification Criteria

- `POST /api/admin/credits/grant` retorna 200 com `{ transaction_id, audit_id, newBalance }`
- `POST /api/admin/stores` retorna 201 para user sem loja, 409 se já tem loja
- `GET /api/admin/users?search=joao` retorna lista filtrada
- `GET /api/admin/users/[id]` retorna dados consolidados
- `GET /api/admin/campaigns/errors` retorna campanhas com status error
- `GET /api/admin/audit-log` retorna histórico paginado
- Todas as rotas retornam 403 para usuário não admin
- Todas as páginas admin renderizam com dados SSR
- `npm run typecheck` passa sem erros

4. Exportar `POST` handler:
   ```typescript

     const admin = await requireAdmin();
     const body = CreateStoreSchema.parse(await request.json());
     const { data, error } = await supabaseAdmin.rpc("admin_create_store_for_user", {
       p_admin_id: admin.userId,
       p_user_id: body.userId,
       p_name: body.storeName,
       p_segment: body.segment,
     });
     if (error) {
       const msg = error.message?.toLowerCase() ?? "";
       if (msg.includes("usuario_ja_possui_loja") || msg.includes("já possui uma loja")) {
         return Response.json({ error: "Usuário já possui uma loja" }, { status: 409 });
       }
       throw error;
     }
     return Response.json(data, { status: 201 });
   }
   ```

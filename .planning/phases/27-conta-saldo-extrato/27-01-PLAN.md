   ```typescript
       .select("*", { count: "exact", head: true })
       .neq("type", "adjustment")
       .eq("store_id", storeId);

     if (error) throw error;
     return count ?? 0;
   }
   ```

   - `hasStore === false` → estado `no_store` (fallback "0 créditos" sem badge de alerta)

   - **inline**: Ícone (Lucide `Coins` ou similar) + valor em linha, cor conforme estado

4. **CTA condicional:**
   - Quando `showCta: true` e estado `zero` ou `low`, exibe link CTA
   - Link usa `ctaHref` ou default `/conta#creditos`

5. **Sem store state:**
   - `hasStore: false` exibe apenas "0 créditos" sem badge de alerta
   - Não exibe CTA de solicitação de créditos (CTA deve ser "Criar loja")
</action>

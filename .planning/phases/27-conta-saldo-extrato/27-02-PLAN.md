# 27-02: Páginas e Integração — TransactionHistory + CreditCta + Dashboard + /conta + Geração

## Objective

Integrar os componentes de crédito nos 3 pontos de decisão do lojista: dashboard (indicador discreto), `/conta` (card de saldo + extrato paginado + CTA) e `/campanhas/nova` (saldo + custo antes de gerar). Implementar `TransactionHistory` com paginação real e `CreditCta` com modal/mailto.

## Must Haves

- [ ] `src/components/credit/transaction-history.tsx` — Client Component, tabela paginada com Pagination da F21, type mapping
- [ ] `src/components/credit/credit-cta.tsx` — Client Component, modal com mailto/mensagem, variantes zero/low/normal
- [ ] Dashboard modificado — `BalanceDisplay` badge no grid (has_store_with_campaigns) e empty state (has_store_no_campaigns)
- [ ] `/conta` modificada — seção "Créditos" com BalanceCard (CTA condicional interno) + TransactionHistory, paginação real
- [ ] `/campanhas/nova` modificada — saldo + custo antes de gerar, botão desabilitado com tooltip quando zero
- [ ] `CampaignInputForm` recebe saldo como prop, desabilita submit quando zero, exibe tooltip e CTA
- [ ] Estados de erro tratados: fallback "—" sem quebrar página, mensagem distinta
- [ ] `npm run typecheck` — zero erros
- [ ] `npm run lint` — zero erros

## Dependencies

27-01 (CreditService session client, BalanceDisplay, BalanceCard), F21 (Pagination), F20 (Dashboard), F25 (campaign flow).

## Verification Criteria

- `TransactionHistory` exibe tabela com colunas Tipo, Valor, Saldo, Motivo, Data
- `TransactionHistory` vazio exibe "Nenhuma transação encontrada"
- `TransactionHistory` com `totalPages > 1` exibe controles de paginação da F21
- `CreditCta` com `variant: "zero"` exibe botão "Solicitar créditos" destacado
- `CreditCta` com `variant: "normal"` não renderiza nada
- `CreditCta` modal abre com mailto quando SUPPORT_EMAIL configurado, fallback sem mailto
- Dashboard `has_store_with_campaigns` exibe badge de saldo no grid de métricas
- Dashboard `has_store_no_campaigns` exibe badge de saldo no empty state
- Dashboard `no_store` não exibe badge de saldo
- `/conta` exibe seção "Créditos" com BalanceCard (CTA condicional interno) + extrato paginado
- `/conta` sem loja exibe "Criar loja" — não exibe extrato
- `/campanhas/nova` exibe "⚡ Saldo: X créditos    Custo: 1" antes do botão "Gerar"

- `npm run typecheck` passa sem erros

## ⚠ Atenção ao Dev — Evitar CTA Duplicado em /conta

O `BalanceCard` (27-01) já implementa CTA condicional interno para saldo zero/baixo (`"Solicitar créditos"`) e sem loja (`"Criar loja"`). A seção "Créditos" em `/conta` **não deve** renderizar `CreditCta` separado — o CTA já está dentro do `BalanceCard`.

**Regra:** `/conta/page.tsx` renderiza apenas `<BalanceCard>` e `<TransactionHistory>`. `CreditCta` é usado exclusivamente no fluxo de geração (`/campanhas/nova`), onde não há `BalanceCard`.

**Resumo por página:**
- **Dashboard**: `BalanceDisplay` (sem CTA — apenas badge)
- **/conta**: `BalanceCard` (CTA interno) + `TransactionHistory`
- **/campanhas/nova**: `CreditCta` standalone (quando saldo = 0)

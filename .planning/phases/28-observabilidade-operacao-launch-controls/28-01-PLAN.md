# 28-01: Fundação — Launch Config + AI Cost Estimator + Pipeline Logger

## Objective

Criar a base dos novos módulos operacionais: launch config centralizado com 5 flags lidas via helper único (zero `process.env` espalhado), estimador de custo IA com tabela de preços OpenAI + Gemini, e logger estruturado de pipeline com sanitização de dados sensíveis.

## Must Haves

- [ ] `src/lib/launch-config/config.ts` com tipo `LaunchConfig` (5 flags booleanas) e função `getLaunchConfig()` com defaults seguros
- [ ] `src/lib/launch-config/__tests__/config.test.ts` com 7+ cenários
- [ ] `src/lib/ai-cost/cost-estimator.ts` com `estimateAiCost()` e tabela de preços OpenAI (gpt-4o, gpt-4o-mini, dall-e-3) + Gemini
- [ ] `src/lib/ai-cost/index.ts` com barrel export
- [ ] `src/lib/ai-cost/__tests__/cost-estimator.test.ts` com 3+ cenários
- [ ] `src/lib/logging/pipeline-logger.ts` com tipo `PipelineEvent` e função `logPipelineEvent()` — JSON via console.log, sanitização de base64 e prompt, fire-and-forget
- [ ] `src/lib/logging/__tests__/pipeline-logger.test.ts` com 4+ cenários
- [ ] `npm run typecheck` — zero erros
- [ ] `npm run lint` — zero erros
- [ ] `npm run build` — bem-sucedido

## Dependencies

F24-01 (CreditService types), F25-01 (rate-limit types, pipeline config).

## Verification Criteria

- `getLaunchConfig()` sem env vars retorna defaults corretos (v15Enabled=true, generationPaused=false)
- Cada flag individual responde a sua env var específica
- Env var mal formatada usa fallback (nunca lança exceção)
- `estimateAiCost()` calcula OpenAI gpt-4o corretamente (1000 prompt + 500 completion = $0.0075)
- `estimateAiCost()` com modelo desconhecido retorna null
- `estimateAiCost()` sem usage retorna null
- `logPipelineEvent()` emite JSON com todos os campos obrigatórios
- Sanitização de base64 e prompt funciona
- Erro interno não propaga (fire-and-forget)
- Zero `process.env` nos callers — todo acesso via `getLaunchConfig()`
- `npm run typecheck`, `lint`, `build` passam

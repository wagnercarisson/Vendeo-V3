#### Task 1.11: Migration — Reescrever reserve_credit bucket-aware

<read_first>

<action>
Replace `reserve_credit` with bucket-aware logic (same 5 parameters):

```
amount_restante := p_amount;
deduct_from_bonus := LEAST(bonus_balance, amount_restante);
bonus_balance := bonus_balance - deduct_from_bonus;
amount_restante := amount_restante - deduct_from_bonus;
deduct_from_purchased := LEAST(purchased_balance, amount_restante);
purchased_balance := purchased_balance - deduct_from_purchased;
amount_restante := amount_restante - deduct_from_purchased;
IF amount_restante > 0 THEN RAISE EXCEPTION 'saldo_insuficiente'; END IF;
p_metadata := p_metadata || jsonb_build_object('bonus_amount', deduct_from_bonus, 'purchased_amount', deduct_from_purchased);
```
</action>

- Function signature unchanged: `reserve_credit(UUID, INTEGER, UUID, TEXT, JSONB)`
- With `bonus_balance = 5, purchased_balance = 10, amount = 3`: deducts 3 from bonus, 0 from purchased. Metadata: `bonus_amount: 3, purchased_amount: 0`
- With `bonus_balance = 5, purchased_balance = 10, amount = 8`: deducts 5 from bonus, 3 from purchased. Metadata: `bonus_amount: 5, purchased_amount: 3`
- With `bonus_balance = 5, purchased_balance = 10, amount = 20`: raises `saldo_insuficiente`, no state change

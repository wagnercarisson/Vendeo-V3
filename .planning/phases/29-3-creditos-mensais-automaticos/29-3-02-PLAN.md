## 29-3-02: grant_monthly_credits + Launch Config

Criar a RPC `grant_monthly_credits()` que implementa concessão mensal automática com elegibilidade, teto, grant parcial, idempotência por ciclo efetivo e FOR UPDATE SKIP LOCKED. Expandir Launch Config com 4 novas flags de política de bônus.

<action>
Add to the existing migration (`20260722000002_creditos_mensais_automaticos.sql`) the RPC:

```sql
CREATE OR REPLACE FUNCTION public.grant_monthly_credits(
  p_amount INTEGER,
  p_bonus_cap INTEGER,
  p_min_store_age_days INTEGER
) RETURNS JSONB ...
```

Implementation rules:
1. **Pré-contagem de elegíveis**: stores WHERE `created_at <= NOW() - make_interval(days => p_min_store_age_days)` AND (`last_monthly_grant_at IS NULL` OR `last_monthly_grant_at < NOW() - make_interval(days => p_min_store_age_days)`)
2. **Pré-contagem de skipped**: elegíveis WHERE `bonus_balance >= p_bonus_cap`
3. **Etapa 1**: INSERT INTO credit_balances (zeros) para elegíveis abaixo do cap sem registro, ON CONFLICT DO NOTHING
4. **Etapa 2**: SELECT ... FOR UPDATE OF cb SKIP LOCKED WHERE bonus_balance < p_bonus_cap
5. **Grant**: LEAST(p_amount, p_bonus_cap - rec.bonus_balance)
6. **Idempotency key**: `'mensal_ciclo_' || FLOOR(EXTRACT(EPOCH FROM (NOW() - s.created_at)) / (30 * 86400)) || '_' || s.id`
7. Call `grant_credits(s.id, grant, 'mensal', idempotency_key, jsonb_build_object('cycle', ciclo, 'grant_type', 'bonus_monthly'), 'bonus_monthly')`
8. Update `credit_balances.last_monthly_grant_at = NOW()` only when grant > 0
9. Return JSONB: `{ eligible: int, granted: int, skipped: int, errors: int }`
</action>

<acceptance_criteria>
- Function `grant_monthly_credits(INTEGER, INTEGER, INTEGER)` exists with RETURNS JSONB
- Eligible store (created_at >= 30d, bonus_balance = 0, no prior grant): receives p_amount, granted=1
- Store at cap (bonus_balance = p_bonus_cap): skipped, last_monthly_grant_at NOT updated
- Store close to cap (bonus_balance = 8, cap = 10, amount = 5): receives grant = 2 (partial)
- Young store (created_at = 15d ago): not eligible
- Already granted store (last_monthly_grant_at = 5d ago): not eligible
- Return JSON structure: `{"eligible": number, "granted": number, "skipped": number, "errors": number}`
- Store without credit_balances row gets row created with zeros before processing
- Concurrent execution: SKIP LOCKED prevents duplicate processing
- Idempotency key for store created 65d ago: `'mensal_ciclo_2_' || store_id`
</acceptance_criteria>

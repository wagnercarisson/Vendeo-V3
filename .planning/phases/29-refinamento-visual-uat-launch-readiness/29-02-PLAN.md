<read_first>

<action>
Apply these microcopy substitutions across all 7 fluxos:

| Termo técnico | Substituição |
|--------------|--------------|
| "Badge Promocional" | "Selo promocional" |
| "Caption" | "Legenda" |
| "CTA" (como label de UI) | "Chamada" ou "Texto de chamada" |
| "Audit Log" | "Histórico de auditoria" |
| "Healthy" (health state) | "Saudável" |
| "Attention" (health state) | "Atenção" |
| "Pause" (health state) | "Pausado" |
| "N/D" (sem dados) | "—" (traço) |
| "Copy Director" (na UI) | "Texto da campanha" |
| "geração" (como jargão técnico no fluxo do lojista) | "criar campanha" |
| "publication copy" | "legenda" |
| "snapshot" (na UI do lojista) | "prévia" |
| "rate limit" (na UI do lojista) | "limite de gerações" |
| "generation" (na UI do lojista) | "campanha" ou "criação" |

**Regra:** remover "geração" quando aparecer como jargão técnico no fluxo do lojista (ex: botão "Gerar campanha" → "Criar campanha"). Manter quando for termo aprovado em mensagens de sistema como "limite de gerações" ou em contextos admin/métricas.

Standardize CTAs:
- "Solicitar créditos" used everywhere (not "comprar", "adquirir", "obter")
- "Fale com o time" used everywhere (not "suporte", "ajuda", "contato")
</action>

<acceptance_criteria>
- None of the technical terms appear in user-visible UI across 7 fluxos
- "Solicitar créditos" is used consistently for all credit-related CTAs
- "Fale com o time" is used consistently for all support CTAs
- Build passes
- TypeScript compile passes
</acceptance_criteria>

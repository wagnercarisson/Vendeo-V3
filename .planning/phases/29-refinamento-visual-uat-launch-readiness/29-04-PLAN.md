### Task 29-04-02: Preparar roteiro de UAT

<read_first>
- docs/launch-readiness/uat-results/pool.md
</read_first>

<action>
Create `docs/launch-readiness/uat-results/roteiro.md` with 8 minimum scenarios:

1. **Cadastro/onboarding**: lojista convidado completa cadastro → loja criada, 5 créditos concedidos, extrato mostra grant
2. **Admin concede créditos**: admin concede créditos via admin → saldo reflete, extrato mostra transação
3. **Geração bem-sucedida**: lojista gera campanha → saldo decrementa 1, extrato mostra deduction
4. **Geração com erro** (simulado): geração falha → saldo restaurado, extrato mostra refund
5. **Saldo consistente**: saldo igual na topbar, dashboard e /conta
6. **Extrato correto**: tipos, valores, datas, saldo before/after corretos
7. **Admin visualiza erro**: admin acessa /admin/campaigns/errors → vê campanhas com erro
8. **Admin visualiza audit log**: admin acessa /admin/audit-log → vê histórico de ações
</action>

<acceptance_criteria>
- `docs/launch-readiness/uat-results/roteiro.md` created
- 8 scenarios detailed with setup, steps, and expected results
- Each scenario references specific requirements
</acceptance_criteria>

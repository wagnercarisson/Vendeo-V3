## Decisions Made

- **Zod v3.24.x pinned** instead of latest v4.x — plan specifically required ^3.x; v3 is stable, the patterns used (z.object, z.string, z.number, safeParse, z.infer) are identical between v3 and v4, but sticking to v3 eliminates risk
- **brandColor regex** accepts both cases (uppercase `#FFF`, lowercase `#fff`) to match store data patterns
- **state validation** designed as `z.string().length(2).optional()` per spec — accepts `undefined` when omitted, rejects `null` and empty strings
- **generated_at** uses `z.string().datetime()` with a Portuguese error message "Deve ser uma data ISO 8601" — this is the Zod v3 API for ISO 8601 enforcement
- **AIProvider** documented constraint: "Implementations MUST NOT access HTTP request/response objects" — keeps the interface pure data transformation
- **Relative imports** between campaign-intelligence modules (`../schema`) — avoids `@/` alias to keep the module self-contained

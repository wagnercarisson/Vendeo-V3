## Decisions Made

- **`toLocaleString('pt-BR')`** for price formatting — uses Node.js ICU data, produces correct decimal comma (`,`) and thousands dots (`.`). Pattern: `(cents / 100).toLocaleString('pt-BR', { minimumFractionDigits: 2 })`.
- **Conditional `original_price_display`** — using `if (input.originalPriceCents > 0)` block to add the key rather than a ternary that produces `undefined`. `JSON.stringify` strips `undefined` values, so `original_price_display` key is absent from JSON when the condition is false.
- **hook logic** — `input.description && input.description.trim().length > 0` checks existence and non-emptiness before using it; falls back to hardcoded PT-BR default.
- **badge_text logic** — same pattern: `input.badge && input.badge.trim().length > 0 ? input.badge : "Oferta"`.
- **Three distinct `console.error` calls** in the service — one per error path (provider exception, JSON parse failure, schema validation failure). Each logs the raw data for debugging without including it in the response.
- **Error messages in Portuguese (BR)** — user-facing error messages follow domain convention.

<action>
Modify `src/app/(app)/conta/page.tsx`:

Add a new card section "Privacidade e Termos" with:

   - Show "Ciente" with current version if privacyAcknowledged is true
   - Show "Pendente" with action button if false (link to re-accept if needed)

   - Show "Nunca aceitou" if never

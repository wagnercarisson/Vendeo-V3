# Plan 31-3-02: Intent-Aware Review Service

## Objective

Implementar a lógica central de revisão intent-aware: montagem de variáveis contextuais em duas etapas, `expectedBadgeBehavior` com três variantes, tratamento de `empty_review` como resultado estruturado, sem placeholders vazios no prompt.

## Tasks

### Task 1: review() monta variáveis contextuais em 2 etapas

<read_first>
- src/lib/image-generation/services/image-review-service.ts (review() método, linhas 56-98)
- openspec/changes/fase-31-3-quality-gate-por-intencao-comercial/design.md (D2)
- openspec/changes/fase-31-3-quality-gate-por-intencao-comercial/specs/intent-aware-review/spec.md
</read_first>

<action>
1. Em `src/lib/image-generation/services/image-review-service.ts`, reestruturar o método `review()`:
   - **Etapa 1 — Resolver placeholders comerciais:**
     - Extrair `discountedPrice`, `badgeText`, `originalPrice` de `input` (valores já formatados pelo pipeline)
     - Se `campaignIntent === "exclusive"`, ignorar `discountedPrice` (exclusive não tem preço)
     - Formatar em variáveis intermediárias reais (não placeholders)
   - **Etapa 2 — Montar strings contextuais finais:**
     - Invocar métodos auxiliares para produzir:
       - `campaignIntentLabel`: "Promoção" | "Destaque" | "Exclusivo"
       - `expectedPriceBehavior`: string descritiva por intent
       - `expectedBadgeBehavior`: string por intent + badge presence
       - `expectedImageTreatment`: "Fundo contextual preservado" | "Fundo comercial" por `preserveImageContext`
       - `expectedCommercialTone`: "Promocional, urgência" | "Aspiracional, desejo" | "Premium, exclusividade"
   - **PromptLoader.load("campaign-image-reviewer", contextVars):**
     - Passar APENAS: `campaignIntentLabel`, `expectedPriceBehavior`, `expectedBadgeBehavior`, `expectedImageTreatment`, `expectedCommercialTone`, `productName`, `storeName`, `originalPrice`, `validationContextSection`
     - NUNCA passar `discountedPrice` ou `badgeText` diretamente como placeholders
2. O prompt final terá placeholders `{{campaignIntentLabel}}`, `{{expectedPriceBehavior}}`, etc. — NÃO `{{discountedPrice}}` ou `{{badgeText}}`.
</action>

<acceptance_criteria>
- `review()` com `campaignIntent: "offer"`, `discountedPrice: "R$ 29,90"`, `badgeText: "Promoção"` monta `expectedPriceBehavior` contendo "R$ 29,90" (não `{{discountedPrice}}`)
- `review()` com `campaignIntent: "exclusive"`, `discountedPrice: undefined` monta `expectedPriceBehavior` = "A imagem NÃO deve exibir preço."
- `PromptLoader.load()` é chamado com vars que NÃO contêm `discountedPrice` ou `badgeText` como chaves
- `npm run typecheck` passa
</acceptance_criteria>

### Task 2: Implementar expectedBadgeBehavior com 3 variantes

<read_first>
- src/lib/image-generation/services/image-review-service.ts (review())
- openspec/changes/fase-31-3-quality-gate-por-intencao-comercial/design.md (D3)
</read_first>

<action>
1. Criar método privado `buildExpectedBadgeBehavior(campaignIntent: CampaignIntent, badgeText: string | undefined): string`:
   ```
   Se campaignIntent === "offer":
     "A imagem DEVE exibir badge promocional. O texto deve ser '{badgeText || ""}'. Badge promocional é obrigatório."

   Se campaignIntent === "spotlight" || "exclusive":
     Se badgeText presente e não vazio:
       "Badge é opcional, mas foi informado '{badgeText}'; se aparecer na imagem, deve bater com o texto exato."
     Se badgeText undefined ou vazio:
       "Nenhum badge foi informado; a imagem pode não ter badge. Se a imagem inventar um badge, ele não deve criar promessa promocional indevida."
   ```
2. Offer SEMPRE usa variante obrigatória, mesmo com badgeText vazio.
3. NUNCA gerar frases com `('')` vazio para spotlight/exclusive sem badge.
</action>

<acceptance_criteria>
- Offer com `badgeText: "Promoção"` → "A imagem DEVE exibir badge promocional. O texto deve ser 'Promoção'."
- Offer com `badgeText: ""` → ainda "DEVE exibir badge promocional"
- Spotlight com `badgeText: "Novidade"` → "Badge é opcional, mas foi informado 'Novidade'"
- Exclusive sem badge → "Nenhum badge foi informado; a imagem pode não ter badge."
- `npm run typecheck` passa
</acceptance_criteria>

### Task 3: Implementar demais variáveis contextuais por intent

<read_first>
- src/lib/image-generation/services/image-review-service.ts (review())
- openspec/changes/fase-31-3-quality-gate-por-intencao-comercial/specs/intent-aware-review/spec.md
</read_first>

<action>
1. Criar método `buildExpectedPriceBehavior(campaignIntent: CampaignIntent, discountedPrice: string | undefined): string`:
   ```
   offer + discountedPrice presente:
     "A imagem DEVE exibir preço promocional. O preço com desconto é {discountedPrice}."
   offer + discountedPrice ausente:
     "A imagem DEVE exibir preço promocional." (raro, mas possível)
   spotlight:
     "A imagem DEVE exibir preço único de {discountedPrice}." ou
     "A imagem DEVE exibir preço (único, sem DE/POR)."
   exclusive:
     "A imagem NÃO deve exibir preço. Qualquer preço na imagem é um problema CRÍTICO."
   ```
2. Criar método `buildCampaignIntentLabel(intent: CampaignIntent): string`:
   - `"offer"` → `"Promoção"`
   - `"spotlight"` → `"Destaque"`
   - `"exclusive"` → `"Exclusivo"`
3. Criar método `buildExpectedImageTreatment(preserveImageContext: boolean | undefined): string`:
   - `true` → `"O fundo contextual da imagem DEVE ser preservado (ambiente, cenário). Não substituir por fundo comercial."`
   - `false/undefined` → `"A imagem DEVE usar fundo comercial limpo, sem contexto de ambiente."`
4. Criar método `buildExpectedCommercialTone(intent: CampaignIntent): string`:
   - `"offer"` → `"Tom promocional com senso de urgência. CTA de compra esperado."`
   - `"spotlight"` → `"Tom aspiracional de destaque e desejo. Sem urgência promocional."`
   - `"exclusive"` → `"Tom premium de exclusividade. Sem linguagem promocional ou de urgência."`
</action>

<acceptance_criteria>
- `buildExpectedPriceBehavior("offer", "R$ 29,90")` contém "R$ 29,90"
- `buildExpectedPriceBehavior("exclusive", undefined)` contém "NÃO deve exibir preço"
- `buildExpectedPriceBehavior("spotlight", "R$ 89,90")` contém "preço único"
- `buildCampaignIntentLabel("exclusive")` → `"Exclusivo"`
- `buildExpectedImageTreatment(true)` contém "preservado"
- `buildExpectedImageTreatment(false)` contém "fundo comercial"
- `buildExpectedCommercialTone("spotlight")` contém "aspiracional"
- `npm run typecheck` passa
</acceptance_criteria>

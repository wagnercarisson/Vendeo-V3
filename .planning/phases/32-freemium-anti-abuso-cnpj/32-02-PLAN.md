    - Classe `FreemiumEntitlementService` com injeção de `supabaseAdmin` (padrão = singleton):
    ```typescript
    class FreemiumEntitlementService {
      constructor(private readonly adminClient = supabaseAdmin) {}
    ```
    - **IMPORTANTE:** Os métodos grant usam RPCs SQL (`try_grant_onboarding_entitlement`, `try_grant_monthly_entitlement`) em vez de `INSERT ... ON CONFLICT` direto via Supabase JS. Isso porque o índice de expressão `(root_hash, benefit_type, COALESCE(cycle, '_nostring_'))` não é bem suportado por `.insert()/.upsert()` do Supabase JS (#3231). As RPCs executam ON CONFLICT em SQL puro com RETURNING id.
    - Métodos (todos públicos, todos usam `this.adminClient`):

    1. `checkOnboardingEligibility(rootHash: string): Promise<boolean>`
       - SELECT 1 FROM freemium_entitlements WHERE root_hash = rootHash AND benefit_type = 'onboarding' LIMIT 1
       - Retorna true se não encontrou (elegível), false se encontrou

    2. `grantOnboardingEntitlement(storeId: string, rootHash: string, txId?: string): Promise<string | null>`
       - `this.adminClient.rpc("try_grant_onboarding_entitlement", { p_store_id: storeId, p_root_hash: rootHash, p_grant_transaction_id: txId ?? null })`
       - Retorna `id` do INSERT se venceu, `null` se ON CONFLICT ignorou

    3. `checkMonthlyEligibility(rootHash: string, cycle: string): Promise<boolean>`
       - SELECT 1 FROM freemium_entitlements WHERE root_hash = rootHash AND benefit_type = 'monthly' AND cycle = cycle LIMIT 1
       - Retorna true se não encontrou

    4. `grantMonthlyEntitlement(storeId: string, rootHash: string, cycle: string, txId?: string): Promise<string | null>`
       - `this.adminClient.rpc("try_grant_monthly_entitlement", { p_store_id: storeId, p_root_hash: rootHash, p_cycle: cycle, p_grant_transaction_id: txId ?? null })`
       - Retorna id ou null

    5. `getHistoryByStore(storeId: string): Promise<FreemiumEntitlement[]>`
       - SELECT * FROM freemium_entitlements WHERE store_id = storeId ORDER BY created_at DESC

    6. `getHistoryByRoot(rootHash: string): Promise<FreemiumEntitlement[]>`
       - SELECT * FROM freemium_entitlements WHERE root_hash = rootHash ORDER BY created_at DESC

    - Mapeamento snake_case → camelCase no retorno das queries (seguir padrão de credit-service.ts)

| client→POST /api/store | CNPJ raw enviado no body da requisição HTTPS |
| route→RPC | cnpj_normalized + cnpj_root_hash (pré-calculado pela rota via process.env.CNPJ_PEPPER) |
| route→response | cnpjMasked no response body; raw CNPJ nunca retornado |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-06 | Spoofing | POST /api/store | mitigate | validateCnpj rejeita CNPJ inválido antes de qualquer operação. Rota server-side calcula root_hash com process.env.CNPJ_PEPPER e passa para RPC service_role — hash nunca exposto ao client |
| T-32-07 | Tampering | entitlement grant | mitigate | INSERT ... ON CONFLICT DO NOTHING — idempotente e race-condition free |
| T-32-08 | Information Disclosure | response | mitigate | maskCnpj aplicado na response. Raw CNPJ nunca retornado |
| T-32-09 | Repudiation | onboarding grant | mitigate | Entitlement registrado antes do grant. grant_transaction_id vinculado |
</threat_model>

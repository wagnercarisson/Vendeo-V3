    - class CnpjVerificationService
    - constructor(primaryProvider: CnpjLookupProvider, fallbackProvider: CnpjLookupProvider, cache: CnpjLookupCache)
    - async resolve(cnpj: string): Promise&lt;LookupOutcome&gt;

    Lógica de resolve:
    1. Normalizar CNPJ (reusar normalizeCnpj da F32)
    2. Consultar cache por cnpj_normalized
    3. Cache hit (outcome=resolved, expires_at > now) → retorna dados
    4. Cache hit (outcome=not_found, expires_at > now) → retorna not_found sem consultar API
    5. Cache miss ou expirado → consulta primaryProvider
    6. Primary unavailable → consulta fallbackProvider
    7. Ambos unavailable → retorna unavailable (NÃO cacheia)
    8. not_found → cacheia com outcome=not_found e TTL 24h
    9. resolved → cacheia com outcome=resolved e TTL 24h

    interface CnpjLookupCache:
    - async get(cnpjNormalized: string): Promise&lt;{outcome, data, expiresAt} | null&gt;
    - async set(cnpjNormalized: string, outcome: string, data: any, ttlHours: number): Promise&lt;void&gt;

    Implementação do cache via fetch Supabase (select/upsert em cnpj_lookup_cache).

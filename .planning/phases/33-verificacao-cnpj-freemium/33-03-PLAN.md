       - cnpjExists: input.lookupOutcome === 'resolved'
       - situacaoCadastral: input.officialData?.situacao_cadastral || null
       - rootEligible: checar se root_hash já tem entitlement 'onboarding' (consulta Supabase)

       - cnaeCompatible: null (sinal fraco, não usado na F33)

    2. Aplicar regras de decisão (ordem importa):
       a. lookupOutcome === 'not_found' → reject (cnpj_not_found)
       b. situacaoCadastral === 'BAIXADA' → reject (cnpj_baixada)
       c. situacaoCadastral === 'NULA' → reject (cnpj_nula)
       d. rootEligible === false → reject (root_already_used)
       e. officialData === null → defer (api_unavailable)
       f. situacaoCadastral === 'SUSPENSA' → review (situacao_suspensa)
       g. nameSimilarity < 0.6 → review (nome_divergente)
       h. cityMatch === false → review (cidade_divergente)
       i. stateMatch === false → review (uf_divergente)
       j. demais → approve (nenhuma razão de impedimento)

    3. Calcular score (0-100):
       - Base 50 + 10*cnpjExists + 10*rootEligible + 10*nameSimilarity + 10*cityMatch + 10*stateMatch

    - Similaridade com razão social (compareBusinessName)
    - Se resultado < 0.6 e nomeFantasia existe, tentar com nomeFantasia

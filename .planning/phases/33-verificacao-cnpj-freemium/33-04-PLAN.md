  <action>
    Criar 6 endpoints admin:

    1. GET /api/admin/reviews?status=review&page=1&limit=20
       - Lista lojas paginadas por verification_status
       - Retorna: id, name, cnpj_masked, user_email, created_at, reasons, decision, official_data (resumido)

    2. GET /api/admin/reviews/[id]
       - Detalhe completo: dados oficiais, sinais de avaliação, motivos, histórico

    3. POST /api/admin/reviews/[id]/approve
       - Chama RPC admin_approve_store_verification
       - Tenta conceder onboarding normal (se raiz elegível)
       - INSERT admin_audit_log com action='approve_verification', metadata={store_id, store_name, onboarding_granted}
       - Response: { success, onboardingGranted }

    4. POST /api/admin/reviews/[id]/reject
       - Chama RPC admin_reject_store_verification
       - INSERT admin_audit_log com action='reject_verification'
       - Response: { success }

    5. POST /api/admin/reviews/[id]/exception
       - Concede grant com benefit_type='admin_exception' (bypassa elegibilidade)
       - INSERT admin_audit_log com action='admin_exception', metadata={reason}
       - Body: { reason: string }
       - Response: { success }

    6. POST /api/admin/reviews/[id]/reveal-cnpj
       - Retorna CNPJ completo (14 dígitos)
       - INSERT admin_audit_log com action='reveal_cnpj', target=store_id
       - Response: { cnpj: string }
  </action>

  <acceptance_criteria>
    - GET /api/admin/reviews lista lojas paginadas por status
    - POST /api/admin/reviews/[id]/approve executa RPC e audita
    - POST /api/admin/reviews/[id]/reject executa RPC e audita
    - POST /api/admin/reviews/[id]/exception concede grant via admin_exception e audita
    - POST /api/admin/reviews/[id]/reveal-cnpj retorna CNPJ completo e audita
    - Tests: 7+ cenários de admin reviews
  </acceptance_criteria>
</task>

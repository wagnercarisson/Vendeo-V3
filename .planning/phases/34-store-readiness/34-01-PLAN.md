## Existing Migration Patterns

From `supabase/migrations/20260727000001_freemium_anti_abuso_cnpj.sql` e anteriores:
- Naming: `YYYYMMDDHHMMSS_descriptive_name.sql`
- RPCs use `CREATE OR REPLACE FUNCTION` with `LANGUAGE plpgsql SECURITY DEFINER`
- REVERT block at end: `-- REVERT` section
- RLS: `ALTER TABLE ... ENABLE ROW LEVEL SECURITY;`
- Triggers: `CREATE OR REPLACE FUNCTION ... RETURNS TRIGGER` + `CREATE TRIGGER ... BEFORE UPDATE ON ...`

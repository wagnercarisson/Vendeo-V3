## Readiness Check Pattern (to be used in both)

```typescript
const readiness = await getStoreReadiness(storeId);
if (!readiness.ready) {
  const firstMissing = readiness.missing[0].item;
  if (firstMissing === "cadastro_fiscal") {
    redirect("/cadastro/cnpj?returnTo=/campanhas/nova");
  } else {
    redirect("/loja?required=visual-direction");
  }
}
```

## API Guard Return Pattern

```typescript
if (!readiness.ready) {
  return Response.json({
    error: {
      message: "Loja não está pronta para gerar campanhas.",
      reasons: readiness.missing.map(m => m.reason),
      missing: readiness.missing.map(m => m.item),
    },
  }, { status: 412 });
}
```

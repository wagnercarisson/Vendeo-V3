<action>
Refactor `getPreFillFromCnpj` into a pure/shared module that does NOT import `supabaseAdmin` or any server-only dependency:

3. The prefill happens in two steps:
   - Server resolves CNPJ data via the existing F33 lookup (BrasilAPI/CNPJá)
   - Server calls `cnpj-address-mapper.ts` to extract address fields

4. The server component (`store-page-client.tsx`) receives prefilled billing data via props or serialized state
5. `billing_data_source` is set based on the CNPJ lookup provider ('brasilapi' or 'cnpja')
6. `billing_data_last_prefilled_from` is tracked with the provider name

Alternatively, the client calls `getPreFillFromCnpj` directly via a thin API route or server action that delegates to the pure mapper — never by importing the original `store-billing-info.ts` module.
</action>

<acceptance_criteria>

- Pode ser importado por client ou server sem quebrar build

- `billing_data_source` reflete a origem ('brasilapi' ou 'cnpja')

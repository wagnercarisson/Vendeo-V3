**Derivação monetária (D1/D4):**
```
custoBrl      = custoUsdTotal × usd_brl_rate
receitaOpBrl  = creditosDebitados × credit_value_brl
resultadoOpBrl = receitaOpBrl − custoBrl
margemOpPct   = receitaOpBrl > 0 ? (resultadoOpBrl / receitaOpBrl) × 100 : null
```
- Parâmetros via `economic.getParameter("usd_brl_rate")` / `getParameter("credit_value_brl")` (38-2-02 — fail-open 1.00 / fail-closed lança → service propaga → API 503).

**Badges (D5) — mapa por evento (detalhe):**
| Badge | Condição |
|-------|----------|
| provider_reported | cost_source = 'provider_reported' |
| provisional image tool estimate | cost_source = 'pricing_table' E cost_estimation_note = 'provisional_image_tool_unit_cost_until_provider_reconciliation' |
| partial | cost_source = 'manual_unknown' OU pricing_table com nota de estimativa parcial (ex.: responses_image_generation_tool_without_unit_pricing) |
| estimated | cost_source = 'pricing_table' (sem nota) ou fallback_static |
| not_available | cost_source = 'not_available' |
| estimated (genérico) | cost_source presente mas nota NULL |

**Badge por entrega (lista)** — a partir dos insumos agregados do RPC (`cost_sources[]`, `cost_estimation_notes[]`, flags `has_*`): prioridade `has_provider_reported` → `provider_reported`; senão `has_provisional_image_estimate` → provisional image tool estimate; senão `has_partial_estimate` → partial; senão `has_not_available` → not_available; senão `has_estimated` → estimated; senão estimated genérico.

**Segmentação (D9) — classifySegment(evidências, store):**
| Segmento | Critério (best-effort) |
|----------|------------------------|
| test | store_is_test = true |
| freemium/promotional | deduction_bonus_amount > 0 E deduction_purchased_amount = 0 |
| paid | deduction_purchased_amount > 0 |
| manual/admin | admin_grant_evidence presente (shape real confirmado em credit_transactions — type/metadata.reason/metadata.source; sem evidência confiável → unknown, nunca inferir errado) |
| unknown | fallback |
- `paid`/`unknown` exibem indicador de baixa confiança quando derivados sem origem clara.
- Segmentação **nunca no RPC** — service layer apenas.

**storeName/owner:** JOIN em stores (store_id → name, user_id como owner) — resolvido no service para listagem e agregados byOwner.

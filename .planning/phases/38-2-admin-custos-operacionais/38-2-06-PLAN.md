Schema (`src/lib/admin/schemas.ts`):
```typescript
export const AiOperationRunsQuerySchema = z.object({
  periodStart: z.string().datetime().optional(),    // period_start ISO
  periodEnd: z.string().datetime().optional(),       // period_end ISO
  storeId: z.string().uuid().optional(),
  operationRunType: z.string().optional(),
  status: z.string().optional(),
  provider: z.string().optional(),
  model: z.string().optional(),
  generationType: z.string().optional(),
  operationRunId: z.string().uuid().optional(),
  segment: z.enum(["test","freemium/promotional","paid","manual/admin","unknown"]).optional(),
  page: z.coerce.number().int().min(1).default(1),
  pageSize: z.coerce.number().int().min(1).max(100).default(25),
}).superRefine(validarJanela);   // default ≤ 90d; max 365d → fail
```
- Validação de janela: se periodStart+periodEnd ausentes → janela default 90 dias (sem 400); se presentes e intervalo > 365 dias → 400 (zod custom) — `AiOperationRunsQuerySchema` deve capturar a condição com mensagem clara.

GET lista (`src/app/api/admin/ai-operation-runs/route.ts`):
- `apiHandler` + `requireAdmin()` (padrão rota ai-costs).
- Query parseada com `AiOperationRunsQuerySchema` → 400 zod `{ error: "Dados inválidos", details }` (inclui janela excedente).
- `new OperationRunsService().listRuns({ ... })` → 200 `{ runs, summary, aggregations, page, total }`.
- `OperationRunsUnavailableError` → 503 `{ error: "operation_runs_unavailable" }`.
- **Segmento:** quando `segment` presente, o service classifica cada run e filtra ANTES de paginar — o `total` e a página refletem o conjunto segmento-filtrado (nunca o RPC paginado sem o filtro). Implementação: service requisita o conjunto base completo (page_size coberto do período) e aplica classificação + filtro + paginação + total no service.
- **summary/aggregations** derivados no service sobre o conjunto filtrado inteiro (nunca sobre a página) — a UI não recalcula KPIs.
- `aggregations` shape (D3/D9): `bySegment`, `byDeliveryType`, `byStage`, `byProviderModel`, `byStatus`, `byStore`, `byOwner` (stores.user_id), `byHour`.

GET detalhe (`src/app/api/admin/ai-operation-runs/[operationRunId]/route.ts`):
- `apiHandler` + `requireAdmin()`.
- `operationRunId` validado como uuid → 400 zod `{ error: "Dados inválidos" }` se inválido.
- `new OperationRunsService().getRunDetail(operationRunId)` → 200 `{ run, events }` — events com `estimatedCostBrl`, `textComponentUsd`, `imageToolComponentUsd`, `badges`.
- 503 fail-closed.

Padrão de teste (analog: `src/app/api/admin/ai-costs/__tests__/route.test.ts`): mock requireAdmin + mock do service (vi.mock) + fetch ao handler.

RPC `admin_update_operation_cost` (D8 — assinatura exata):
```
(p_actor_id UUID, p_operation_key TEXT, p_cost_credits INTEGER DEFAULT NULL,
 p_enabled BOOLEAN DEFAULT NULL, p_reason TEXT DEFAULT NULL, p_operation_id UUID DEFAULT NULL)
RETURNS JSONB  -- { operation_key, cost_credits, enabled, audit_id, updated_at, idempotent }
```
- `LANGUAGE plpgsql SECURITY DEFINER SET search_path = ''`

- Idempotência: se p_operation_id repetido → retorna audit existente com `idempotent: true` (sem novo UPDATE)
- Transação única: UPDATE na tabela de custos + INSERT na audit na mesma transação (rollback em falha)
- Actor: `updated_by = p_actor_id` no UPDATE; `actor_id = p_actor_id` na audit
- Grants: `REVOKE EXECUTE ... FROM PUBLIC, anon, authenticated;` + `GRANT EXECUTE ... TO service_role;`

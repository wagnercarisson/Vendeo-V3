```typescript
export const DEFAULT_OPERATION_COSTS: Record<OperationKey, { costCredits: number; enabled: boolean }> = {
  campaign_generation:         { costCredits: 1, enabled: true },
  visual_signature_generation: { costCredits: 1, enabled: true },
};

export class OperationCostUnavailableError extends Error {
  constructor(public readonly operationKey?: OperationKey, message?: string) {
    super(message ?? (operationKey ? `Falha ao ler custo de operação: ${operationKey}` : "Falha ao ler custos de operação"));
    this.name = "OperationCostUnavailableError";
  }
}

export class OperationCostService {
  constructor(private readonly client: SupabaseClient = supabaseAdmin) {}
  async getCost(operationKey: OperationKey): Promise<OperationCostResolution>;
}
```

Contrato de resolução `getCost(key)` (D5):
- `SELECT cost_credits, enabled FROM public.credit_operation_costs WHERE operation_key = $key` via `this.client.from("credit_operation_costs").select("cost_credits, enabled").eq("operation_key", operationKey).maybeSingle()`
- Linha inexistente (data === null, error null — banco saudável): retorna `{ operationKey, ...DEFAULT_OPERATION_COSTS[key], source: "fallback" }` + `console.warn` (aviso)
- Linha existente: `{ operationKey, costCredits: data.cost_credits, enabled: data.enabled, source: "table" }`
- Erro real (error !== null): `console.error` + `throw new OperationCostUnavailableError(...)` — NUNCA retorna fallback em erro de leitura (D5: não sabe se a operação foi desligada)
- Operação com `enabled=false`: retorna a resolução com `enabled: false` — a decisão 503 é da rota (D4)

Padrão de classe/estilo (analog): `src/lib/credit/credit-service.ts` (constructor com default `supabaseAdmin`, query builder do supabase, propagação de erro). Erro custom: padrão `src/lib/auth/errors.ts`.

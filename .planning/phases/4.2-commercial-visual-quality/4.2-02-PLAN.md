       If the script is not available or fails, fall back to `python .opencode/skills/ui-ux-pro-max/scripts/search.py ...`

    3. **Supplement with detailed searches for specific zones**:
       These help inform specific layout decisions:
       ```
       python3 .opencode/skills/ui-ux-pro-max/scripts/search.py "product image price hero hierarchy" --domain ux
       python3 .opencode/skills/ui-ux-pro-max/scripts/search.py "call-to-action button pill campaign integrated" --domain style
       python3 .opencode/skills/ui-ux-pro-max/scripts/search.py "store brand identity professional subtle" --domain ux
       ```

    4. **Create the art direction contract** at `openspec/design-system/CAMPAIGN_ART_DIRECTION.md`.
       The document MUST be well-structured Markdown with the following required sections, each containing specific, actionable specifications (not vague statements):

       **A. Template Identity**
       - Template name: `produto-oferta-comercial`
       - Canvas: 1080×1080px, 1:1 aspect ratio
       - Safe margins: 40px outer, 60px text safe zone

       **B. Zone Layout & Hierarchy**
       - ASCII art diagram of the complete composition showing ALL zones
       - Zone distribution: top-to-bottom vertical layout with approximate % heights
       - Clear hierarchy: product image as primary anchor, discounted price as most prominent text, hook as secondary highlight, CTA as campaign element, store identity discreet
       - Specific zone proportions (not ranges): each zone must have a defined % value

       **C. Product Image Zone**
       - Position and dimensions (specific % of canvas height)
       - Treatment: object-fit behavior (contain vs cover), shadow intensity, vignette/overlay specification
       - Fallback: explicit error state for missing image (not a placeholder, not publishable)

       **D. Price Block**
       - Position within layout (below product name)
       - Discounted price as visual hero: font size (larger than current 52px if appropriate), color, weight
       - Original price: strikethrough style, position relative to discounted price
       - Background accent or pill for the price if applicable

       **E. Hook / Benefício**
       - Position in composition (above or below product name)
       - Visual weight relative to other elements: font size, color, style (italic/regular)
       - Empty hook behavior: zone hides, elements adjust without empty space

       **F. CTA as Campaign Element**
       - Visual treatment: pill shape, font, size, color (accent color), shadow
       - Position within layout (bottom third, not at very bottom — store identity is lowest)
       - Non-interactive: NOT a button, NOT form element, pure visual pill
       - Empty CTA fallback: "Aproveite Agora!"

       **G. Store Identity**
       - Position: bottom of composition, integrated not floating
       - Logo treatment: circular, max 40×40px, above store name
       - Initials fallback: circular with brand/accent color, same size
       - Store name: font, size, color, single line truncation

       **H. Background Treatment**
       - Per segment: specific visual treatment for each segment palette
       - Gradients, overlays, or textures per segment (not just solid color)
       - Fallback for unknown segment: white + subtle treatment

       **I. Fallback Rules**
       Table of what happens when each data field is missing:
       | Missing Data | Behavior |
       |---|---|
       | productImageUrl | Error state, not publishable |
       | logoUrl | Initials fallback, brand/accent color |
       | brandColor | → segment palette accent → #22C55E |
       | original_price_display | Only discounted price (larger) |
       | badge_text | No badge, no empty space |
       | subtitle | Zone hidden, CTA shifts up |
       | cta | "Aproveite Agora!" |
       | hook | Hook zone hidden, elements adjust |

       **J. Anti-Patterns (DO NOTs)**
       - List 5-8 specific visual mistakes to avoid
       - Examples: no stacked layout, no disabled button element, no solid-only background, no text over image without overlay, no distorted product image

       **K. Reference Composition Description**
       - Detailed prose description of the ideal visual: what the rendered campaign looks like
       - Covers the visual reading order: eye starts at product image → moves to price → hook → CTA → store

    5. **Incorporate the design system output**: Use the palette, typography, and style recommendations from the UI/UX Pro Max search. If there are conflicts between the search output and existing `CAMPAIGN_VISUAL_SYSTEM.md` or `SEGMENT_PALETTES`, document both options and let user decide.

    6. **Cross-reference existing code constraints**:
       - `resolveCampaignBackgroundColor()` in types.ts uses `SEGMENT_PALETTES`
       - `resolveCampaignAccentColor()` resolves palette_accent → segment → brandColor → #22C55E
       - The renderer is a pure React component with no side effects
       - Container: `w-full max-w-[1080px] aspect-[1/1]`
       - All text uses Poppins (headings) and Open Sans (body) from `CAMPAIGN_VISUAL_SYSTEM.md`

    7. Document the output as `openspec/design-system/CAMPAIGN_ART_DIRECTION.md`.

    **Critical**: Do NOT write any code. Do NOT modify campaign-renderer.tsx. This is a design-only task.

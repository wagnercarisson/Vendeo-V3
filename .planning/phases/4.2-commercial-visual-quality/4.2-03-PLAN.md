       - Position: top of canvas, occupying the zone height defined in the 4.2.0 contract

       - When `productImageUrl` is null: render an explicit error state — a centered `<ImageOff>` icon with "Imagem do produto indisponível" text on a gray background. This MUST look like an error, NOT like a placeholder for publishable art.
       - No gradient overlay at the image→text transition unless specified in the 4.2.0 contract.

    4. **Badge** (if `spec.offer.badge_text` is non-empty):
       - Position: top-right corner, same margin as current (top-6 right-6)
       - Styling: `rounded-full`, white text, `accentColor` background, Poppins 700, font size per 4.2.0 contract
       - If badge is empty/null: render nothing, no empty space

    5. **Hook Zone** (NEW — from `spec.commercial_copy.hook`):
       - Position and styling per 4.2.0 contract (e.g., italic/secondary color, positioned between image and product name)
       - Only render if `hook` is non-empty
       - If empty: render nothing, elements below shift up naturally

    6. **Product Name Zone** (`spec.offer.product_name`):
       - Font: Poppins 700, color `#1E293B`, center-aligned
       - Font size: 42px base, 36px if name > 40 chars
       - Max 2 lines with `line-clamp-2 overflow-hidden text-ellipsis`
       - Position per 4.2.0 contract

    7. **Price Block**:
       - Original price (if non-null): strikethrough text, `text-slate-400`, font size per 4.2.0 contract, centered above discounted price
       - Discounted price: rendered as hero element — most prominent text in composition
         - Font: Poppins 700, color: `accentColor`, font size per 4.2.0 contract (largest text on canvas)
         - If `original_price_display` is null: the price can be larger (per the Phase 4.1 logic, keep this but update sizes per 4.2.0)
       - Consider adding a subtle background accent behind the price if specified in 4.2.0 contract (e.g., translucent pill or underline)

    8. **Description Zone** (`spec.commercial_copy.subtitle`):
       - Only render if non-empty
       - Font: Open Sans 400, color `#475569`, center-aligned
       - Max 2 lines
       - If empty: zone hidden, CTA shifts up

    9. **CTA as Campaign Element**:
       - Render as a visual pill element — NOT as a `<button>` element, NOT with `disabled` attribute
       - Use a `<div>` or `<span>` with pill styling: `rounded-full`, background `accentColor`, white text, Poppins 700
       - No `disabled`, no `cursor-pointer`, no interactive styling — this is a display element
       - Style: per 4.2.0 contract (size, shadow, position)
       - Text: `spec.commercial_copy.cta` || "Aproveite Agora!"
       - Max width: 70% of container width

          - Text: `getStoreInitials(storeIdentity.storeName)`, white, Poppins 600, centered
        - Store name: below logo/initials, Open Sans 500, `text-slate-500`, single line truncation
        - The store identity MUST look professional and integrated into the composition

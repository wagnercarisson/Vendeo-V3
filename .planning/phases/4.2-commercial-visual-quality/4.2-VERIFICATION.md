## WARNING Issues

### 1. Background treatment simplified (W-01)

**Source:** Spec `commercial-campaign-template/spec.md` — Requirement: "Background with visual treatment"

The spec requires "visual treatment beyond a solid color — such as subtle gradient, radial overlay, or texture." The current implementation uses solid segment colors (`resolveCampaignBackgroundColor()`) without additional visual treatment.

**Rationale:** The 4.2.0 contrato originalmente previa gradiente/overlay, mas foi revisado para "solid color per segment" durante as revisões do contrato. O usuário aprovou essa direção.

**Recommendation:** Defer background visual treatment to Phase 4.3 alongside the broader composition revision. Current solid-color approach is accepted.

### 2. Description/subtitle zone omitted (W-02)

**Source:** Spec `campaign-visual-renderer/spec.md` — Requirement: "Description zone: behavior unchanged"

The spec says description zone behavior is "unchanged from Phase 4.1." However, the 4.2.0 contract explicitly states description/subtitle is NOT rendered in `produto-oferta-comercial`. Hook replaces description as the primary persuasive text.

**Action taken:** Document revised in contract §A to explicitly state: "Description/subtitle NOT rendered in `produto-oferta-comercial`. The hook/benefício is the primary persuasive text below the price."

**Assessment:** Correct divergence — the spec delta had inconsistent language (unchanged behavior vs new contract). The user approved the contract knowing description was omitted.

---

## SUGGESTION Issues

### 1. Character counter introduces pattern deviation (S-01)

The hook and CTA fields in the adjustments panel include character counters (`{(adjustments.hook ?? originalSpec.commercial_copy.hook).length}/120`). This is a **new UI pattern** — existing fields (title, price, badge) do not have character counters.

**Recommendation:** Consider adding character counters to existing fields for consistency, or document the character counter as a pattern for content-length-sensitive fields only (hook/CTA) vs. display fields (title/price).

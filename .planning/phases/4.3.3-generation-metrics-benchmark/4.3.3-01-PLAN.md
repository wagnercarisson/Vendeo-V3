### 1.5 Implement MetricsWriter

<read_first>
- src/lib/image-generation/metrics/types.ts
</read_first>

<action>
Create `src/lib/image-generation/metrics/writer.ts` with `MetricsWriter` class:
- Constructor takes `metricsDir: string` (default `"metrics"`)
- `write(metrics: GenerationMetrics): Promise<void>` — best-effort, wraps in try/catch
- Uses `fs.promises.appendFile` to append JSON line + `\n`
- Falls back to `console.log` with structured JSON when filesystem write fails
- Creates `metricsDir` if it doesn't exist (try/catch)
- NEVER throws — all errors are caught and logged via `console.error`
- In production (`NODE_ENV === "production"`), skip filesystem write by default; if `METRICS_ENABLED=true`, write to stdout
</action>

<acceptance_criteria>
- `MetricsWriter.write()` never throws or rejects
- JSONL file created in `metrics/` directory
- Each line is valid JSON followed by `\n`
- Production defaults to no-op unless `METRICS_ENABLED=true`
- Failure (permission, disk, etc.) logs error and continues
</acceptance_criteria>

## Decisions Made

- **Factory pattern over registry**: Simple switch/if-else in factory.ts avoids plugin system overhead and circular imports with config.ts
- **JSONL over database**: Metrics are best-effort, local-only, unstructured. JSONL is append-only and requires no schema migrations
- **Production no-op by default**: Metrics are for development/benchmarking. Production must opt in via METRICS_ENABLED=true
- **Metrics at every phase boundary**: Both phase start (running) and phase end (complete/failed) events are emitted for full timing coverage
- **Metrics written at all completion points**: Success, review_failed, review_error, generated_product_mismatch, and provider_error all write metrics

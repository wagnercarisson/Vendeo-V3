## Objective

Separate technical metrics from user-facing progress: human-friendly messages in the UI, rotating professional copy, optional "Ver etapas da geração" panel. Refine validation/review alignment rules and adjust prompts for creative freedom boundaries and commercial repertoire guidance.

<action>
Add `creativeContextGuidance` variable in `buildPromptVariables()`. Implement a simple mapping that considers:

- `inferredCategory` (from validation, fallback to storeSegment)
- Whether there's a category conflict (`hasCategoryConflict`)

Examples:
- `"alimentacao-bebidas"` + `"energetico"` (aligned) → `"Valorize energia e disposição. Preço é oportunidade."`
- `"variedades"` + `"eletronicos"` (conflict) → `"Equilibre varejo popular com desejo por tecnologia."`
- `"moda-vestuario"` + `"calcados-esportivos"` (aligned) → `"Valorize estilo e performance. Preço é investimento."`

Keep mapping simple (if-else or object lookup). Default to empty string when no guidance applies.
</action>

<acceptance_criteria>

- Value considers segment, category, and conflict status
- Defaults to empty string when no specific guidance exists
</acceptance_criteria>

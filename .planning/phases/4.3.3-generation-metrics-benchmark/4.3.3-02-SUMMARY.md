## Decisions Made

- **Two-layer progress architecture**: `onPhaseChange.message` carries human-friendly PT-BR text; `onMetricsEvent` carries technical data (provider, model, runId, cost, attempts). UI only renders message field.
- **Random message selection**: Messages are picked via `Math.random()` on each `emitHuman()` call, providing natural rotation without state tracking.
- **Detail guarded by DEBUG**: The `IMAGE_GENERATION_DEBUG` flag gates technical detail emission to `onPhaseChange` — preserves debug capability while keeping production UI clean.
- **Keyword-based creative guidance**: The `buildCreativeContextGuidance` method uses simple `includes()` matching on segment/category strings rather than an external data source or ML — keeps it lightweight, deterministic, and easy to extend.

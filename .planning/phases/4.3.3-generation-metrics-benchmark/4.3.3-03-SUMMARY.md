## Decisions Made

- Used dynamic imports in `benchmark.ts` to set `process.env.IMAGE_GENERATION_RESPONSES_MODEL` before the config module evaluates its constants, enabling genuine model override via `--model` flag
- Used separate JSONL file pattern `benchmark-{timestamp}.jsonl` (instead of the existing `generation-{date}.jsonl` from MetricsWriter) to clearly distinguish benchmark runs from production generation metrics
- Placeholder 1x1 transparent PNG base64 fallback when fixture images don't exist — allows testing the pipeline end-to-end without requiring fixture images
- Fail-fast for invalid `--provider` (unlike the production factory which falls back to OpenAI with a warning) — benchmark should catch misconfiguration immediately

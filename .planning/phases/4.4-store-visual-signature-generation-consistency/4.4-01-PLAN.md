<action>
Create `src/lib/visual-signature/persistence.ts` with:

1. **`uploadToStorage(params)`** — accepts `{ storeId: string; buffer: Buffer; mimeType: 'image/png' | 'image/svg+xml'; fileName?: string }`. Validates storeId as UUID via `/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i`. Generates UUID fileName if omitted. Ext determines file extension: `png` for `image/png`, `svg` for `image/svg+xml`. Uploads to `supabaseAdmin.storage.from('visual-signatures')` at path `{storeId}/{uuid}.{ext}` with upsert:true. Resolves public URL via `.getPublicUrl(storagePath)`. Returns `{ storagePath, assetUrl }`. Throws on error with Supabase error message.

2. **`persistSignature(input)`** — accepts `CreateVisualSignatureInput`. Inserts via `supabaseAdmin.from('store_visual_signatures').insert(input).select().single()`. Returns the created `VisualSignatureRecord`. Throws on error.

3. **`getActiveVisualSignature(storeId)`** — accepts string. Queries `supabaseAdmin.from('store_visual_signatures').select('*').eq('store_id', storeId).eq('status', 'active').maybeSingle()`. Returns `VisualSignatureRecord | null`. Throws on error.

Import `supabaseAdmin as supabase` from `@/lib/supabase`. Import types from `./types`. Export all three functions.
</action>

<action>
Create `src/lib/visual-signature/typographic-fallback.ts` with:

**`TypographicFallbackGenerator` class:**

Constructor takes no arguments.

**`generate(params: { storeId: string; storeName: string; brandColor?: string | null; segment?: string }): Promise<CascadeResult>`:**

1. Extract initials using a local `getStoreInitials()` function: split name by whitespace, take first letter of first two words (uppercase). If only one word, take first two characters (uppercase).

2. Determine brand color: use `params.brandColor` if provided, else use `SEGMENT_COLOR_FALLBACK[params.segment ?? 'outros']` (import from `@/lib/store`). Fallback to `'#22C55E'` if neither available.

3. Build SVG string using a template literal:
   - ViewBox: `0 0 400 200`
   - Outer circle at center (200, 80), radius 60, filled with brand color
   - Initials text centered horizontally (x=200, y=95), white (#FFFFFF), sans-serif, font-weight 700, font-size 48px, text-anchor middle
   - Store name text at (200, 160), brand color, sans-serif, font-weight 500, font-size 20px, text-anchor middle
   - Include XML namespace: `xmlns="http://www.w3.org/2000/svg"`

4. Convert SVG string to Buffer: `Buffer.from(svgString, 'utf-8')`

5. Call `uploadToStorage({ storeId, buffer, mimeType: 'image/svg+xml' })`.

6. Build `VisualSignatureMetadata` with `generation_tier: 'typographic'`.

7. Call `persistSignature()` with:
   - `store_id`: params.storeId
   - `storage_path`: result from uploadToStorage
   - `asset_url`: result from uploadToStorage
   - `type`: `'fallback_typographic'`
   - `status`: `'active'` (per D-11: fallback nasce como active direto)
   - `generation_mode`: `'fallback'`
   - `prompt`: null
   - `metadata`: `{ generation_tier: 'typographic' }`

8. Return `{ tier: 'typographic', assetUrl, storagePath, mimeType: 'image/svg+xml' }`.

9. Wrap in try/catch — this is the last resort; if anything fails, throw with descriptive message.

Import types from `./types`. Import persistence functions from `./persistence`. Import `SEGMENT_COLOR_FALLBACK` from `@/lib/store`.

Export both `TypographicFallbackGenerator` class and the standalone `getStoreInitials` function (re-exported for use by other modules like the campaign renderer).
</action>

<action>
Create `src/app/api/stores/[storeId]/logo/route.ts` (note: `stores` not `store` — create the directory `src/app/api/stores/[storeId]/logo/` if needed).

Export async `POST(request: NextRequest, { params }: { params: Promise<{ storeId: string }> })`:

1. Extract `storeId` from `(await params).storeId`
2. Validate storeId as UUID format (regex `/^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i`). Return 400 if invalid.
3. Parse the multipart form data: `const formData = await request.formData(); const file = formData.get('logo') as File | null;`
4. Return 400 if no file uploaded: `{ error: "Nenhum arquivo enviado" }`
5. Validate MIME type: only `image/png`, `image/jpeg`, `image/webp` allowed. Return 400 if invalid type: `{ error: "Formato de arquivo inválido. Use PNG, JPEG ou WebP." }`
6. Validate file size: max 2MB (2097152 bytes). Return 400 if oversized: `{ error: "Arquivo muito grande. Máximo 2MB." }`
7. Generate unique filename: `crypto.randomUUID()` + extension from MIME type (.png, .jpg, .webp)
8. Convert file to Buffer: `Buffer.from(await file.arrayBuffer())`
9. Upload to `supabaseAdmin.storage.from('store-logos').upload(path, buffer, { contentType: file.type, upsert: true })` where path is `{storeId}/{uuid}.{ext}`
10. If upload fails, return 500 with Supabase error message
11. Resolve public URL: `supabaseAdmin.storage.from('store-logos').getPublicUrl(path)`
12. Update `stores` table: `supabaseAdmin.from('stores').update({ logo_url: publicUrl, updated_at: new Date().toISOString() }).eq('id', storeId).select().single()`
13. If store update fails, return 500
14. Return 200 with the updated store data

Import `NextRequest, NextResponse` from `next/server`. Import `supabaseAdmin as supabase` from `@/lib/supabase`.
</action>

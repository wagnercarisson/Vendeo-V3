<action>
Create `src/lib/visual-signature/ai-image-generator.ts` with:

**`VisualSignatureValidator` class** (exported):

1. **`validate(params: { imageBase64: string; storeName: string }): Promise<{ valid: boolean; reason?: string }>`**:
   - Check 1: Verifies the base64 string is non-empty and decodes to a valid buffer (>100 bytes)
   - Check 2: Check if the image appears generic (basic heuristic — check if image is extremely small or appears like a simple circle — this is a V1 heuristic, not computer vision)
   - For V1, validation is basic: ensure image has content, is a valid PNG, and is above minimum dimensions
   - Returns `{ valid: true }` or `{ valid: false, reason: "..." }`
   - The strict visual quality evaluation (looks like real brand mark, no pricing, etc.) is handled by the manual quality gate (Plan 4.4-09)

**`AiImageGenerator` class** (exported):

Constructor accepts optional `{ promptLoader?: PromptLoader }`. Defaults to `new PromptLoader()` if not provided.

1. **`generate(params: { storeId: string; storeName: string; segment: string; brandColor: string; tone: string; signal?: AbortSignal; attempt?: number }): Promise<CascadeResult>`**:

   a. **Load prompt** via `this.promptLoader.load('visual-signature-generator', { storeName: params.storeName, segment: params.segment, brandColor: params.brandColor, tone: params.tone })`

   b. **Dynamic import OpenAI**: `const { default: OpenAI } = await import('openai')` (same pattern as OpenAIImageProvider)

   c. **Instantiate OpenAI client**: `new OpenAI({ apiKey: process.env.OPENAI_API_KEY })`

   d. **Call Responses API** with `image_generation` tool:
      ```typescript
      const response = await openai.responses.create({
        model: process.env.IMAGE_GENERATION_RESPONSES_MODEL || 'gpt-5.5',
        input: [{ role: 'user', content: [{ type: 'input_text', text: prompt }] }],
        tools: [{ type: 'image_generation' as const, size: '1024x1024', quality: 'auto' as const }],
      }, { signal: params.signal });
      ```

   e. **Extract image output**: find `item.type === 'image_generation_call'` and get its `result` (base64 string)

   f. **Validate**: call `VisualSignatureValidator.validate({ imageBase64, storeName: params.storeName })`. If validation fails, throw with descriptive message.

   g. **Convert base64 to Buffer**: `Buffer.from(imageBase64, 'base64')`

   h. **Upload to Storage**: call `uploadToStorage({ storeId: params.storeId, buffer, mimeType: 'image/png' })`

   i. **Determine tier**: if `params.attempt` is 0 or undefined, tier is `'image_direct'`. If >= 1, tier is `'image_retry'`.

   j. **Persist**: call `persistSignature()` with:
      - `store_id`: params.storeId
      - `storage_path`: from uploadToStorage result
      - `asset_url`: from uploadToStorage result
      - `type`: `'ai_generated'` (if image_direct) or `'automatic_generated'` (if image_retry with no user choice context)
      - `status`: `'draft'` (variations for user choice will be activated later)
      - `generation_mode`: `'user_choice'` (if user-initiated) or `'automatic'` (if automatic)
      - `prompt`: the loaded prompt string
      - `metadata`: `{ generation_tier, provider: 'openai', model: IMAGE_GENERATION_RESPONSES_MODEL, elapsedMs: Date.now() - startTime }`

   k. Return `{ tier, assetUrl, storagePath, mimeType: 'image/png' }`

   l. Wrap in try/catch. On failure, throw an error with message like `"ai_image_generation_failed: ${error.message}"` so callers can distinguish AI failures from other errors.

Import `PromptLoader` from `@/lib/image-generation/prompt-loader`. Import persistence from `./persistence`. Import types from `./types`.

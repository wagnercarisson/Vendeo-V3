## Decisions Made
- Added `simplifiedPrompt` boolean parameter beyond original plan — when true, uses a simpler inline prompt for retry attempts (avoids prompt file complexity for second try)
- Dynamic import of `openai` SDK (same lazy pattern as OpenAIImageProvider elsewhere in the codebase)
- Generation mode determination: attempt 0 or undefined → `user_choice`/`ai_generated`; attempt >=1 → `automatic`/`automatic_generated`
- All AI-generated signatures created as status `draft` (activation happens later via activateSignature)
- Error prefix `ai_image_generation_failed:` enables structured cascade differentiation in server-actions.ts

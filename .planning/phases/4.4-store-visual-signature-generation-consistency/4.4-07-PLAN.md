<action>
Create `src/components/flow/visual-signature-modal.tsx`:

A client component (`"use client"`) that implements the 4-option modal per D-05.

Props:
```typescript
interface VisualSignatureModalProps {
  storeId: string;
  storeName: string;
  segment: string;
  brandColor: string;
  onClose: () => void;        // Called when modal completes any action
  onLogoUpload: () => void;    // Called when user chooses option 4
}
```

**The modal has NO close button** (per D-05). No X button, no clicking outside to close, no Escape key handler.

The modal renders a dark overlay + centered white card.

**Initial state — 4 option cards:**

Render 4 selectable cards in a 2×2 grid (or vertical stack on mobile), each with:
1. **"Gerar 3 opções para eu escolher"** — icon: Sparkles, subtitle: "Criamos 3 variações para você escolher a que mais combina"
2. **"Deixar o Vendeo escolher por mim"** — icon: Wand, subtitle: "Nosso sistema cria a melhor assinatura para sua loja"
3. **"Tenho logotipo, mas vou enviar depois"** — icon: Image, subtitle: "Criamos uma assinatura temporária — você pode substituir depois pelo logotipo"
4. **"Tenho logotipo e quero enviar agora"** — icon: Upload, subtitle: "Faça upload do logotipo da sua loja"

Clicking a card navigates to the next state within the modal.

**State 1: Options** — the 4 cards above. Clicking any card transitions to the appropriate next state.

**State 2: Generating** — loading spinner + status message ("Gerando assinaturas..." or "Criando assinatura visual..."). Shows the progress of the server action. Has NO cancel button.

**State 3: Picker** (after option 1) — renders the `VisualSignaturePicker` with the 3 variations. User selects one and clicks confirm. On confirm, calls `activateSignature(storeId, signatureId)`. On success, calls `onClose()`.

**State 4: Success** (after options 2/3) — checkmark + message "Assinatura visual criada com sucesso!" + button "Continuar" that calls `onClose()`.

**Option 4** — calls `onLogoUpload()` immediately (modal closes, logo upload flow opens).

**State transitions for options 2 and 3:**
- Call `generateAutomatic(storeId)` from server actions
- Result is automatically persisted as `active`
- Show success state

Implementation details:
- Call `generateVariations(storeId)` for Option 1 (passes store context data)
- Call `generateAutomatic(storeId)` for Options 2 and 3 (same behavior per D-05)
- Use `error` state and show error message with "Tentar novamente" button if generation fails
- All server action calls use `useTransition` or `startTransition` for pending states

Import types from `@/lib/visual-signature/types`. Import server actions from `@/lib/visual-signature/server-actions`. Import `VisualSignaturePicker` from `./visual-signature-picker`.

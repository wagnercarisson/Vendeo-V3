2. **If `storeIdentity.logoUrl` is null AND `storeIdentity.visualSignatureUrl` is provided**: render the visual signature asset as a centered image (width up to 200px, height auto, maintaining aspect ratio). The store name text below is **OMITTED** (per D-09: visual signature already contains store name). This is the key functional change.

3. **If neither logoUrl nor visualSignatureUrl**: render initials circle + store name text (existing fallback — unchanged).

```tsx
{storeIdentity.logoUrl ? (
  <img src={storeIdentity.logoUrl} ... onError={...} />
) : storeIdentity.visualSignatureUrl ? (
  <img
    src={storeIdentity.visualSignatureUrl}
    alt={storeIdentity.storeName}
    className="max-w-[200px] h-auto"
  />
) : (
  // existing initials fallback
)}
```

When visual signature is rendered, do NOT render the `<p>{storeIdentity.storeName}</p>` line below it (per D-09: omit textual name when visual signature contains name).

Add at the top of the file:

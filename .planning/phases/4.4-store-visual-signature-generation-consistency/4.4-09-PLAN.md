- ✅ NO visual artifacts, distortion, or rendering issues
- ✅ Image is a valid PNG (for AI-generated) or valid SVG (for typographic fallback)

**Document the evaluation:**

- Note which generation tier produced it (image_direct, image_retry, typographic)

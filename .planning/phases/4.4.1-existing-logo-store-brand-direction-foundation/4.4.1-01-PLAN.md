Table `public.store_brand_assets`:
- id UUID PRIMARY KEY DEFAULT gen_random_uuid()
- store_id UUID NOT NULL REFERENCES public.stores(id) ON DELETE CASCADE
- asset_type TEXT NOT NULL DEFAULT 'logo'
- variant_type TEXT NOT NULL — values: 'original','normalized','on_light','on_dark','square_safe','horizontal_safe'
- source TEXT NOT NULL — values: 'user_upload','system_generated'
- parent_asset_id UUID REFERENCES public.store_brand_assets(id) (nullable self-FK for variant → original)
- storage_path TEXT (nullable — required when status != 'failed', see CHECK)
- mime_type TEXT NOT NULL
- width INTEGER NOT NULL
- height INTEGER NOT NULL
- size_bytes INTEGER NOT NULL
- checksum TEXT NOT NULL (SHA-256 hex)
- version INTEGER NOT NULL
- status TEXT NOT NULL — values: 'active','archived','failed'
- metadata JSONB DEFAULT '{}'::jsonb
- created_at TIMESTAMPTZ NOT NULL DEFAULT now()
- updated_at TIMESTAMPTZ NOT NULL DEFAULT now()

Constraints:
- CHK: status IN ('active', 'archived', 'failed')
- CHK: variant_type IN ('original', 'normalized', 'on_light', 'on_dark', 'square_safe', 'horizontal_safe')
- CHK: source IN ('user_upload', 'system_generated')
- CHK: asset_type IN ('logo')
- CHK: (status = 'failed' AND storage_path IS NULL) OR (status != 'failed' AND storage_path IS NOT NULL) — storage_path required when active/archived
- Partial unique index: (store_id, asset_type, variant_type) WHERE status = 'active'
- Index: (store_id) for faster lookup
- updated_at trigger: specific function `update_store_brand_assets_updated_at()`, trigger `trg_store_brand_assets_updated_at` BEFORE UPDATE FOR EACH ROW

Use existing pattern from store_visual_signatures migration for trigger function style. Add REVERT comments.

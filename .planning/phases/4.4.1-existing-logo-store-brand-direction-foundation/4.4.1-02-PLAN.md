```typescript
import sharp from 'sharp';

const ALLOWED_MIME_TYPES = ['image/png', 'image/jpeg', 'image/webp'] as const;
const ALLOWED_EXTENSIONS = ['.png', '.jpg', '.jpeg', '.webp'] as const;
const MAX_FILE_SIZE = 5 * 1024 * 1024; // 5MB
const MIN_WIDTH = 200;
const MIN_HEIGHT = 200;

const ON_DARK_BACKGROUND = '#1A1A2E';
const ON_LIGHT_BACKGROUND = '#FFFFFF';
const NORMALIZED_CANVAS_SIZE = 500;
const HORIZONTAL_CANVAS_WIDTH = 800;
const HORIZONTAL_CANVAS_HEIGHT = 300;
```

Export async functions:

- `validateImage(buffer: Buffer): Promise<{ valid: boolean; error?: string; mimeType?: string }>`
  - Try `sharp(buffer).metadata()` to verify integrity (throws on corrupted)
  - Extract format → map to MIME (png→image/png, jpeg→image/jpeg, webp→image/webp)
  - Check format is in allowed list
  - Check buffer.length <= MAX_FILE_SIZE
  - Return `{ valid: true, mimeType }` or `{ valid: false, error: string }`

- `getImageDimensions(buffer: Buffer): Promise<{ width: number; height: number }>`
  - Return `sharp(buffer).metadata()` width and height

- `checkMinimumDimensions(width: number, height: number): { valid: boolean; error?: string }`
  - Width >= MIN_WIDTH AND height >= MIN_HEIGHT

- `computeChecksum(buffer: Buffer): string`
  - Return crypto.createHash('sha256').update(buffer).digest('hex')

- `generateNormalized(buffer: Buffer): Promise<{ buffer: Buffer; width: number; height: number; size_bytes: number }>`
  - sharp(buffer).resize(NORMALIZED_CANVAS_SIZE, NORMALIZED_CANVAS_SIZE, { fit: 'inside', withoutEnlargement: true })
  - .flatten({ background: { r: 0, g: 0, b: 0, alpha: 0 } }) — preserve transparency by using transparent background
  - .png()
  - Return processed buffer + metadata

- `generateOnLight(buffer: Buffer): Promise<...>`
  - First call generateNormalized
  - Then sharp(normalizedBuffer).flatten({ background: ON_LIGHT_BACKGROUND }).png()
  - Return buffer + metadata

- `generateOnDark(buffer: Buffer): Promise<...>`
  - First call generateNormalized
  - Then sharp(normalizedBuffer).flatten({ background: ON_DARK_BACKGROUND }).png()
  - Return buffer + metadata

- `generateSquareSafe(buffer: Buffer): Promise<...>`
  - First call generateNormalized
  - Then sharp(normalizedBuffer).resize(NORMALIZED_CANVAS_SIZE, NORMALIZED_CANVAS_SIZE, { fit: 'contain', background: { r: 0, g: 0, b: 0, alpha: 0 } }).png()
  - Return buffer + metadata

- `generateHorizontalSafe(buffer: Buffer): Promise<...>`
  - Normalized then .resize(HORIZONTAL_CANVAS_WIDTH, HORIZONTAL_CANVAS_HEIGHT, { fit: 'contain', background: { r: 0, g: 0, b: 0, alpha: 0 } }).png()
  - Return buffer + metadata

- `generateAllVariants(buffer: Buffer): Promise<VariantGenerationResult[]>`
  - Call all 5 variant generators in parallel with Promise.allSettled
  - Map results to VariantGenerationResult array (success: true/false for each)
  - Do NOT include original variant (it's the validated input buffer stored as-is)

Each function catches sharp errors and returns a rejected promise with descriptive message. Include `import crypto from 'node:crypto'` for checksum.

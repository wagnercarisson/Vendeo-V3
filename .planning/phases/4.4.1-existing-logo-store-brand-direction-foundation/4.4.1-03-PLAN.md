<objective>
Implement the Store Brand Director AI analysis engine (LLM with vision for logo analysis), extend the existing store PATCH API for new direction fields, and create the Brand Profile API for managing AI-inferred brand identity.

**Purpose:** The Brand Director turns an uploaded logo + store data into a structured brand profile (colors, style, tone, personality, guidelines). The Store API extension allows lojistas to provide marketing direction. The Brand Profile API allows reading, regenerating, updating colors, and archiving profiles.

**Output:** Brand Director AI service, extended store PATCH handler, Brand Profile API route
</objective>

export async function GET(request: NextRequest, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const { data, error } = await supabase

  if (error) return NextResponse.json({ error: error.message }, { status: 500 });

}

**PATCH** (for `/brand-profile/colors`) — Update brand_colors_chosen in-place:
```typescript
export async function PATCH(request: NextRequest, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const body = await request.json();
  const { colors } = body;
  if (!Array.isArray(colors) || colors.some((c: unknown) => typeof c !== 'string' || !/^#[0-9A-Fa-f]{6}$/.test(c as string))) {
    return NextResponse.json({ error: 'colors deve ser um array de hex colors (#RRGGBB)' }, { status: 400 });
  }
  // Update the active synced profile's brand_colors_chosen
  const { data: existing } = await supabase
    .from('store_brand_profiles')
    .select('id')
    .eq('store_id', id)
    .eq('status', 'synced')
    .single();
  if (!existing) return NextResponse.json({ error: 'Nenhum perfil ativo encontrado' }, { status: 404 });
  const { data, error } = await supabase
    .from('store_brand_profiles')
    .update({ brand_colors_chosen: colors, updated_at: new Date().toISOString() })
    .eq('id', existing.id)
    .select()
    .single();
  if (error) return NextResponse.json({ error: error.message }, { status: 500 });
  return NextResponse.json(data, { status: 200 });
}
```

For `POST /api/store/[id]/brand-profile` (generate):
1. Validate storeId as UUID
2. Fetch store data (name, segment, city, state, new fields) for context
3. Fetch active logo asset (original variant) to get storage_path
4. If original asset exists, download its buffer from storage
5. Create BrandDirectorService, call analyze() with logo buffer + store data
6. Archive previous synced profile: set status='outdated'
7. Insert new brand profile with status='synced'
8. Return created profile

For `POST /api/store/[id]/brand-profile` with `action === 'archive'`:
1. Find active synced profile
2. Set its status to 'archived'
3. Return updated profile

Use a single POST handler that inspects the action:
```typescript
export async function POST(request: NextRequest, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const url = new URL(request.url);
  const path = url.pathname;
  
  if (path.endsWith('/generate')) {
    return handleGenerate(request, id);
  }
  if (path.endsWith('/archive')) {
    return handleArchive(request, id);
  }
  return NextResponse.json({ error: 'Ação não reconhecida' }, { status: 400 });
}
```

For `handleGenerate`:
- Fetch store data from `stores` table
- Fetch active logo original asset from `store_brand_assets` WHERE store_id=id AND variant_type='original' AND status='active'.single()
- If logo asset found: download from storage bucket `store-brand-assets` with supabaseAdmin.storage.from('store-brand-assets').download(asset.storage_path)
- Create BrandDirectorService, call analyze with buffer + store data
- Archive old profile: `UPDATE store_brand_profiles SET status='outdated' WHERE store_id=id AND status='synced'`
- Insert new profile with status='synced'
- Handle AI errors gracefully: if analyze throws BrandDirectorAnalysisError, create profile with status='failed' and error metadata
- Return 201 with profile

For `handleArchive`:
- `UPDATE store_brand_profiles SET status='archived', updated_at=NOW() WHERE store_id=id AND status='synced'`
- Return the updated profile

Error handling: all catch blocks return `{ error: 'message' }` with appropriate HTTP status.

## Key Details

- BrandDirectorService uses OpenAI chat.completions with vision, `json_object` response format
- Dev fallback when OPENAI_API_KEY not set (non-production): returns mock BrandDirectorResult
- Error handling: BrandDirectorAnalysisError with structured metadata
- Profile lifecycle: synced (success) or failed (AI error) — no processing state in V1
- PATCH colors validates hex format: `/^#[0-9A-Fa-f]{6}$/`
- POST generate archives old profile → inserts new one
- POST archive sets status to 'archived'

## POST /api/store/[id]/logo

Validation chain:
1. Extension check (PNG/JPG/WEBP only) → 400 "Formatos aceitos: PNG, JPG ou WEBP."
2. File size check (5MB max) → 400 "Arquivo muito grande. Máximo 5MB."
3. Server-side sharp validation (MIME, integrity) → 400 on failure
4. Minimum dimensions (200x200) → 400 on failure

Processing:
- Archive previous active assets + outdated previous profile (atomic)
- Upload original to storage at `{store_id}/original/{uuid}.ext`
- Generate 5 variants (normalized, on_light, on_dark, square_safe, horizontal_safe)
- Each variant: upload to storage, create asset record (active) or failed record
- Run Brand Director analysis inline, create synced or failed profile
- Return 201 with originalAsset, variants[], profile, version

<action>
Create `prompts/store-identity-art-director.md` with the following structure:

1. **Role definition** — exclusively creates visual signatures for stores without logo. Never generates campaigns, CTAs, products, or offers.

2. **Template variables:**
   - `{{storeName}}`, `{{segment}}`, `{{subsegment}}`, `{{tone_of_voice}}`
   - `{{positioning}}`, `{{short_description}}`, `{{slogan}}`, `{{city}}`, `{{state}}`
   - `{{brandColor}}` — store's chosen brand color
   - `{{rejectionContext}}` — optional, only present when regenerating after rejection

3. **When rejectionContext is present:**
   - Include the rejection reason from the lojista
   - Include: "A versão anterior foi rejeitada. Busque uma direção criativa completamente diferente — não apenas uma variação pequena da anterior."
   - If no specific feedback: "A versão anterior foi rejeitada sem feedback específico. Busque uma direção criativa completamente diferente."

4. **Output format instructions:**
   - Generate a PNG visual signature: professional brand mark, store name as main prominent element, clean typography, transparent or simple solid background, optionally include a symbol or icon related to the segment
   - Generate a reference card PNG: signature on neutral background showing brand identity in context (helps Campaign Director interpret identity)
   - Output structured JSON metadata with: creative_description, suggested_colors (array of hex), visual_direction (e.g., "Moderna e minimalista"), elements_used (array)

5. **Quality criteria:**
   - NOT pricing, products, offers, CTAs, or promotional copy
   - NOT generic "initials in circle" design
   - NOT campaign art (scenes, product images, decorative elements)
   - Professional and publishable quality
   - Use brandColor as accent color
   - Clean, readable typography

6. **Three tonalities** to guide style based on store tone_of_voice:
   - profissional (clean/corporate) — if tone_of_voice is "profissional" or unset
   - moderno (trendy/contemporary) — if tone_of_voice is "moderno" or "jovem"
   - elegante (sophisticated/premium) — if tone_of_voice is "elegante" or "sofisticado"

7. **Language:** Entire prompt in Brazilian Portuguese (PT-BR)

8. **Important admonitions:**
   - Do NOT mix roles with campaign generation
   - Do NOT generate campaign art — this is a store identity asset
   - The generated asset will be reused across all campaigns for this store
</action>

<action>
Create `prompts/store-brand-profiler.md` with the following structure:

1. **Role definition** — infers a complete brand profile for stores without a logo. Executes AFTER the visual signature is approved by the lojista. Never creates visual signatures. Never generates campaigns.

2. **Template variables — store cadastral data:**
   - `{{storeName}}`, `{{segment}}`, `{{subsegment}}`, `{{tone_of_voice}}`
   - `{{positioning}}`, `{{short_description}}`, `{{slogan}}`, `{{city}}`, `{{state}}`

3. **Template variables — art director approved outputs:**
   - `{{creativeDescription}}` — textual direction of the approved signature
   - `{{suggestedColors}}` — hex colors suggested by the art director
   - `{{visualDirection}}` — e.g., "Moderna e minimalista"
   - `{{elementsUsed}}` — design elements used in the signature

4. **Processing instructions:**
   - Primary input is the creative metadata from the art director (description, colors, direction, elements)
   - The approved visual signature asset URL and reference card URL are available for visual reference but heavy image analysis is NOT required
   - Infer brand identity from the combination of store data + creative direction
   - Do NOT ignore the approved visual signature — use the creative metadata as primary source

5. **Output format** — structured JSON (same format as store-brand-director-with-logo):
   - `logo_colors_detected`: array (populated from suggested_colors since no real logo exists)
   - `safe_color_tokens`: object with primary, secondary, accent, background hex values
   - `visual_style`: text description of visual style
   - `visual_tone`: text description of visual tone
   - `typography_direction`: text description
   - `brand_personality`: text description of brand personality
   - `campaign_guidelines`: creative guidelines for campaign generation
   - `campaign_brief`: concise brief for the campaign director
   - `inferred_primary_color`: hex — AI's best guess for primary brand color based on visual signature
   - `inferred_accent_color`: hex — AI's best guess for accent color
   - `confidence_score`: float 0-1

6. **Language:** Entire prompt in Brazilian Portuguese (PT-BR)

7. **Important admonitions:**
   - NOT to create visual signatures (that's the Identity Art Director's role)
   - NOT to generate campaign art
   - Brand profile is consumed as directional context by the Campaign Director — it guides, not mandates
   - Missing reference card should NOT block or reduce quality of the profile
</action>

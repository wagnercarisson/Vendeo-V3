## Key Architecture

### StoreIdentityArtDirectorService
- Delegates image generation to `AiImageGenerator` (reuses existing cascade: image_direct → image_retry → typographic fallback)
- Loads `store-identity-art-director` prompt via `PromptLoader` with rejection context when present
- Persists generated signature as `draft` via `persistSignature()`
- Wraps errors in `identity_art_director_failed:` prefix (no typographic fallback at this level)

### BrandProfilerWithoutLogoService
- Text-only LLM call (no vision) — uses creative metadata as primary input
- Loads `store-brand-profiler` prompt with 13 template variables (9 store + 4 art director)
- Parses JSON response into `BrandProfilerWithoutLogoResult`
- Persists profile with `source='without_logo'`, `active_logo_asset_id=null`
- **On success**: marks previous synced profile as `outdated`, creates new profile as `synced`
- **On failure**: creates profile as `failed`, preserves previous synced profile

### Generation Events Service
- 2 functions: `insertGenerationEvent()` and `updateGenerationEventDecision()`
- Both are **best-effort** — never throw, catch all errors, log and return null
- `updateGenerationEventDecision` matches by `asset_id` AND `attempt_number`

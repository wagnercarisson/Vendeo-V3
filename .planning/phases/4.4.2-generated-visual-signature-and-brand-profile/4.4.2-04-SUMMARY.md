## Endpoint Summary

| Method | Path | Behavior |
|--------|------|----------|
| POST | `visual-signature/generate-without-logo` | Generates 1 visual signature, increments attempts, returns asset + metadata |
| POST | `visual-signature/reject` | Archives current draft, records rejection, returns rejection context |
| POST | `visual-signature/approve` | Sets active, triggers brand profiler, resets attempts |
| POST | `brand-profile/generate-without-logo` | Creates brand profile from store data + art director outputs |
| PATCH | `logo-status` | Updates logo_status and visual_signature_attempts with validation |
| PATCH | `store/[id]` | Extended to accept logo_status and visual_signature_attempts |

## Common Patterns
- All endpoints validate storeId as UUID
- Follow existing Next.js App Router patterns with Promise-based params
- Generation events recorded via best-effort pattern

<action>
Create `src/components/flow/visual-signature-approval-modal.tsx`:

Props:
```typescript
interface VisualSignatureApprovalModalProps {
  isOpen: boolean;
  onClose: () => void;
  storeId: string;
  storeData: { name: string; segment: string; /* ...all store fields */ };
  initialAttempt?: number; // resume from existing draft
  onComplete: (result: { logoStatus: string; signatureUrl?: string; brandProfile?: any }) => void;
}
```

States:
1. **generating** — shows loading spinner while generating
2. **display** — shows generated signature for approval
3. **feedback** — optional text input after rejection click
4. **exhausted** — shows all 3 signatures for re-evaluation (at attempt 3/3)
5. **error** — technical failure message

**Display state (attempt < 3):**
- Signature preview in a rounded container (~400x400px)
- Attempt indicator: "Tentativa 1/3" (or 2/3, 3/3)
- "Aprovar" button (primary green)
- "Não gostei, gerar outra versão" button (outline)

**Exhausted state (attempt = 3):**
- Grid showing all 3 generated signatures side by side
- Each with "Aprovar" button
- "Continuar sem logo" link
- "Não gostei, gerar outra versão" button DISABLED with tooltip "Limite de 3 versões atingido"

**Rejection flow:**
1. User clicks "Não gostei, gerar outra versão"
2. Optional feedback text field appears: "O que você não gostou?"
3. User can type feedback or just click "Gerar outra versão" again
4. Calls POST /api/store/[id]/visual-signature/reject with optional reason
5. If not exhausted: calls generate-without-logo with rejection context

**Approval flow:**
1. User clicks "Aprovar"
2. Calls POST /api/store/[id]/visual-signature/approve
3. Shows brief loading state while brand profiler runs
4. Calls onComplete with result

**Modal close without decision:**
- Signature remains as draft
- onClose called — parent can detect pending draft on next visit

**Sequential generation:**
- Exactly 1 signature per invocation
- Wait for user decision before next action
- No "generate 3 at once" behavior
</action>

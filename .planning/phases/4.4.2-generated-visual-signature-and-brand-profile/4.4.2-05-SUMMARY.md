## Changes Summary

### store-identity-form.tsx
- Added 3 new buttons below upload area: "Enviar logotipo", "Não tenho logo" (outline + tooltip), "Continuar sem logo" (discrete link)
- Loads `logo_status` from store API on mount
- Conditional rendering per logo_status: generated shows signature preview, explicit_none shows placeholder, failed shows retry, exhausted shows re-evaluation
- "Não tenho logo" opens `VisualSignatureApprovalModal`

### visual-signature-approval-modal.tsx (new)
- Sequential single-signature generation (1 at a time, max 3 attempts)
- States: generating → display → feedback → approving / exhausted / done
- Display: signature preview (~400x400px), attempt indicator, approve/reject buttons
- Rejection: optional text feedback → calls reject endpoint → triggers next generation
- Exhausted at 3/3: shows all 3 signatures in grid for re-evaluation, reject disabled
- "Continuar sem logo" link available in exhausted and error states
- Modal close preserves draft for resume

### store-visual-signature-section.tsx
- Renders different UI per logo_status: generated, explicit_none, failed, exhausted, null
- Each state has appropriate messaging and actions
- Supports both existing VisualSignatureModal (options-based) and new VisualSignatureApprovalModal (sequential)

### store-identity-block.tsx
- Visual signature displayed in rounded container when `visualSignatureUrl` is present
- Falls back to initials+name when no logo and no signature

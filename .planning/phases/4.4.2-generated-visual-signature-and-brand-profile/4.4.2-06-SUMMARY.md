## resolveStoreIdentity Updates

Resolution chain now follows 4 steps:
1. **Brand assets active**: resolvedLogoUrl + brandProfile (existing, unchanged)
2. **Active visual signature + brand profile (source=without_logo)**: visualSignatureUrl + brandProfile
3. **Brand profile only (source=without_logo)**: store name text + brandProfile (campaign context even without visual asset)
4. **Nothing**: store name + segment fallback (existing, unchanged)

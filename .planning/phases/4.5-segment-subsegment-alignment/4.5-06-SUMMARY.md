## Key Changes

- `getSubsegmentMode` returns 3 modes: `'rich'` (≥2 subsegments, dropdown + Outro), `'travado'` (1 subsegment, disabled select with label), `'other'` (outros, free-text input)
- Rich dropdown: shows subsegment options + "Outro" → opens free-text field
- Travado: disabled select with single human-friendly label (e.g., "Mercados e Mercearias")
- Other: free-text input with placeholder "Digite o seu subsegmento", validates on blur + submit
- `subsegmentIsOther` state tracks "Outro" toggle in rich mode
- `handleSegmentChange` resets subsegment and auto-fills travado values
- Hydration: detects custom vs predefined subsegments on page load
- Client-side validation: 3-30 chars, rejects generic values (outro, loja, comercio, varejo)

# Plan 08: Fix Client-Side Blur Validation for Subsegment "Outro"

## Goal

Fix `handleBlur` and `handleSubsegmentBlur` in `store-identity-form.tsx` to validate the free-text subsegment field when the user has selected "Outro" in a rich segment's subsegment dropdown.

## Root Cause

Two conditions miss the `subsegmentIsOther` state:

1. `handleBlur` (line 205): `if (getSubsegmentMode(formData.segment) === 'other')` — skips validation when `subsegmentIsOther === true` (rich segment + "Outro" selected)

2. `handleSubsegmentBlur` (line 239): `if (mode !== 'other') return;` — early-returns when user is in rich mode with "Outro" open

## Changes

### File: `src/components/flow/store-identity-form.tsx`

**Change 1 — handleBlur condition (line 205):**
```
- if (getSubsegmentMode(formData.segment) === 'other')
+ if (getSubsegmentMode(formData.segment) === 'other' || subsegmentIsOther)
```

**Change 2 — handleSubsegmentBlur guard (line 239):**
```
- if (mode !== 'other') return;
+ if (mode !== 'other' && !subsegmentIsOther) return;
```

**Change 3 — handleSubsegmentBlur dependencies (line 247):**
```
- }, [formData.segment, formData.subsegment]);
+ }, [formData.segment, formData.subsegment, subsegmentIsOther]);
```

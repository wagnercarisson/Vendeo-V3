  <action>
    Create `src/lib/drift.ts` with the following exports:

    1. `SENSITIVE_FIELDS` constant: `readonly string[]` containing `['segment', 'subsegment', 'tone_of_voice', 'name', 'brand_color', 'accent_color']`

    2. `DriftSnapshot` type (export interface):
       - `segment: string | null`
       - `subsegment: string | null`
       - `tone_of_voice: string | null`
       - `name: string | null`
       - `brand_color: string | null`
       - `accent_color: string | null`

    3. `DriftStatus` type: `'none' | 'new' | 'dismissed'`

    4. `normalizeSnapshotValue(v: string | null | undefined): string`:
       - null/undefined → empty string
       - hex strings (matching /^#[0-9A-Fa-f]{6}$/) → lowercased
       - other strings → returned as-is

    5. `currentVisualState(store: Pick<Store, 'segment' | 'subsegment' | 'tone_of_voice' | 'name' | 'brand_color'>, profile: Pick<BrandProfileRecord, 'brand_colors_chosen' | 'safe_color_tokens' | 'inferred_accent_color'> | null): DriftSnapshot`:
       - segment, subsegment, tone_of_voice, name: direct from store fields
       - brand_color: store.brand_color (may be null)
       - accent_color: priority chain — `brand_colors_chosen[1]` → `profile.safe_color_tokens.accent` → `profile.inferred_accent_color` (first non-null, non-undefined wins; any of these may be null/undefined)

    6. `computeDriftStatus(current: DriftSnapshot, inputSnapshot: DriftSnapshot | null | undefined, dismissedSnapshot: DriftSnapshot | null | undefined): DriftStatus`:
       - If inputSnapshot is null/undefined → return 'none'
       - For each of the 6 fields, compare `normalizeSnapshotValue(current[field])` vs `normalizeSnapshotValue(inputSnapshot[field])`
       - If any field differs → drift exists
       - If no drift → return 'none'
       - If drift exists AND dismissedSnapshot is not null/undefined AND for all 6 fields `normalizeSnapshotValue(current[field]) === normalizeSnapshotValue(dismissedSnapshot[field])` → return 'dismissed'
       - Otherwise → return 'new'

    Do NOT import BrandProfileRecord in the function signatures — use inline Pick types as shown above. Import the types from their source files where needed (use `import type { Store } from '@/lib/store'` and `import type { BrandProfileRecord } from '@/lib/brand-assets/types'`).

    Export all types and functions. Use named exports.
  </action>

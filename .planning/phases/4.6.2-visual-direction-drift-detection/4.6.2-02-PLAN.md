    Create `src/components/flow/use-drift-detection.ts`:

    **Hook signature:**
    ```typescript
    export function useDriftDetection(
      store: Pick<Store, 'id' | 'segment' | 'subsegment' | 'tone_of_voice' | 'name' | 'brand_color'> | null,
      profile: Pick<BrandProfileRecord, 'brand_colors_chosen' | 'safe_color_tokens' | 'inferred_accent_color' | 'metadata'> | null,
      options?: { onRealinhado?: () => void }
    ): {
      driftStatus: DriftStatus
      currentSnapshot: DriftSnapshot | null
      realinhar: () => Promise<void>
      ignorar: () => Promise<void>
      isRealinhando: boolean
    }
    ```

    **Implementation:**

    1. State variables:
       - `driftStatus: DriftStatus` (default `'none'`)
       - `currentSnapshot: DriftSnapshot | null` (default `null`)
       - `isRealinhando: boolean` (default `false`)

    2. `useEffect` on mount (and whenever `store` or `profile` changes):
       - If no `store` or no `store.id` (create mode), set driftStatus to `'none'` and return
       - If no `profile`, set driftStatus to `'none'` and return
       - Compute `currentSnapshot` using `currentVisualState(store, profile)`
       - Read `input_snapshot` from `profile.metadata?.input_snapshot` (cast to DriftSnapshot or null)
       - Read `drift_dismissed_snapshot` from `profile.metadata?.drift_dismissed_snapshot` (cast to DriftSnapshot or null)
       - Compute `driftStatus = computeDriftStatus(currentSnapshot, inputSnapshot, dismissedSnapshot)`
       - Set state accordingly

    3. `realinhar()` async function:
       - Set `isRealinhando = true`
       - Fetch `POST /api/store/${store.id}/brand-profile/infer` with `{ textOnlyOrigin: 'explicit' }`
       - On success (response data.success === true):
         - Set `driftStatus = 'none'` (in-place state update — no reload, no navigation)
         - Call `options?.onRealinhado?.()` — parent-provided callback to refetch the updated profile
       - On failure: throw an error (caller handles toast display)
       - Finally: `isRealinhando = false`

    4. `ignorar()` async function:
       - Set `isRealinhando = true`
       - Compute a `dismissSnapshot` from current store state (same fields as `currentSnapshot`)
       - Fetch `PATCH /api/store/${store.id}/brand-profile/metadata` with JSON body `{ drift_dismissed_snapshot: dismissSnapshot }`
       - On success:
         - Set `driftStatus = 'dismissed'`
       - On failure: throw an error (caller handles toast)
       - Finally: `isRealinhando = false`

    5. Return `{ driftStatus, currentSnapshot, realinhar, ignorar, isRealinhando }`

    Import types from `@/lib/drift`, `@/lib/store`, and `@/lib/brand-assets/types`. Import `useEffect`, `useState`, `useCallback` from React.

    The hook does NOT throw on mount errors — only on `realinhar()`/`ignorar()` failures (promise rejection).
  </action>

**Estratégia por identity_state (servidor decide exclusivamente):**

```typescript
const strategy = {
  text_only: () => BrandTextOnlyInferenceService.infer(store),
  logo: () => BrandDirectorService.analyze(store, logoAsset),
  visual_signature: () => BrandProfilerWithoutLogoService.generate({
    ...input,
    mode: 'regenerate',
    // content_used lido da VS metadata, NÃO do perfil anterior
  }),
}[identity_state]();
```

**Regra de compensação (heterogênea por serviço):**

**text_only e logo:** o endpoint é dono da persistência e compensação.
1. Executar inferência (BrandTextOnlyInferenceService / BrandDirectorService) ANTES de qualquer mutação
2. Se inferência falhar → retornar erro, perfil anterior não marcado como outdated
3. Se inferência OK → endpoint marca perfil anterior synced como outdated
4. Inserir novo perfil com status 'synced'
5. Se insert falhar → restaurar perfil anterior para 'synced'

**VS (profiler):** o profiler (BrandProfilerWithoutLogoService) é dono da persistência e compensação.
1. Inferir todos os campos brand (ignorando cache, mode:'regenerate')
2. Marcar perfil anterior synced como outdated
3. Inserir novo perfil com status 'synced'
4. Se insert falhar → restaurar perfil anterior para 'synced'
5. Atualizar input_snapshot com valores atuais da store
- O endpoint NÃO faz marcação/inserção separada no caminho VS.

**VS path específico:**
- Localizar VS ativa (store_visual_signatures com status 'active')
- Ler `content_used` de `metadata.artDirectorOutput.content_used`
- Passar content_used para o profiler (mode 'regenerate')
- Preservar identity_state = 'visual_signature'
- Preservar visual_signature_id no BP
</action>

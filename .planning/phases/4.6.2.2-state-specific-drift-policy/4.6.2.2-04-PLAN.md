**Estratégia por identity_state:**

```typescript
const strategy = {
  text_only: () => BrandTextOnlyInferenceService.infer(store),
  logo: () => BrandDirectorService.analyze(store, logoAsset),
  visual_signature: () => BrandProfilerWithoutLogoService.generate({
    ...input,
    mode: 'regenerate',
    // content_used lido da VS metadata, NÃO do perfil anterior
  }),
}[identity_state]();
```

**Fluxo de compensação (para TODOS os 3 caminhos):**
1. Ler identity_state da store
2. Executar inferência ANTES de qualquer mutação no banco
3. Se inferência falhar: retornar erro, perfil anterior NÃO marcado como outdated
4. Se inferência bem-sucedida: marcar perfil anterior synced como outdated
5. Inserir novo perfil com status 'synced'
6. Se o insert falhar: restaurar perfil anterior para 'synced' (compensação)
7. Atualizar input_snapshot com valores atuais da store

**VS path específico:**
- Localizar VS ativa (store_visual_signatures com status 'active')
- Ler `content_used` de `metadata.artDirectorOutput.content_used`
- Passar content_used para o profiler (mode 'regenerate')
- Preservar identity_state = 'visual_signature'
- Preservar visual_signature_id no BP

**Garantia:** Nunca existem dois registros synced para a mesma store simultaneamente.
</action>

- VS → BrandProfilerWithoutLogoService mode:'regenerate' usado

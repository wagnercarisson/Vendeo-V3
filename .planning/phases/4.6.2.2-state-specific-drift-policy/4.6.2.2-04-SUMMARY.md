# Phase 4.6.2.2 Plan 04: Realinhamento Sensível por identity_state com Compensação

**Data:** 2026-06-30

Implementar a estratégia de realinhamento por identity_state no endpoint POST /brand-profile/realign com compensação (inferir antes de mutar) nos 3 caminhos. Adicionar mode 'regenerate' ao brand profiler.

## Key Results

- `BrandProfilerInput.mode: 'reuse' | 'regenerate'` adicionado
- `mode:'regenerate'` implementa 3 ramos de persistência (A/B/C)
- POST /realign dispatches by identity_state (servidor decide exclusivamente)
- text_only/logo: endpoint persiste com compensação (restore se insert falha)
- VS: profiler persiste com compensação interna (3 ramos)
- content_used lido da VS metadata, não do perfil anterior
- 231 testes passando (7 novos)

## Implementation Details

### Task 1 — Profiler Mode

- `BrandProfilerInput.mode?: 'reuse' | 'regenerate'` em types.ts
- `BrandProfilerInput.contentUsed?` para preservar content_used da VS
- `generate()` com mode:'regenerate' → skip cache, direto para inferência
- `persistWithRegenerate()` com 3 ramos:
  - **Ramo A (BP synced):** UPDATE direto — se falhar, anterior permanece synced
  - **Ramo B (BP failed/outdated + fallback):** marca fallback outdated → UPDATE target → restaura fallback se falhar
  - **Ramo C (BP inexistente):** marca fallback outdated (se existir) → INSERT → restaura fallback se falhar
- Content_used preservado no metadata do BP em modo regenerate

### Task 2 — Realinhamento Route

- Dispatch por `store.identity_state` exclusivamente (não mais por logoAsset)
- `text_only` → `BrandTextOnlyInferenceService` (endpoint persiste)
- `logo` → `BrandDirectorService` (endpoint persiste)
- `visual_signature` → `BrandProfilerWithoutLogoService` mode:'regenerate' (profiler persiste)
- Compensação text_only/logo: inferir → marcar outdated → inserir → restaurar se falhar
- Logo path preserva tratamento de `BrandDirectorAnalysisError`
- VS path lê `content_used` do metadata da VS ativa

### Task 3 — Tests

**Profiler tests:**
- mode:'regenerate' com perfil synced → skips cache
- mode:'regenerate' com contentUsed → preserva no perfil
- Mode default ('reuse') quando omitido

**Realinhamento tests:**
- VS path returns 200 with profile source=without_logo
- VS path calls profiler with mode:'regenerate' and content_used
- VS path no active VS returns 400
- VS path profiler failure returns error (perfil anterior não outdated)

Add test: "Cancelar" calls onClose, does NOT call onComplete, does NOT initiate request.

The key constraint: `state`, `generate()`, and `drift` are NOT public props. The component manages these internally. Test by mocking the network layer:

```typescript
// @vitest-environment jsdom
import '@testing-library/jest-dom/vitest';
import { render, screen, fireEvent, waitFor } from '@testing-library/react';
import { describe, it, expect, vi, beforeEach } from 'vitest';
import { VisualSignatureApprovalModal } from '../visual-signature-approval-modal';
```

**Mocking strategy:**
1. Before each test: `vi.spyOn(global, 'fetch')` and set return values
2. The modal mount sequence:
   - `useEffect` → checks `hasActiveSignatureDrift` (no drift) → `GET /visual-signature`
   - Mock GET to return `{ signatures: [] }` (zero signatures → calls `generate()`)
   - `generate()` calls `POST /generate-without-logo`
   - Mock POST to return `{ ok: false, status: 500, json: async () => ({ error: "Falha ao gerar assinatura" }) }`
   - This triggers `setState({ phase: "error", message })` internally

3. After rendering, `waitFor` the error UI to appear
4. Clear the fetch mock call history (to distinguish post-click from mount requests)
5. Click "Cancelar"
6. Assert: `onClose` was called, `onComplete` was NOT called
7. Assert: no new fetch was initiated after the click

Create a helper that provides all required props with defaults and use it across all tests:

```typescript
function createModalProps(overrides: Record<string, unknown> = {}) {
  return {
    isOpen: true,
    onClose: vi.fn(),
    onComplete: vi.fn(),
    storeId: 'test-store',
    storeName: 'Loja Teste',
    segment: 'alimentacao',
    brandColor: '#FF6600',
    ...overrides,
  };
}

beforeEach(() => {
  vi.restoreAllMocks();
});
```

Test implementation:
```typescript
it('"Cancelar" fecha o modal sem mutações', async () => {
  const props = createModalProps();
  const { onClose, onComplete } = props;

  // Mock GET /visual-signature → empty (triggers generate)
  // Mock POST /generate-without-logo → error (triggers error phase)
  vi.spyOn(global, 'fetch').mockImplementation(async (url, init) => {
    const urlStr = typeof url === 'string' ? url : url instanceof Request ? url.url : '';
    if (urlStr.includes('/visual-signature') && (!init || init.method === 'GET' || init.method === undefined)) {
      return new Response(JSON.stringify({ signatures: [] }), { status: 200 });
    }
    if (urlStr.includes('/generate-without-logo')) {
      return new Response(JSON.stringify({ error: 'Erro simulado' }), { status: 500 });
    }
    return new Response(JSON.stringify({}), { status: 200 });
  });

  render(<VisualSignatureApprovalModal {...props} />);

  // Wait for error UI to appear
  await waitFor(() => {
    expect(screen.getByText('Cancelar')).toBeInTheDocument();
  });

  // Clear fetch history (mount generates requests)
  vi.mocked(fetch).mockClear();

  // Click Cancelar
  fireEvent.click(screen.getByText('Cancelar'));

  // Assert: onClose called, onComplete NOT called
  expect(onClose).toHaveBeenCalledTimes(1);
  expect(onComplete).not.toHaveBeenCalled();

  // Assert: no new fetch after click
  expect(fetch).not.toHaveBeenCalled();
});
```

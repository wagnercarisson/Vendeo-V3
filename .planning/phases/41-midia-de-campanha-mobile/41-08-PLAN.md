## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-41-08 | Tampering | Multi-file input | mitigate | `accept=".png,.jpg,.jpeg,.webp,.heic,.heif"` + validação do hook (validateImage) por item — arquivo inválido não entra no grid (D10) |
| T-41-08a | Spoofing | Origem da imagem | mitigate | `onAdd(file, source)` — source vem do gatilho usado (galeria → "upload"; câmera → "camera") — D4; nunca do conteúdo do arquivo |
| T-41-08b | DoS | Teto de imagens | mitigate | `productImages.length >= MAX_CAMPAIGN_IMAGES` desabilita os controles de adicionar (D10) |
| T-41-08c | Information Disclosure | Object URLs | mitigate | `URL.revokeObjectURL` por item na remoção/substituição — evita leak de memória (padrão hook :427-429) |
| T-41-08d | Tampering | Role dos itens | mitigate | Primeiro item = primary, demais = reference (D3) — role derivado da posição, não do input do usuário |
| T-41-08e | Spoofing | Mocks de teste | accept | Teste de crédito mocka o upload (`() => null`) — sem execução real de arquivos; comportamento de render preservado com `productImages: []` |
| T-41-SC | Tampering | Instalações de pacotes | accept | Nenhum pacote novo — sem gate de legitimidade |

## Trust Boundaries

| Boundary | Componente | Descrição |
|----------|------------|-----------|
| admin HTTP → RPC | Rota admin futura → `admin_set_visual_signature_model_config` | Corpo do ator é não confiável; identidade deve ser derivada no servidor. |

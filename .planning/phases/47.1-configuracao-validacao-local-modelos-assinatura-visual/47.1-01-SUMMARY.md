## Deviations from Plan

1. **[Rule 3 - Blocking] Concorrência em database descartável em vez de
   transações no schema real.** A auditoria é imutável (trigger), então commits
   concorrentes reais não podem ser limpos depois. Solução permitida pelo plano:
   database descartável no mesmo servidor local, criado/removido pelo harness.
   O schema aprovado permaneceu intocado.
2. **[Operacional] Apply manual + runner validado em `-ProofsOnly`.** Os passos
   autorizados 2–3 (cópia + `migration up --local`) foram executados
   explicitamente; depois disso não há pendência para o runner aplicar. O runner
   foi exercitado em `-ProofsOnly` após o apply e seu ramo de apply usa o mesmo
   comando com os mesmos guards.
3. **[Ambiente] Credencial de testes lida em processo.** `OPENAI_API_KEY` de
   `C:\Projetos\Vendeo V3\.env.local` foi lida apenas em memória para
   `VENDEO_VS_VALIDATION_OPENAI_API_KEY`; valor nunca impresso, copiado ou
   commitado.
4. **`openspec validate --strict` sem seletor** retorna uso/exit 1 na CLI atual;
   gate equivalente usado: `--changes --strict` (PASS).

| Boundary | Componente | Descrição |
|----------|------------|-----------|
| navegador admin → API | rotas GET/PUT/DELETE | Corpo e origem não confiáveis. |
| API → RPC | configuração dedicada | Escrita só pode ocorrer via RPC auditada. |
| view → UI | seleção herdada | Diagnóstico não pode virar segundo editor. |

| Threat ID | Categoria | Componente | Disposição | Mitigação |
|-----------|-----------|------------|------------|-----------|
| T-47.1-19 | Elevation of Privilege | API admin | mitigate | `requireAdmin` + `requireSameOrigin` em todas as mutações; corpo estrito; nenhuma escrita direta na tabela. |
| T-47.1-20 | Tampering | Modelo/qualidade forjados | mitigate | Zod aceita apenas orquestrador/preset/motivo/operationId; modelo/qualidade/identidade derivados no servidor/RPC. |
| T-47.1-21 | Information Disclosure | Erros de RPC | mitigate | Mapeamento para códigos seguros; nunca ecoar mensagem SQL/bruta. |
| T-47.1-22 | Repudiation | Reset | mitigate | DELETE exige motivo e operationId, chama RPC auditada e invalida leitura. |

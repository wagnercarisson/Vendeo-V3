Exportar `getLabEnvironment(): LabEnvironmentState` com a seguinte ordem de avaliação (fail-closed):
1. Se `process.env.VENDEO_LAB_ENABLED !== "true"` → `{ enabled: false, supabaseHost: null, local: false, reason: "disabled_flag" }`. Comparação **estrita** com a string `"true"` (qualquer outro valor, inclusive `"1"`, `"TRUE"`, ausente → recusa).
2. Ler `process.env.NEXT_PUBLIC_SUPABASE_URL`. Ausente, vazia ou não parseável por `new URL(...)` → `{ enabled: false, supabaseHost: null, local: false, reason: "missing_url" }`.
3. Extrair `hostname` normalizado: `toLowerCase()` e remoção de colchetes de IPv6 (`[::1]` → `::1`). Nunca retornar a URL completa, path ou query — apenas `supabaseHost`.
4. Se o hostname casar produção conhecida — igual a `supabase.co`/`supabase.in`/`supabase.com` **ou** terminando em `.supabase.co`/`.supabase.in`/`.supabase.com` — → `{ enabled: false, supabaseHost, local: false, reason: "remote_blocked" }`. Este bloqueio vence **sempre**, mesmo que o host esteja na allowlist.
5. `local = hostname ∈ { "localhost", "127.0.0.1", "::1", "0.0.0.0" }`.
6. Allowlist: `process.env.VENDEO_LAB_ALLOWED_SUPABASE_HOSTS` é CSV; fazer `split(",")`, `trim()`, `toLowerCase()`, descartar vazios. Um hostname na allowlist é permitido.
7. Se `local` ou hostname na allowlist → `{ enabled: true, supabaseHost, local, reason: "ok" }`. Caso contrário → `{ enabled: false, supabaseHost, local: false, reason: "non_local_supabase" }`.

Exportar `assertLabEnvironment(): LabEnvironmentState` que chama `getLabEnvironment()` e, se `reason !== "ok"`, lança `new LabEnvironmentError(reason, supabaseHost)`. A mensagem da exceção deve conter o `reason` e, quando houver, **apenas o hostname** — nunca a URL completa, path, query ou chave. Mensagens: `disabled_flag` → "Laboratório desabilitado: VENDEO_LAB_ENABLED não é 'true'"; `missing_url` → "Laboratório desabilitado: NEXT_PUBLIC_SUPABASE_URL ausente ou inválida"; `non_local_supabase` → "Laboratório desabilitado: host '<host>' não é local nem permitido"; `remote_blocked` → "Laboratório bloqueado: host de produção '<host>'".

Exportar `labEnvironmentDeniedBody(reason: LabEnvironmentReason): { error: "environment_blocked"; reason: LabEnvironmentReason }` — corpo padronizado que as rotas do laboratório devolvem com HTTP 403 (aplicado nos planos 48-1-08/09). Não usar `NODE_ENV` nem `VERCEL_ENV` em nenhuma decisão.

Definir `LabScenarioContentSchema` (Zod `.strict()`) com:
- `slug: z.string().regex(/^[a-z0-9]+(-[a-z0-9]+)*$/)` (whitelist de path — sem `..`, sem `/`, sem maiúsculas)
- `name: z.string().min(1)`, `description: z.string().optional()`
- `intent: z.enum(SCENARIO_INTENTS)`, `format: z.enum(SCENARIO_FORMATS)`, `locale: z.enum(SCENARIO_LOCALES)`, `mediaKinds: z.array(z.enum(SCENARIO_MEDIA_KINDS)).min(1)`
- `brief: { product: { name, brand?, sizeOrVariant?, description? }, offer: { originalPriceCents?, discountedPriceCents?, badgeText?, validityText?, availabilityNotes?, campaignDetails?, additionalDetails?, hook?, cta?, objective?, targetChannel? }, legalNotice: { mandatoryText?, illustrativeNoticeEnabled? }, creativeContext: { preserveImageContext?, sensitiveConstraints? } }`
- `store: { name: z.string().min(1), segment: z.string().min(1), brandColor: z.string().regex(/^#[0-9A-Fa-f]{6}$/) }`
- `identity: z.union([ z.object({ state: z.literal("text_only") }).strict(), z.object({ state: z.literal("logo"), logoPath: z.string().min(1) }).strict() ])`
- `images: z.array(z.object({ id: z.string().min(1), role: z.enum(["primary","reference"]), path: z.string().min(1), alt: z.string().optional() }).strict()).min(1)` com `superRefine` exigindo **exatamente 1** imagem com `role: "primary"` (mensagem `exactly_one_primary_image`)
- `fictitious: z.literal(true)` — trava explícita de que os dados são fictícios ou autorizados
- `superRefine` que, para `intent`/`format`/`locale` fora de `SUPPORTED_SCENARIO_MODES`, adiciona issue com `message: "unsupported_scenario_mode"` no path correspondente.

Exportar `class UnsupportedScenarioModeError extends Error` com `readonly code = "unsupported_scenario_mode"` e `readonly field: "intent" | "format" | "locale"`.

Exportar `parseLabScenarioContent(input: unknown): LabScenarioContent` que **pré-detecta** modalidade não suportada **antes** do Zod: qualquer valor **string** fora de `offer`/`1:1`/`pt-BR` — inclusive valores **desconhecidos** fora das uniões (que o `z.enum` rejeitaria antes do `superRefine`, produzindo erro genérico sem `code`) — lança `UnsupportedScenarioModeError` com o campo culpado. Campo de modalidade ausente ou de tipo não-string segue para `LabScenarioContentSchema.safeParse`, que produz o erro normal; se houver issue com `message === "unsupported_scenario_mode"` (defesa em profundidade para uso direto do schema), lança `UnsupportedScenarioModeError` com o campo do path; qualquer outro erro é lançado como `Error` cuja mensagem é a serialização dos issues (nunca incluir o conteúdo bruto das imagens).

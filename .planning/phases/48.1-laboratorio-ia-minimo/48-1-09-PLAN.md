<objective>
Entregar a superfície visual do laboratório sob `/admin/laboratorio`: um único link na navegação principal do admin, layout com guarda de ambiente e sub-navegação interna, página inicial (experimentos recentes + avaliações pendentes), lista somente leitura de cenários, formulário de criação prompt-only com modelo fixo não editável, detalhe com variantes/runs/budget e execução de 1 run com estimativa, confirmação explícita e progresso NDJSON.

Purpose: dar ao admin uma bancada operável sem tocar em nenhuma superfície do lojista (D1/D12) e sem permitir execução acidental: a estimativa é exibida antes e a confirmação é obrigatória (D14).
Output: 1 layout + 4 páginas de rota, 7 componentes locais e 3 testes de componente verdes.

Notas de escopo:
- A sub-navegação interna usa `<nav>` + `<Link>` (D12): "Experimentos" → `/admin/laboratorio`, "Cenários" → `/admin/laboratorio/cenarios` e "Avaliações" → `/admin/laboratorio#avaliacoes-pendentes` (seção de pendências da página inicial). O primitivo `tabs` listado no `48.1-UI-SPEC.md` **não** é criado nesta fase por não ser usado por nenhuma tela — criar componente sem consumidor seria escopo morto.
- Os primitivos locais usam elementos nativos semânticos (`<select>`, `<textarea>`, `<table>`, `<input type="radio">`, `<dialog>`); `src/components/ui/` permanece intocado.
- Este plano **não** importa nenhum arquivo criado pelo 48-1-10 (comparação/avaliação) para preservar a execução paralela da onda 6; o link para a comparação é apenas um `href`.
</objective>

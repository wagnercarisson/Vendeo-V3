# Phase 48.1 — UI Design Contract (Laboratório Mínimo de IA)

> Contrato visual e de interação para a superfície interna `/admin/laboratorio`. Derivado do OpenSpec (D12/D13 + specs `lab-admin-ui`/`lab-human-evaluation`) e do `openspec/design-system/MASTER.md`. A fonte da verdade do projeto prevalece: **dark OLED, Poppins/Open Sans, lucide-react, sem emojis, sem light mode**.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Tailwind + `src/components/ui/` primitives) |
| Preset | not applicable |
| Component library | none (primitivos locais do lab em `src/app/(app)/admin/laboratorio/_components/`) |
| Icon library | `lucide-react` (obrigatório; proibido emoji) |
| Font | Poppins (headings/labels), Open Sans (body), JetBrains Mono (dados: custo, latência, IDs) |

**Primitivos globais reutilizados:** `button`, `card`, `badge`, `input`, `empty-state`, `error-state`, `page-header`, `skeleton`, `loading-skeleton`, `pagination`.

**Primitivos locais a criar (não promover para `src/components/ui/` nesta fase):** `select` (nativo `<select>`), `textarea` (nativo), `table` (nativo `<table>` com estilos do MASTER), `radio-group` (nativo `<input type="radio">`), `dialog`/confirm (usar o padrão de modal do projeto ou `<dialog>` nativo), `tabs` (botões com ARIA `role="tablist"`/`role="tab"`; **omitido na 48-1-09** — a sub-navegação usa `<nav>`+`<Link>` e não há consumidor para um primitivo `tabs`; promover apenas se houver reuso real), `blind-toggle` (switch acessível).

## Screens & States (inventário)

| Rota | Papel | Estados obrigatórios |
|------|-------|----------------------|
| `/admin/laboratorio` | Página inicial: experimentos recentes + avaliações pendentes | carregando (skeleton), vazio (empty-state + CTA "Novo experimento"), ambiente desabilitado (aviso com `reason`), erro |
| `/admin/laboratorio/experimentos/novo` | Form de criação | validação inline, submetendo, erro de API, sucesso → redireciona ao detalhe |
| `/admin/laboratorio/experimentos/[id]` | Detalhe: variantes, runs, budget restante, "Executar run" (estimativa + confirmação + progresso NDJSON) | carregando, sem runs, run em andamento, budget esgotado, run `failed`, avaliação pendente |
| `/admin/laboratorio/experimentos/[id]/comparar` | Comparação lado a lado + voto humano | sem runs comparáveis, modo cego on/off, avaliação registrada, reavaliação, erro técnico exibido |
| `/admin/laboratorio/cenarios` | Lista de cenários versionados (somente leitura) | carregando, vazio, erro |

**Estado de ambiente desabilitado** (todas as telas): card central com ícone `lucide` (`ShieldAlert`), título "Laboratório desabilitado neste ambiente", `reason` legível (`disabled_flag`/`missing_url`/`non_local_supabase`/`remote_blocked`) e nota de que nenhuma tabela `lab_*`, storage ou provider foi acessado.

**Layout:** `layout.tsx` do lab com guarda de ambiente + sub-navegação interna (Experimentos / Cenários / Avaliações) via `<nav>` semântico; **um único** link "Laboratório" na nav principal do admin. `max-w-5xl` para listas/form; `max-w-7xl` para a comparação lado a lado. Responsivo: comparação empilha em mobile (< 768px); alvos de toque ≥ 44×44px.

## Interaction Contract

- **Criação:** dimensão alterada exibida como **fixa** `prompt` (não editável); modelo exibido como **fixo e não editável por variante**; seleção de cenário(s) limitada a `MAX_SCENARIOS_PER_EXPERIMENT=3`; repetições `1–3`; teto `1–12`.
- **Execução:** botão "Executar run" abre confirmação com **estimativa de custo** (por componente; cobertura `complete|partial|missing`) e exige **confirmação explícita** (`confirmed: true`) antes de disparar. Pricing parcial/indisponível exibe faixa/aviso em `accent.amber` (nunca valor exato). Progresso via stream NDJSON; ao final, navega/exibe o `runId`. Um run por vez (`MAX_CONCURRENT_LAB_RUNS=1`); budget restante sempre visível.
- **Comparação:** arte via signed URL; painéis baseline × candidata; status técnico, custo, latência, erros/alertas e seletor de repetição. **Modo cego** oculta modelo/prompt durante a escolha e pode ser revelado depois; a ordem apresentada é registrada.
- **Avaliação:** voto `baseline|candidate|tie|none` + observação livre; registra avaliador + timestamp + `baseline_run_id`/`candidate_run_id` + `blind_order`; avaliação mais recente exibida; reavaliar cria novo registro (append-only).
- **Proibido:** qualquer nota/score automático de beleza, composição, apelo comercial, profissionalismo ou "publicável"; nenhum modelo textual aprova/reprova.
- **Feedback:** loading com spinner + texto; validação inline no blur (nunca só no submit); erros em `accent.red` com ícone `AlertCircle`; transições 150–300ms; `cursor-pointer` em todo elemento clicável.

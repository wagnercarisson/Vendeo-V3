## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bootstrap local → Supabase | deve recusar qualquer host remoto/produção antes de I/O |
| DDL local → cadeia de migrations remotas | `supabase db push` nunca pode carregar as tabelas da bancada |
| requisição de run → banco | concorrência/idempotência; uma geração ativa global |

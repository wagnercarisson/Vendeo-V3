## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| serviço → provedores externos | URL construída com CNPJ canônico; resposta HTTP não confiável |
| provedores → cache | Resultado externo define o que é persistido por 24h |
| cache → consumidores | `not_found` cacheado bloqueia cadastro |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-50.3-06 | Tampering | URL do provedor | mitigate | `resolve` normaliza antes de qualquer lookup; `cnpj` canônico `[A-Z0-9]{12}[0-9]{2}` impede `?`, `#`, `/`, `%`; provedores recebem apenas o valor canônico. |
| T-50.3-07 | Tampering/DoS | `cnpj_lookup_cache` | mitigate | 404 ambíguo é `unavailable`; `unavailable` e `unsupported_format` nunca são cacheados; teste assere `set` não chamado nesses caminhos. |
| T-50.3-08 | Information Disclosure | logs dos provedores | mitigate | Logs continuam apenas com status HTTP e CNPJ canônico; nenhum payload/pepper é impresso. |
| T-50.3-09 | Spoofing | resposta HTTP inesperada | mitigate | `switch`/ramo explícito com fallback default `unavailable`; 200 só é `resolved` com `razao_social` (BrasilAPI) / objeto válido (CNPJá). |
| T-50.3-10 | Elevation of Privilege | capacidade do provedor | accept | `supportsAlphanumeric` é capacidade de código, default `false`; não há flag de ambiente nem ativação remota. |
</threat_model>

2. **[Rule 3 — bloqueio] `db push` tentava TLS no Postgres local.** O CLI falhava com "server refused TLS connection". Correção: `push` define `PGSSLMODE=disable` no processo do CLI (continua usando `db push --yes --db-url`). Tentativas anteriores saíram com exit 1 e foram refeitas após a correção.
3. **[Rule 3 — bloqueio] Serviço de e-mail local não executável no host.** A imagem do mailpit falhava com `exec format error`, impedindo o stack de ficar saudável. Correção: `[inbucket] enabled = false` no config efêmero (nenhum teste F50.4 depende de e-mail).
4. **[Rule 1 — bug] Runner SQL não limpava transação abortada.** Uma falha em um arquivo deixava a sessão em `25P02` e contaminava os arquivos seguintes. Correção: `ROLLBACK` antes de prosseguir após falha.
5. **[Rule 1 — bug] Fixtures SQL incompatíveis com o schema real.** (a) `f50_4_eligibility_matrix.sql` usava UUIDs de store com 13 dígitos no último grupo — corrigidos para UUID válido; (b) as três suítes criavam várias lojas com o mesmo `stores.user_id`, violando `stores_user_id_key` — cada loja recebeu um `auth.users` próprio com o mesmo `created_at` (preserva exatamente a coorte).

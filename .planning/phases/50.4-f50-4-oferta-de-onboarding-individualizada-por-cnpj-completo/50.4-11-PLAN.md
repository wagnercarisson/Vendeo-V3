## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → POST /api/store | Sessão por cookie envia CNPJ e recebe dados da loja; resposta não pode conter identificadores internos. |
| browser → POST /api/store/update-cnpj | Sessão por cookie altera identidade fiscal e pode disparar concessão; exige same-origin. |
| route → RPC service_role | Linha crua de `stores` retorna do banco; a rota é a última barreira antes do cliente. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-50.4-GC-03 | Spoofing (estado) | confirmação fiscal no cliente | mitigate | `cnpjRegistered` booleano derivado da linha server-side; cliente não deriva de input nem de reload. |
</threat_model>

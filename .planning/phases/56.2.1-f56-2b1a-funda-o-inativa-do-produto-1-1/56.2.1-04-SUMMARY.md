## Accomplishments

- Migration `20261008000002_f56_2b1a_product_1_1_campaign_credit.sql` (LOCAL-ONLY, REVERT block): table with `UNIQUE (campaign_id, operation_id)`, closed status set `reserved|art_uploaded|delivered|refunded`, `amount > 0`, RLS service_role, `SELECT/INSERT/UPDATE` only.
- Atomic RPCs (SECURITY DEFINER, `search_path=''`, least privileges): `reserve` (calls `reserve_credit` **and** inserts `reserved` in the same transaction — rollback leaves ledger/balance/state untouched), `mark_art_uploaded`, `deliver` (terminal; idempotent), `refund` (one-time; refuses `delivered`), `get` (separates temporary `reserved` from definitive `delivered`), `reconcile` (exceptional; only stale `reserved`/`art_uploaded`).
- Thin server-only client `ProductOneToOneCreditOperationClient` that only invokes the RPCs and maps errors (`CreditOperationError`), including `credit_reservation_failed` for ledger failures and terminal-refund mapping.
- Simulated contract tests (no DB): static migration contract + mocked-RPC client behavior (idempotent `reserved`, `delivered` definitive, refund, error mapping, empty-response rejection).

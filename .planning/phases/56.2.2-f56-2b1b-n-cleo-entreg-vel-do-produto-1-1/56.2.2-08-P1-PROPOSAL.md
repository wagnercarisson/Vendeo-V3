## 1. Defeito confirmado (por que está semanticamente errado)

`createDurableAttemptEnvelopeSink` (`src/lib/product-1-1/orchestration/instrumentation.ts`)
**reconstrói** um `AiCallEnvelope` (zero-duration) e o entrega ao `DefaultAiTelemetrySink`:

```ts

  capability: "campaign_product_image",
  protocol: "images",
  status: envelope.result,
  provider: "openai",
  model: envelope.model,
  durationMs: 0,                                    // ❌ durationMS reconstruído (zero)
  ...(envelope.internalCostUsd !== null
    ? { providerReportedCostUsd: envelope.internalCostUsd }  // ❌ custo INTERNO rotulado como provider-reported
    : {}),
  quality: envelope.quality,
  target: envelope.target,
  attemptNumber: envelope.attemptNumber,
  metadata: { /* version/origin em metadata */ },
};
```

`resolveAiCost` (`src/lib/ai-cost/cost-estimator.ts`) tem uma **fonte 1 rígida**:

```ts
// Fonte 1: provider_reported (D3) — nunca sobrescrito pelo cálculo interno
if (typeof providerReportedCostUsd === "number" && !Number.isNaN(providerReportedCostUsd)) {
  return { estimatedCostUsd: providerReportedCostUsd, providerReportedCostUsd, costSource: "provider_reported" };
}
```

Consequências:
1. **Origem ERRADA** — o custo interno (pricing do par `modelo + qualidade` + versão/origem,
   `@/lib/ai-cost/image-pair-pricing`) é classificado como `provider_reported` e grava a
   coluna `provider_reported_cost_usd` (badge/auditoria `provider_reported`). É falso:
   nenhum provider reportou esse número.
2. **`usage` DESCARTADO** — o envelope reconstruído não carrega `usage` ⇒ `prompt_tokens`
   /`completion_tokens`/`image_tokens` ficam NULL (o token accounting real se perde).
3. **`durationMs = 0`** — o evento persistido diz 0 ms mesmo que a chamada real tenha
   duração medida.

**Fato-chave que permite a correção mínima:** o `AiGateway` **já emite EXATAMENTE UM
envelope REAL por tentativa** (`src/lib/ai/gateway.ts:92-137`), com `durationMs` REAL
(`Date.now() - startedAt`), `usage` REAL, `status` REAL, `model` REAL, `quality`,
`target` e `attemptNumber`. No novo fluxo esse envelope vai para o **`NoopAiTelemetrySink`**
(`buildAttemptTelemetry`) e depois é **descartado** e substituído por um envelope
reconstruído. O reparo é: **persistir o envelope REAL do gateway** (não reconstruir) e,
NESSES eventos, resolver o custo interno com a **origem correta**.

## 2. Proposta — Opção A (RECOMENDADA, MINIMAL, SEM migration)

**Ideia:** permitir que o `DefaultAiTelemetrySink` receba, no seu **contexto**, um
**custo interno já resolvido** (modelo+qualidade+versão+origem). Quando presente, o sink
usa ESSE custo diretamente (origem `pricing_table` + `pricing_version`) em vez de
`resolveAiCost`; quando ausente, a cadeia legada permanece **byte-idêntica**.

## 3. Por que é MINIMAL e ADITIVA

| Critério | Como é satisfeito (Opção A) |
|---|---|
| Não altera a cadeia legada | `resolveAiCost` só é chamado quando `context.internalCost` está AUSENTE — contexts legados são idênticos byte-por-byte. |
| Sem migration / sem coluna nova | Reutiliza `pricing_table` + `pricing_version` + `metadata` (já existentes). |
| Preserva `COST_SOURCES` (5 fontes) | Não adiciona valor ao enum/CHECK (testes "exatamente 5 valores" intactos). |
| Exatamente 1 registro por tentativa | O envelope REAL do gateway (1/tentativa) vai a UM sink persistente; a reconstrução é removida. |
| Preserva `metadata` (versão/origem) | `buildCallMetadata` já faz spread de `envelope.metadata`; a origem interna é acrescentada pelo sink. |
| Custo real (não zero) | O envelope do gateway carrega `durationMs`/`usage` reais; o sink já os repassa. |
| Nunca `provider_reported` | `internalCost` ⇒ `costSource: "pricing_table"`; `provider_reported_cost_usd` permanece NULL. |

**Como evita o campo semanticamente errado:** o sink nunca popula
`envelope.providerReportedCostUsd` para eventos do novo fluxo; a fonte 1 de
`resolveAiCost` (que rotula `provider_reported`) nunca é alcançada. O custo interno é
gravado como `cost_source = 'pricing_table'` (a verdade: o preço veio da tabela de pricing
do par) com `pricing_version` = versão da linha e a origem interna auditável
(`origin = 'new_flow_pair_pricing'`) em `metadata`.

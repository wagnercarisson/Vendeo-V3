# Phase 57.4 Plan 02: Shell compartilhado traduzido Summary

Shell do lojista lendo integralmente do catálogo (`pt-BR`/`es-419`), menu da conta na ordem Conta → Novidades → Configurações → Sair com entrada para `/configuracoes`, exceção de `/admin` preservada em português e `LogoutButton` com rótulo por prop.

## What Was Built

- **Sidebar/drawer:** `NAV_ITEMS` passou a usar `labelKey` tipada e `messages.nav`; `aria-label` do `nav`, rótulos dos cinco itens, `lang="es-419"` no `nav`/painel e labels de fechar/dialog do drawer vêm do catálogo. Hrefs, ícones, rota ativa, `onNavigate`, focus trap, Escape, scroll lock e `duration-0` intactos.
- **Badge de novidades:** `messages.badge` para `aria-label`/`title`, mantendo `role="status"` e a regra de visibilidade (`latestEntryId` + `hasUnseen`).
- **Topbar:** hamburger, CTA e rótulos acessíveis do catálogo; `Vendeo`/nome da loja não traduzidos; reload forçado em `/campanhas/nova` preservado; 44 px mantidos.
- **Menu da conta:** lojista na ordem aprovada (`/conta` Conta, `/novidades`, `/configuracoes` Configurações, Sair); admin legado (`Configurações → /conta`, Novidades, Sair) sem `/configuracoes`. `lang` aplicado por item traduzido, nunca ao cabeçalho com e-mail.
- **LogoutButton:** `label?: string` com padrão `"Sair"`, sem provider; `clearStorage`/`clearAllDrafts`/form `POST /auth/signout` preservados.
- **Sino:** `messages.label`/`formatMessage(messages.unread, { count })`, import direto de `@/lib/i18n/translate`, fetch único, `9+`, destino e 44 px preservados.
- **AppShell:** calcula `shellEffective`, `lang` e `isAdmin`, encaminhando catálogo efetivo e locale aos filhos; `commonMessages` continua sem encaminhamento.

## Deviations from Plan

### Acceptance-criterion false positive (not a code deviation)

**1. [Rule 3 - blocking check] `sidebar.tsx` grep matches the `/campanhas` href**
- **Found during:** Task 1 acceptance checks.
- **Issue:** the criterion `Select-String ... -Pattern "Campanhas|Configurações|Navegação principal"` returns 0 is case-insensitive in PowerShell and matches the required `href="/campanhas"`, which the spec mandates keeping unchanged.
- **Resolution:** no code change. Verified with a case-sensitive check that no visible label literals remain (`Campanhas`, `Configurações`, `Navegação principal` all removed from JSX text; labels come from `messages.nav`). Removing the href would violate the app-shell spec.
- **Files:** none.

**2. [Rule 3 - blocking check] `topbar.tsx` grep matched a code comment**
- **Found during:** Task 2 acceptance checks.
- **Issue:** the pre-existing comment contained the literal `"Nova Campanha"`, tripping the “0 occurrences” check.
- **Fix:** reworded the comment to describe the CTA without the literal label; behavior unchanged.
- **Files:** `src/components/shell/topbar.tsx`.

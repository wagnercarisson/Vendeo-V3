### `src/lib/i18n/server.ts` (service, request-response)

**Analog:** `src/lib/market-preferences/user-preferences-service.ts`

**Server-only + import pattern** (lines 1-17):


**Read + fallback** to copy (lines 104-112):

```ts
export async function getUserLocalePreference(userId: string): Promise<UserLocalePreferenceDTO> {
  const row = await readPreferenceRow(userId);
  if (!row) {
    return { uiLocale: "pt-BR", source: "legacy_br", version: 0 };
  }
  return mapStoredUserLocalePreference(row as unknown as Record<string, unknown>);
}
```

**Error taxonomy** (`errors.ts:17-25, 67-75`): `PreferencesUnavailableError` (503) and `StoredPreferencesInvalidError` (status 500, but a *known* failure for render fallback).

`getUiRenderContext` contract from design §3:

```ts
type UiRenderContext =
  | { ok: true; locale: SupportedUiLocale; preference: UserLocalePreferenceDTO }
  | { ok: false; locale: "pt-BR"; errorCode: "preferences_unavailable" | "stored_preferences_invalid" | "preferences_read_timeout" };
```

**Cache:** no existing `cache()`/`unstable_cache` usage in `src/lib` (verified). Use `import { cache } from "react"` per design; it is per-request, not a global. Do **not** add module-level mutable state (design risk: “Cache compartilhado entre usuários”).

**Timeout:** `UI_LOCALE_READ_TIMEOUT_MS = 200` with `Promise.race`; attach `.catch(() => undefined)` to the original promise so a late rejection is isolated (design §3). Logging style precedent: `console.warn("[tag] ...")` (`economic-parameter-service.ts:66`, `feature-flag-service.ts:85`); never include PII.

### `src/components/settings/settings-language-form.tsx` (client form, request-response)

**Analogs:** `src/app/(app)/admin/users/[id]/grant-freemium-exception/form.tsx` + `src/components/credit/trial-offer-retry.tsx`

**Fetch + error + `finally`** (copy structure from `form.tsx:30-49`):

```tsx
const res = await fetch("/api/preferences", {
  method: "PATCH",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ uiLocale: selected, expectedVersion: version }),
});
if (!res.ok) {
  const data = await res.json().catch(() => ({ error: "..." }));
  throw new Error(data.error || "...");
}
router.refresh();
...
} catch (err) {
  setError(...);
} finally {
  setSaving(false);
}
```

**Status-aware handling** (design §6): branch on `res.status` for 400/401/403/409/500/503 before generic error; `409` keeps the form but exposes a “Recarregar” action → `router.refresh()`; never auto-resubmit. Network failure = thrown `TypeError` from `fetch` → connection message.

**No PATCH on mount** — initialize from props only; no `useEffect` issuing requests. Sync `uiLocale`/`version` from props after `router.refresh()` (analog: `src/__tests__/.../evaluation-form.test.tsx:207` comment).

**Markup:** `fieldset` + `legend`, native radios; classes follow `form.tsx:52-94` (`max-w-lg`, `space-y-6`, `min-h-[44px]` buttons). Save confirmation in `aria-live` — precedent `trial-offer-retry.tsx:68-69` (`role="status"`), error `role="alert"` (`:86-90`).

Focus/selection preservation rationale from design §6; keep `saving` in `finally`.

## Shared Patterns

### Authentication (server pages)
**Source:** `src/lib/auth/require-user.ts:29-38`
**Apply to:** `configuracoes/page.tsx`, `(app)/layout.tsx`

```ts
export async function requirePageUser(): Promise<AuthenticatedUser> {
  try {
    return await requireUser();
  } catch (error) {
    if (error instanceof UnauthorizedError) redirect("/login");
    throw error;
  }
}
```

Do **not** call `getCurrentStore` in `/configuracoes` (locked: available without store).

### Preference service / DTO
**Source:** `src/lib/market-preferences/{user-preferences-service,dtos,errors}.ts`
**Apply to:** `i18n/server.ts`, settings page/form

Read is side-effect free: `getUserLocalePreference` returns `{ uiLocale: "pt-BR", source: "legacy_br", version: 0 }` for no row and never writes (`user-preferences-service.ts:104-112`). Writes only via `PATCH /api/preferences`; contract unchanged (`route.ts:17-22, 78-114`). Error bodies: `{ error, code, ... }` with 400/409/500/503 mapping (`route.ts:24-64`).

### API error handling (client)
**Source:** `src/app/(app)/admin/users/[id]/grant-freemium-exception/form.tsx:30-49` + `src/components/credit/trial-offer-retry.tsx:37-64`
**Apply to:** `settings-language-form.tsx`

`try / !res.ok → throw / catch → setError / finally → setSaving(false)`, with `response.json().catch(() => ({}))` fallback. `router.refresh()` only after confirmed success.

### Page composition
**Source:** `src/components/ui/page-header.tsx`, `card.tsx`, `loading-skeleton.tsx`
**Apply to:** `configuracoes/page.tsx`, `loading.tsx`

`PageHeader` takes plain server-safe props (`title`, `breadcrumbs[]`, `actions?`); `Card` is a shell with `rounded-xl border border-border bg-bg-surface`. Breadcrumb shape: `{ label: "Dashboard", href: "/dashboard" }, { label: "Configurações" }`.

### `lang` scoping
**Source:** `src/app/layout.tsx:58` (`<html lang="pt-BR">`)
**Apply to:** shell regions + settings content only

Never mutate `document.documentElement.lang`; set `lang` on the `nav`, topbar controls, drawer panel and settings content block only. Dynamic regions (store name, e-mail, notifications) get no Spanish `lang`.

<threat_model>
## Trust Boundaries

| Boundary | Desconhecido → Sistema |
|----------|------------------------|
| Conteúdo editorial → DOM | Trecho/título são texto React; nunca HTML |
| URL assinada → `<img>` | `src` server-side; fallback local em erro |
| Dados de campanha → cliente | Apenas `thumbnailUrl` e textos; nenhum path interno |
| Locale → atributos | `lang` aplicado no menor bloco |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-58-03-01 | Tampering | anúncio compacto | mitigate | Texto React escapado; proibido `dangerouslySetInnerHTML`/`renderMarkdown` no compacto; teste negativo |

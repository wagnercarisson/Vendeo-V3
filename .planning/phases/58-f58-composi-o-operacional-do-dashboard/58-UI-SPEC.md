## Spacing Scale

Declared tokens (multiples of 4):

| Token | Value | Usage in F58 |
|-------|-------|--------------|
| 2xs | 4px | Icon-to-text gap inside count chip/fallback |
| xs | 8px | Header action gap, title/date gap, excerpt gaps |
| sm | 12px | Card content padding on mobile (`p-3`), stacked header gap |
| md | 16px | Card content padding (`p-4`), card grid gap, heading→content gap |
| lg | 24px | Page section gap mobile (`gap-6`), card padding from `sm` (`p-6`) |
| xl | 32px | Desktop page gap (`lg:gap-8`), header→grid gap desktop |
| 2xl | 48px | Not used in F58 |
| 3xl | 64px | Not used in F58 |

**Exceptions (approved):**
- 44px minimum interactive target (`min-h-[44px]`, `min-w-[44px]`) — accessibility, not a spacing token.
- `EmptyState` internal vertical padding `py-20` (80px) — inherited shared primitive; do **not** override or wrap in extra padding.
- Square thumbnail: `aspect-square` (campaign renders are 1:1).
- Count chip uses `px-3 py-1` (12px/4px), not an arbitrary micro-spacing value.

Rules:
- Do not introduce arbitrary values other than the exceptions above.
- Do not add a new page `max-width`; content fills the shell `main` width with `min-w-0`.
- Vertical rhythm between credits and news on desktop is the grid row gap (`lg:gap-8`, 32px). Do not add `space-y-*` or a secondary wrapper.

## Typography

Exactly **4 sizes** and **2 weights** for all F58-authored UI.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 24px (`text-2xl`) | 600 | 1.2 (`leading-tight`) | Greeting `h1`; credits numeric value |
| Heading | 20px (`text-xl`) | 600 | 1.2 (`leading-tight`) | Section `h2` (“Campanhas disponíveis”); compact announcement title |
| Body | 14px (`text-sm`) | 400 | 1.5 (`leading-normal`) | Body copy, campaign product name (600), dates, links (600), failure text |
| Label / Caption | 12px (`text-xs`) | 600 (label) / 400 (date) | 1.2 (label) / 1.5 (date) | Uppercase card label, count chip, campaign dates, skeleton labels |

Rules:
- Fonts: `font-heading` (Poppins) for Display, Heading, labels, product names, numeric values; `font-body` (Open Sans) for body, dates, excerpt.
- Numeric values use `tabular-nums`.
- No 16px, 18px, 28px, or 32px type in new dashboard components.
- Long text: `break-words`; product name max 2 lines (`line-clamp-2`); `h1` max 2 lines; never overlap actions or thumbnails.
- `EmptyState`/`ErrorState` are shared primitives: their actual internal title is 20px (`text-xl`) / 700. They are the only 700-weight exception and must not be restyled.

| Accent (10%) | `#22C55E` / `#3B82F6` | See reserved list below |

| Destructive | none | No destructive action exists in F58 |

**Accent reserved for (exhaustive):**
- `#22C55E` green: header primary CTA **“Nova campanha”** only in `has_eligible_campaigns`; empty-state **“Criar campanha”** in `no_eligible_campaigns`; empty-state **“Configurar loja”** in `no_store`; fixed shortcut action **“Criar campanha”**; credits `Coins` icon and border tint; verification-approved banner success icon; readiness banner “Configurar agora” CTA (existing component behavior).
- `#3B82F6` blue: **all text links** (“Ver todas as campanhas”, “Ver detalhes”, “Ver novidades”) and **all focus rings**. No blue fills.
- `#F59E0B` amber: warning icons/text in the preserved verification/readiness banners and the credits-unavailable icon.
- `#EF4444` red: campaign failure icon only. Never a full red card or red CTA.

Rules:
- Text: `text-text-primary` for titles/values; `text-text-secondary` for body, dates, labels, count; `text-text-muted` **only** for decorative/non-essential elements (never dates, never actionable text); `text-text-disabled` only for the fallback thumbnail icon.
- No white/`#FFFFFF` surfaces, no purple, no gradients, no chart palette, no translucent glass panels.
- No color-only state: zero vs unavailable vs available differ by **text and icon**, not only tone.

## Layout Contract

### Page composition (DOM order is normative)

```
<div class="w-full min-w-0">  <!-- lang="es-419" only when uiLocale === "es-419"; omit otherwise -->
  [compact header: h1 greeting + actions]
  [VerificationBanners?]
  [ReadinessCheckBanner?]
  <div class="grid grid-cols-1 gap-6 lg:grid-cols-3 lg:gap-8">
    <section credits>   ← DOM 1st
    <section campaigns> ← DOM 2nd (single panel)
    <section news>      ← DOM 3rd
  </div>
  <section shortcut>    ← DOM 4th, full-width band below the grid
</div>
```

- **No `PageHeader`**, no `h1` “Dashboard”, no breadcrumbs, no date-range filter.
- Header: `mb-6 flex flex-col gap-2 lg:mb-8`.
  - `h1`: `min-w-0 font-heading text-3xl font-bold leading-tight text-text-primary break-words sm:text-4xl`.
  - Store name inside `h1` as `<span lang="">{storeName}</span>`; separator from namespace (`", "`). No store → welcome phrase only.
  - Subtitle below `h1`: desktop `text-base text-text-secondary font-body`; mobile short variant. Desktop copy: “Suas campanhas e informações essenciais em um só lugar.” Mobile short: “Suas campanhas em um só lugar.”
  - **No internal header action buttons.** The existing creation action lives in the topbar/shell and is not changed. The no-store and readiness states keep their own required CTAs.
- Banners render between header and grid, preserving their existing `mb-6` and visual tokens. In `es-419` all their strings come from the dashboard namespace via optional props.
- Grid placements at `lg`:
  - Campaigns: `lg:col-span-2 lg:col-start-1 lg:row-start-1 lg:row-span-2` (primary column).
  - Credits: `lg:col-start-3 lg:row-start-1` (highlighted).
  - News: `lg:col-start-3 lg:row-start-2`.
  - Use explicit `col-start`/`row-start` for desktop placement. Mobile may use scoped `order-1/2/3` only to preserve credits → campaigns → news while credits/news share an independent desktop stack.
- The fixed creation band is a full-width section below the grid, never a sidebar card.
- Mobile DOM order: credits → campaigns → news → fixed creation band. The shortcut never appears between credits and news.
- `no_store`: header (neutral welcome) + `EmptyState` only. **No** credits query, no campaigns query, no announcement, no banner. Header shows **no** action buttons; the single CTA lives in the empty state to avoid duplication.
- `no_eligible_campaigns` / `has_eligible_campaigns`: full grid with credits and news; campaigns section shows empty state (count 0) or cards.

### Credits block

- `<section aria-labelledby="credits-title">` → `<Card className="border-accent-green/30 bg-accent-green/5 p-4 sm:p-6">` (highlighted).
- Desktop: title, icon/value row, secondary description and action stacked. Mobile: compact horizontal block with icon + title/action on the left and the value on the right; avoid a tall card with empty space.
- `h2#credits-title`: `flex items-center gap-2 text-sm font-semibold text-text-primary font-heading` with a green `Coins` icon inside a green-tinted circle (`h-9 w-9`, icon `h-5 w-5`, `aria-hidden`) = “Créditos disponíveis”.
- Available: value `font-heading text-3xl font-bold leading-none text-text-primary tabular-nums`; no repeated unit in the number. Secondary description below: “Saldo atual da sua loja”.
- Zero: render **only** `messages.zero` (full string `0 créditos` / `0 créditos`) in a single element; do not render a separate number or unit. No warning icon, no muted color, no “0 0 créditos”.
- Unavailable: `AlertCircle` amber + “Saldo indisponível”; **never render `0` or `—`**.
- Action always present (all three states): “Ver créditos e extrato” → `/conta`, `min-h-[44px]`, green text link with trailing arrow, focus visible.
- Do **not** render `BalanceDisplay`. Do **not** show demo/bonus breakdown in the dashboard.

### Campaigns section

- `<section aria-labelledby="campaigns-title" className="min-w-0">` wrapped in one `<Card className="p-4 sm:p-6">` panel.
- Panel header: `flex items-start justify-between gap-3`.
  - Left: `h2#campaigns-title` = “Campanhas recentes” (`text-xl sm:text-2xl font-semibold text-text-primary font-heading`), with secondary count below (“1 campanha disponível” / “{count} campanhas disponíveis”).
  - Right: “Ver todas” link → `/campanhas`, green text link with trailing arrow, 44px.
- Rows: `divide-y divide-border` inside the panel; up to three rows.
- Campaign row: a non-interactive `div` with thumbnail + metadata + a single visible `Abrir campanha` link. No nested links/buttons.
  - Thumbnail wrapper: `relative h-20 w-20 shrink-0 overflow-hidden rounded-lg bg-bg-elevated sm:h-24 sm:w-24` (small-to-medium).
  - Image: plain `<img>` (no `next/image`), `h-full w-full object-cover`, `alt=""`.
  - `onError` sets failed state and swaps to fallback **in place**, preserving the action.
  - Fallback: `ImageOff` `h-6 w-6 text-text-disabled aria-hidden="true"`.
  - Metadata: product name `<span lang="" className="text-base sm:text-lg font-semibold text-text-primary font-heading">`; date `text-sm text-text-secondary font-body`.
  - Action: `Abrir campanha` link with arrow, outlined on desktop (`border border-border-light rounded-lg min-h-[44px] px-4`) and placed below the metadata on mobile. Desktop: right-aligned.
- No status badge, no technical metrics, no error/generating campaigns, no nested interactive elements.
- Empty (`count = 0`): render `<EmptyState icon={Megaphone} title=… description=… action={<Link…>}/>` **directly in the section** (no wrapping `Card`, no extra padding). CTA = “Criar campanha” → `/campanhas/nova`, green, 44px.
- Failure: compact panel `<Card role="status" className="p-4 sm:p-6">` with `AlertTriangle` `h-5 w-5 text-accent-red aria-hidden="true"`, title `text-sm font-semibold font-heading text-text-primary`, body `mt-1 text-sm text-text-secondary font-body`, and the same `/campanhas` link style. No retry button (server component), no red background.
- Divider, then orientation text inside the same panel: “Abra uma campanha para visualizar o conteúdo completo e baixá-lo para publicar.” (`mt-4 border-t border-border pt-4 flex gap-2 text-sm leading-normal text-text-secondary font-body`, with info icon). This is guidance, not a review or publication action by Vendeo.
- “Ver todas” lives in the panel header, not as a footer link.

### Fixed creation band (bottom)

- Full-width, discrete band **below** the campaigns + sidebar grid, never inside the sidebar.
- Fixed invitation, not a recommendation: “Que tal criar sua próxima campanha?” with action “Criar campanha” → `/campanhas/nova`.
- `<Card className="mt-6 flex flex-col gap-3 border-border-light bg-bg-surface p-4 sm:flex-row sm:items-center sm:justify-between sm:p-5">`.
- Title `h2`: `text-base font-semibold leading-tight text-text-primary font-heading`.
- Action link: green, 44px, trailing arrow, focus visible.
- Mobile: after news; DOM order credits → campaigns → news → band.
- The copy is static and independent of balance, campaign history, review status or any other signal. It does not introduce recommendation logic.

### News section

- `<section aria-label="{sectionLabel}">` (label localized, visually hidden; avoids a second visible heading).
- Render `<ChangelogAnnouncement entry={entry} compact excerpt={excerpt} labels={...} />`; the component owns the `Card`.
- Compact card: `p-4`, no `mb-6` (grid gap governs spacing), `rounded-xl border border-border bg-bg-surface`.
- Internal compact layout:
  - Visible “Novidades”/“Novedades” badge at the top (green-tinted pill), then title.
  - Header row `flex items-start justify-between gap-3`: title `h2` `text-xl font-semibold leading-tight font-heading text-text-primary line-clamp-2` with `lang="pt-BR"`; close button `44×44`, ghost, `X` icon (`h-4 w-4`), `aria-label` localized.
  - Date `mt-1 whitespace-nowrap text-xs text-text-secondary font-body` (editorial date, unchanged formatting).
  - Excerpt `mt-2 text-sm leading-normal text-text-secondary font-body break-words` with `lang="pt-BR"`; plain React text only.
  - Actions `mt-3`: “Ver novidades” link `text-sm font-semibold text-accent-blue`, 44px → `/novidades`.
- Modal variant (`announcement: "modal"`): preserve existing overlay/dialog tokens (`fixed inset-0 z-50`, `bg-black/50 backdrop-blur-sm`, `max-w-[480px]`, `bg-bg-elevated`, `rounded-xl`, `p-6`, `shadow-xl`); compact modal renders title/date/excerpt/actions only. Do not downgrade modal to card.
- Dismiss calls `dismissAnnouncement(id)`; does not change `lastSeenId`. `entry === null`, `announcement === "none"`, dismissed, or empty excerpt with no entry → render nothing.
- The news wrapper is rendered when an entry exists. The excerpt may be `null`/empty; in that case the compact component keeps title, date and actions and omits only the excerpt paragraph. Do not gate the wrapper on `entry && excerpt`. After client-side dismissal, the wrapper may remain in the DOM with no visible content and no reserved gap; this is accepted for the preserved dismissal contract.
- Do not render full markdown body, `<ul>`, or `dangerouslySetInnerHTML` in compact mode.

## Responsive Behavior

| Range | Header | Page grid | Campaign cards | Notes |
|-------|--------|-----------|----------------|-------|
| `< 640px` | Stacked: title, then actions (wrap) | 1 column, DOM order: credits → campaigns → news | 1 column | Credits full width above campaigns; all actions 44px |
| `640–1023px` | Row: title left, actions right (wrap) | 1 column, same order | 2 columns | Campaigns remains before news visually |
| `≥ 1024px` | Row | 3 columns: campaigns span cols 1–2 and rows 1–2; credits col 3 row 1; news col 3 row 2 | 3 columns inside the 2-col-wide section | Explicit placements, no `order` |

Additional rules:
- Truncation is mandatory: product name 2 lines max; `h1` 2 lines max; dates never wrap; count chip never shrinks.
- No horizontal scroll at 320px width.
- Touch targets ≥44×44 for: header CTAs, card links (whole card), “Ver todas”, “Ver detalhes”, announcement link/close, empty-state CTA, and preserved banner interactive controls (`ApprovedBanner` close and `ReadinessBanner` “Configurar agora” CTA). `ReadinessBanner` has no close action.
- Hover may change color, brightness, border or underline (≤200ms); **no scale/translate**, no layout shift.
- `prefers-reduced-motion`: use `motion-safe:` transitions where new motion is authored; skeletons keep the shared pulse/shimmer (pre-existing system behavior).

## Interaction & Accessibility Contract

- Heading hierarchy: `h1` greeting → `h2` “Créditos disponíveis” / “Campanhas disponíveis” / compact announcement title. Campaign product names are **not** headings. No skipped levels.
- Landmarks: one `<section>` per block with `aria-labelledby` (credits, campaigns) or localized `aria-label` (news).
- Focus: visible `focus-visible:ring-2 focus-visible:ring-accent-blue` with `ring-offset-2 ring-offset-bg-deep` on every interactive element. Whole-card link focus ring must be visible (not clipped by `overflow-hidden` — apply ring on the `<Link>` with offset).
- Keyboard order = DOM order: header CTAs → banners → credits details → campaign cards 1→3 → “Ver todas” → announcement link/close.
- **Accepted tradeoff:** on desktop, campaigns are visually top-left, but keyboard/reading order starts with credits because mobile priority is normative. Manual keyboard validation is a required gate; do not use CSS `order` to “fix” visual order at the cost of DOM order.
- Images: thumbnail is decorative (`alt=""`) because the campaign link carries a localized `aria-label` that identifies the campaign and date; the whole-card label is the accessible name, so `lang=""` on the visible product span does not cover pronunciation of the label. This limitation is accepted for this phase.
- The preserved modal uses existing `role="dialog"`/`aria-modal="true"` but does not add a new focus trap, initial focus or focus return in F58; this is a documented accessibility limitation, not a new regression.
- Failure panel: `role="status"` (not `alert`) to avoid an assertive announcement on every page load.
- Loading: container `role="status" aria-label="{loading}"` and `lang="es-419"` only in the Spanish resolved locale; all skeleton shapes `aria-hidden="true"`.
- Modal: preserve existing `role="dialog" aria-modal="true"` and `aria-label`; do not add a new focus-trap implementation in this phase.
- Contrast: text uses primary/secondary tokens only (≥7:1 target on `#020617`/`#0F172A`); `text-muted` is banned for dates, labels, and links.
- Count chip `aria-hidden="true"` is intentional; a visually hidden localized sentence SHALL announce the count using the singular form for `1` and plural otherwise. Do not expose the bare chip number as the only accessible count.

Formatting rules:
- Credits: integer via `Intl.NumberFormat(uiLocale)`; no currency, no decimals, no conversion. Available uses number + unit; zero uses the full `messages.zero` string alone, never number+unit plus `messages.zero`.
- Campaign dates: `Intl.DateTimeFormat(uiLocale, { day: "2-digit", month: "short", year: "numeric", timeZone: storeTimeZone ?? "UTC" })`; explicit `UTC` when the store timezone is unavailable (never server-local, never a guessed store zone).
- Greeting period: computed with `Intl` in the store timezone; null/invalid → neutral phrase. Never `getHours()`, never silent `America/Sao_Paulo`.
- Announcement excerpt: server-derived plain text, ≤~200 chars at a word boundary + `…`; no AI summary, no translation, no HTML.

## Forbidden Patterns (non-negotiable)

- ❌ `PageHeader` titled “Dashboard”; duplicate `h1`; breadcrumbs.
- ❌ KPI strip, “Total de Campanhas”, “Campanhas Prontas”, “Taxa de Sucesso”, charts, analytics table, date-range filter.
- ❌ “Próximo passo”, adaptive next-step card, recommendations, priority matrix, success rate.
- ❌ Campaigns with `error`/`generating` in cards, counts, or thumbnails; status badges on cards.
- ❌ `BalanceDisplay`, `—` for unavailable balance, or `0` for a failed read.
- ❌ Full editorial markdown body in the dashboard announcement; `dangerouslySetInnerHTML` in compact mode.
- ❌ Emoji as icons; `❌` markers in localized readiness output (see alignment note).
- ❌ `storage_path` or unsigned URLs reaching the client; `next/image` with new domains; a new image API route.
- ❌ White surfaces, purple, gradients, glassmorphism, dark-on-dark low-contrast text.
- ❌ Scale/translate hover, instant transitions, missing `cursor-pointer`.
- ❌ CSS `order` for responsive reordering; client-side locale switching or a provider.
- ❌ New route, new API, new dependency, schema change, migration, deploy.

**Design-system alignment (required, minimal):** in `ReadinessBanner`, the existing `❌` text glyph violates MASTER “no emoji as icons”. Replace it with a lucide `X` (or `Circle`) icon, `h-4 w-4 text-accent-amber aria-hidden="true"`, in both default and localized rendering. No behavior change. The only other visual changes to shared components beyond optional message props are accessibility hit areas: `ApprovedBanner` close becomes `min-h-[44px] min-w-[44px]` and `ReadinessBanner` “Configurar agora” CTA becomes `min-h-[44px]`; no copy, behavior, or layout semantics change. `ReadinessBanner` does not gain a close action.

## Genuine Ambiguities (flagged, non-blocking)

1. **Announcement date language.** `dashboard-localization` says title/date/excerpt remain Portuguese, while D-09 limits `lang="pt-BR"` to title and excerpt. Resolution in this contract: keep `formatChangelogDate` unchanged and **do not** add `lang` to the date. Visual result is safe; screen-reader pronunciation of a Portuguese month inside an `es-419` region is a known limitation.
2. **Campaign thumbnail accessible name.** Spec accepts “alt text **or** accessible name”. This contract uses a decorative `alt=""` plus a localized `aria-label` on the whole-card link, preventing double announcement. If the checker requires a literal `alt`, use the same `openAria` string as `alt` and drop `aria-label` — do not do both.
3. **Credits unavailable tone.** “Unavailable” is a partial failure, not an error. Amber icon + secondary text is chosen to avoid alarming the store owner; red is reserved for the campaigns failure panel.

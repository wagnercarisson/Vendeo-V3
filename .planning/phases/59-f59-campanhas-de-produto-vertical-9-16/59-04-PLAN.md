<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bytes do provider → pipeline sharp | bytes não confiáveis, possivelmente truncados ou com dimensão inesperada |
| processo → bucket privado | upload assinado com service role; path errado pode sobrescrever arte de outra campanha |
| objeto no bucket → sonda | conteúdo pode ser adulterado/ausente; classificação errada muda crédito |
| path de storage → assinatura | assinatura indevida expõe arte privada |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-59-16 | Tampering | `resizeVerticalToJpeg1080x1920` | mitigate | Fonte exigida exatamente 1152×2048 + igualdade de proporção ANTES do resize; decode completo do resultado; falha fechada sem upscale/crop/pad. |
| T-59-17 | Tampering | path de upload | mitigate | Path determinístico por UUIDs e `upsert:false`; conflito ⇒ `artifact_path_conflict`, sem sobrescrita. |
| T-59-18 | Spoofing | `probeArtifact` | mitigate | `integral` só com jpeg 1080×1920 decodificado; 1024×1024 ⇒ `invalid`; ausência só com 404 que nomeia o objeto; erro ⇒ `indeterminate`. |

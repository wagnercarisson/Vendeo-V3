### 4.1 Preflight somente leitura

```powershell

psql $env:TEST_DATABASE_URL -v ON_ERROR_STOP=1 -c "select current_database(), inet_server_addr(), inet_server_port();"

# ledger e versão máxima
psql $env:TEST_DATABASE_URL -v ON_ERROR_STOP=1 -Atc "select version, name from supabase_migrations.schema_migrations order by version;"

# fingerprint do ledger: SHA-256 do JSON ordenado com version + name + statements.
# `statements` é serializado explicitamente via to_jsonb (array/objeto/string/null).
$ledgerJson = psql $env:TEST_DATABASE_URL -v ON_ERROR_STOP=1 -Atc @"
select jsonb_agg(
         jsonb_build_object(
           'version', version,
           'name', name,
           'statements', to_jsonb(statements)
         ) order by version
       )::text
from supabase_migrations.schema_migrations;
"@
if ($LASTEXITCODE -ne 0) { throw "ledger_query_failed" }
if ([string]::IsNullOrWhiteSpace($ledgerJson)) { throw "ledger_empty" }

$ledgerJson | node -e "const c=require('crypto');let s='';process.stdin.on('data',d=>s+=d).on('end',()=>{const t=s.trim();if(!t){console.error('empty_ledger_output');process.exit(1)}console.log(c.createHash('sha256').update(t).digest('hex'))})"
if ($LASTEXITCODE -ne 0) { throw "ledger_fingerprint_failed" }

# estado da tabela e do bucket
psql $env:TEST_DATABASE_URL -Atc "select to_regclass('public.campaign_composition_artifacts');"
```

## 8. Rollback e limitações

- **Instância descartável:** destruir o ambiente é o rollback.
- **Homolog:** rollback é decisão separada e não automática; não há backfill nem migração de legado.
- A migration inclui bloco `-- REVERT` comentado, executável apenas manualmente em ambiente descartável.
- `service_role` ignora RLS; a imutabilidade da linha é provada pelo trigger via conexão owner, e a não sobrescrita do objeto é comportamento do módulo (`upsert:false`, sem delete), não da policy.
- Conclusão local/integração **não** é aprovação de produção.

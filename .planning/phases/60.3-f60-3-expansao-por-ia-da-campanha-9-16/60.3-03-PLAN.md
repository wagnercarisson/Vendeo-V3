## Contratos F60.1 que o gate consome

- `getArtifactByIdentity(identity, client?)` → `{ kind: "found"; record } | { kind: "absent" } | { kind: "read_failed"; message }`.
- `retrieveCompositionArtifact({ identity, authorization }, deps?)` → `integral` (com `artifact` + `bytes`) | `absent` | `invalid` | `metadata_conflict` | `indeterminate`.
- `persistCompositionArtifact({ identity, authorization, bytes, origin, source, sourceCampaignId? }, deps?)` → `created | reused` | conflitos | `integrity_failure` | `persistence_failure` | `indeterminate`.
- `CompositionArtifactStorage.readObjectInfo(path, bucket?)` → `{ kind: "found"; metadata } | { kind: "absent" } | { kind: "indeterminate" }`; `downloadBytes` idem.
- `buildObjectEvidence(input)` → `{ ok: true; evidence } | { ok: false; reason }`; `verifyObjectEvidence(storedMetadata, expectedEvidence)` → `{ ok: true } | { ok: false; reason: "evidence_missing" | "evidence_invalid" | "evidence_mismatch" }`.
- `compositionArtifactStoragePath(identity)`; `COMPOSITION_ARTIFACT_BUCKET`.
- `isAbsenceError` (interno de `storage.ts`): só 404 nomeando o **objeto** prova ausência; qualquer outro erro é `indeterminate`.

- `getArtifactByIdentity` → `read_failed` ⇒ `blocked`/`pre_call_probe_indeterminate`, zero calls.

- `absent` + `readObjectInfo` `absent` ⇒ **only path that proceeds to the paid call**.

## Shared Patterns

### A. Server-only boundary
**Source:** `composition-artifacts/{retrieve,persist,storage,evidence,repository,access}.ts` line 1.
```ts
import "server-only";
```
Apply to: `model.ts`, `reuse-evidence.ts`, `probe.ts`, `transport.ts`, `telemetry.ts`, `output.ts`, `expand.ts`. **Not** to `types.ts`, `policy.ts`, `prompt.ts`, `failure.ts`, `reuse-compatibility.ts`. Tests mock it: `vi.mock("server-only", () => ({}))`.

### B. Client injection
**Source:** `repository.ts:165-179`, `storage.ts:89`, `image-pair-pricing.ts:96-102`, `ai-model-catalog-service.ts:45-49`.
Every server module takes `client: SupabaseClient = supabaseAdmin` as the last constructor arg or a `deps: { client?: SupabaseClient } = {}` object. Tests pass `createFakeArtifactBackend().client`. Never read env or build a client inside the module body.

### C. Closed unions + `Object.freeze`
**Source:** `square-preparation/types.ts`, `composition-artifacts/types.ts:204-217`, `role-policy.ts:73-103`.
Return discriminated unions with `readonly kind` + closed `reason`; freeze returns and constants. Never throw for expected failure modes; reserve `throw` for programming defects (`VerticalResizeError`, `ImageModelPairNotEligibleError`).

### D. Absence vs indeterminate
**Source:** `storage.ts:33-40`, `retrieve.ts:96-103`, `prepare.ts:356-359`.
Only a 404 that names the **object** proves absence; everything else is `indeterminate` → blocked, zero paid calls.

### E. Evidence is computed by F60.1 only
**Source:** `evidence.ts:240-334` / `380-450`.
`buildObjectEvidence` for the *expected* value, `verifyObjectEvidence` for the *stored* value. Never hand-build metadata, never recompute digests outside `evidence.ts`.

### F. Single telemetry event
**Source:** `gateway.ts:197-204` (one `emit` per try/catch branch, sink failure swallowed), `telemetry-sink.ts:378-401` (`BufferingAiTelemetrySink`), route `:269-307` (flush handler).
One gateway `invokePrepared` per module call ⇒ one envelope. Decorate, never re-emit. Flush exactly once, in `try/finally`, best-effort.

### G. Cost truthiness
**Source:** `telemetry-sink.ts:99-129`, `182-227`; `image-usage-token-cost.ts:308-345`.
Unknown ⇒ `estimatedCostUsd: null` + `costSource: "not_available"`. `provider_reported` wins when present; otherwise `pricing_table` via usage tokens. Never `0` and never a hardcoded `0.05`.

### H. Pre-call pricing coverage
**Source:** `image-pair-pricing.ts:109-124` (`code_default` rejected), `130-190` (coverage `complete|partial|missing`, `assertExecutable` throws).
60.3 must add the stricter requirement: `image_unit_usd` **plus** `inputCostUsd`, `outputCostUsd`, `imageInputTokenUsdPer1M`, `imageTokenUsdPer1M`, `cachedInputCostUsd`, `imageCachedInputTokenUsdPer1M`. Missing any ⇒ `pricing_unavailable`/`incomplete_coverage`, zero calls. `ModelPricing` field names come from `ai-model-pricing.ts:16-18` and `types.ts` `UsageTokenPricing`.

### I. Architecture guard
**Source:** `src/lib/ai/__tests__/architecture-guard.test.ts:101-137`.
No `images.edit(`, no `resolveAiCost(`, no `AiCostTracker.record(` outside the allowed roots. `vertical-expansion/**` talks only through `AiGateway` + adapter classes + `createDefaultTelemetryContext`.

### J. Migration/workflow
**Source:** `AGENTS.md` — no migration in 60.3; if one ever appears it must be `YYYYMMDDHHmmss_description.sql` (UTC, real seconds, uniqueness-checked). Do not reset/reapply the F60.1 migration.

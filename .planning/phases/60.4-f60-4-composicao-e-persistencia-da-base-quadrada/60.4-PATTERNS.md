# Phase 60.4: F60.4 — Composição e persistência da base quadrada — Pattern Map

**Mapped:** 2026-11-11
**Files analyzed:** 14 new/modified production files + 1 test directory (`__tests__/*.contract.test.ts`)
**Analogs found:** 14 / 14 (no exact copy; 11 strong role+flow matches, 3 partial/exact-by-precedent)

Source of truth read: `60.4-CONTEXT.md`, `openspec/changes/archive/2026-11-12-fase-60-4-composicao-e-persistencia-da-base-quadrada/{design.md,tasks.md,specs/campaign-square-base-composition/spec.md}`, `AGENTS.md`, `docs/fluxo-de-desenvolvimento.md`.

**Core structural insight (drives every file below):** F60.3 (`src/lib/campaign/vertical-expansion/**`) is a near-exact architectural template — same pure-contract split, same F60.1 gate, same single-shot transport, same buffered telemetry, same closed result union. F60.2 (`src/lib/campaign/square-preparation/**`) is the smaller module template for "retrieve → transform → F60.1 persist → readback". The genuinely new work is: (a) read-only frozen state (snapshot+binding+evidence) that F60.3 does not have, (b) the copy pipeline, (c) the additive `maxRetries` option in text adapters.

### 1. `types.ts` (pure contract) — analog `vertical-expansion/types.ts`

**Why it is the right analog:** it is the only existing module that declares "entrada fechada + evidência da chamada + união discriminada de resultado" without importing `server-only`, Supabase, Sharp, or crypto.

**Imports pattern** (`types.ts:16-24`) — reuse the *owner* types, never redefine:
```ts
import type { CostResolution, TokenUsage } from "@/lib/ai-cost/types";
import type {
  ArtifactRecord,
  AuthorizationContext,
} from "@/lib/campaign/composition-artifacts/types";
import type {
  ProviderFailure,
  ProviderFailureClass,
} from "@/lib/product-9-16-two-stage/types";
```

**Attempt input pattern** (`types.ts:38-55`):
```ts
export interface ExpandVerticalAttempt {
  readonly number: number;         // 1-based, inteiro positivo
  readonly reference: string;      // referência opaca, não vazia
}
export interface ExpandVerticalInput {
  readonly source: ExpandVerticalSourceIdentity;
  readonly operationId: string;
  readonly attempt: ExpandVerticalAttempt;
  readonly authorization: AuthorizationContext;
  readonly timeoutMs?: number;
  readonly signal?: AbortSignal;
}
```
For 60.4 add `target: "primary" | "fallback"` to `attempt` (design `Contract > Entrada`), `storeId`/`campaignId` at top level, `briefing: ProductPromptCompositionBriefing`, `briefingText`, `campaignIntent`, `backgroundDirection`, `productImagesDataUrls`, `identityImageUrl?`, `identityDirective?`, `references?`, `referenceSelections?`, `copyContext?`, `usdBrlRateAtGeneration?`, `creditValueBrlAtGeneration?`, `runId?`, `traceId?`.

**Call-evidence pattern** (`types.ts:63-85`) — copy verbatim shape, swap literals:
```ts
export interface ExpansionCallEvidence {
  readonly callId: string;
  readonly operationId: string;
  readonly attemptNumber: number;
  readonly attemptReference: string;
  readonly provider: string;
  readonly model: string;
  readonly protocol: "images";
  readonly quality: "low";
  readonly requestedSize: "1152x2048";
  readonly returnedSize: string | null;
  readonly durationMs: number;
  readonly callStatus: "success" | "failed" | "timeout";
  readonly outcome: /* closed union */;
  readonly usage?: TokenUsage;
  readonly cost: CostResolution;
  readonly errorType?: string;
}
```
60.4: `quality: string` (comes from frozen snapshot target, **not** a constant), `requestedSize: "1024x1024"`, drop `returnedSize`, outcome union = `generated | invalid_output | provider_failure | definitive_failure | unknown | persistence_failed | readback_failed`.

**Closed-result pattern** (`types.ts:105-225`): one discriminated member per failure. For 60.4 the union is already specified in `design.md` between `### Saída` and `### Architecture / Files`; copy the *style* (frozen object literals, `readonly`, no `Error` escaping).

**Key differences:**
- 60.4 needs `CopyOutcome` and `FrozenContentPayload` types that F60.3 has no equivalent for.
- Frozen payload type must be JSON-serializable (`string` payload fields, `readonly` arrays) because it is stored in the existing `TEXT` column `product_1_1_snapshot_frozen_evidence.briefing`.
- `content_divergence` and `frozen_state_conflict` are **pre-call** members: `{ copy: null; call: null }` (`design.md:289-290`). They must be in the union before `blocked`.
- Only `import type` from `@/lib/product-1-1/**` here (those modules start with `import "server-only"`); a value import would break the pure contract and `server-only` tests.

### 4. `frozen-state.ts` — analogs `preflight.ts:133-176` + `persist-snapshot.ts`

**Existing classifier to mirror** (`preflight.ts:64-68,133-176`):
```ts
const SNAPSHOT_TABLE = "image_generation_config_snapshots";
const EVIDENCE_TABLE = "product_1_1_snapshot_frozen_evidence";
const BINDING_TABLE = "product_1_1_snapshot_content_binding";

// .from(SNAPSHOT_TABLE).select("id").eq("campaign_id", campaignId).maybeSingle()
// .from(EVIDENCE_TABLE).select("id").eq("snapshot_original_id", snapshot.id).maybeSingle()
// .from(BINDING_TABLE).select("snapshot_original_id").eq("snapshot_original_id", snapshot.id).maybeSingle()
```
It returns `no_snapshot | complete | repairable | corrupt` and is **private** (`defaultResolveFrozenEvidenceState`). 60.4 must build its own reader here; **do not export it from preflight.ts and do not modify preflight.ts.**

**Evidence row contract** (`persist-snapshot.ts:51-52,131-143`):
```ts
const EVIDENCE_COLUMNS =
  "id, snapshot_original_id, campaign_id, operation_id, campaign_intent, background_direction, briefing, reference_selections, base_version, composer_version, policy_versions";
```
Binding row (from migration `20261009000003`): `snapshot_original_id UUID PRIMARY KEY`, `campaign_id`, `operation_id`, `content_fingerprint TEXT`.

**Snapshot row columns** (migration `20261005000002` + `persist-snapshot.ts:407-419`): `id, campaign_id UNIQUE, primary_model, primary_quality, fallback_model, fallback_quality, config_version_id, origin, run_id, trace_id`.

**Canonicalization primitives to reuse (do not reimplement):**
- `canonicalJson(value): string` — `composition-artifacts/evidence.ts:69`
- `computeContentFingerprint(content)` — `persist-snapshot.ts:215-237`; it hashes `campaignIntent`, `backgroundDirection`, `briefing`, `referenceSelections`, `baseVersion`, `composerVersion`, `policyVersions` via `stableJson` + SHA-256, and **`briefing` is hashed as the raw string**.
- `evidenceMatches(row, evidence)` — `persist-snapshot.ts:239-254` (private); replicate the field-by-field comparison for granular `content_divergence` reasons.

**Classification contract to implement** (design D2):
| State | Condition | Result |
|---|---|---|
| `absent` | no snapshot row for `campaign_id` | first composition |
| `complete` | snapshot + binding.`operation_id === input.operationId` + evidence exists | resume |
| `repairable` | snapshot + binding of same operation, evidence missing | repair only under equivalence |
| `bound_to_other_operation` | snapshot/binding/evidence belongs to another `operation_id` | `frozen_state_conflict` |
| `unproven` | snapshot without binding | `frozen_state_conflict` |
| `corrupt` | incoherent evidence (campaign/operation mismatch) | `frozen_state_conflict` |
| `indeterminate` | any read error | `blocked` |

**Key differences / hard requirements:**
- F60.3's classifier never compares `operation_id`; 60.4 **must** read the binding's `operation_id` and compare to the input. This is the `bound_to_other_operation` proof.
- Real uniqueness constraints (verified): snapshot `campaign_id UUID NOT NULL UNIQUE`; binding `snapshot_original_id` PK **and** `UNIQUE (campaign_id, operation_id)`; evidence `snapshot_original_id UUID NOT NULL UNIQUE` **and** `UNIQUE (campaign_id, operation_id)`. Therefore: one snapshot per campaign, one binding/evidence per snapshot, one operation per snapshot. Never write a second binding/evidence.
- Parse must be fail-closed: `briefing` is a TEXT column; `JSON.parse` + shape check; unknown/extra keys inside the frozen payload => `blocked` (`frozen_content_invalid`).
- Comparison must fill omitted fields from the frozen payload before comparing (`copyContext` omitted on resume is legal — spec scenario "Retomada sem reenviar contexto de copy").
- Image equivalence = content hash of the received data URL vs `referenceSelections[].id`, plus `kind`/`role`/`index` order.


- The frozen payload is serialized with `canonicalJson` **before** `buildProductOneToOneFrozenEvidence`, otherwise `computeContentFingerprint` will hash a different string on every resume (see Risks #3).

## Shared Patterns

### Server-only boundary
Every I/O module starts with `import "server-only";` as the first statement (`probe.ts:1`, `expand.ts:1`, `prepare.ts:1`, `retrieve.ts:1`). Pure modules (`types`, `policy`, `validation`, `failure`) must **not** have it (`types.ts:1-14` explains why). Tests mock it globally:
```ts

```

### Authorization
`verifyCampaignAccess({ storeId, campaignId, authorization }, client): Promise<{ok:true;authorization}|{ok:false;reason}>` from `composition-artifacts/access.ts:65-103`; reasons are exactly `identity_conflict | store_mismatch | not_owner`, which map 1:1 to `authorization_denied.reason`. Call it **before any read/write** (as `expand.ts:268-278`).

### F60.1 authority
- Read: `getArtifactByIdentity` (row), `retrieveCompositionArtifact` (bytes vs row), `CompositionArtifactStorage.readObjectInfo/downloadBytes`, `buildObjectEvidence`/`verifyObjectEvidence`, `computeChecksumSha256`.
- Write: **only** `persistCompositionArtifact`. Never `uploadImmutable`, never `update`/`remove`, never `createSignedUrl`/`getPublicUrl`.
- Identity path: `compositionArtifactStoragePath({storeId,campaignId,operationId,role})`.

### Error handling
No exception escapes the public API: every analog catches and returns a typed member (`expand.ts:600-607`, `probe.ts` never throws, `reuse-evidence.ts` never throws). `AiGateway.emit` is best-effort and never changes the result (`gateway.ts:197-204`).

### Telemetry / cost
Single sink path only: `createDefaultTelemetryContext` + `DefaultAiTelemetrySink`; no direct `generation_events` writes, no `new AiCostTracker().record(...)` (`architecture-guard.test.ts:86-87` forbids it outside `src/lib/ai/**`).

### Deadlines
Use the pure helpers only: `deadlineAt`, `remainingBudget`, `remainingBeforeDeadline`, `canStartDurableWrite`, `createDeadlineRejection` (`deadline.ts:52-155`). `AbortError`/deadline rejection ⇒ `unknown_result`, never definitive.

## Risks / Landmines for the Planner

1. **`content_divergence` / `frozen_state_conflict` must be pre-call members with `copy: null, call: null`.** They are decided *before* the gate and before copy starts. If the orchestrator starts copy first, a divergent resume could burn a copy request. Order is fixed: input → access → frozen state → **content comparison** → gate → snapshot/config → copy → image.
2. **`computeContentFingerprint` hashes `briefing` as a raw string.** The frozen payload must be serialized with `canonicalJson` (from `composition-artifacts/evidence.ts`) **before** building `ProductOneToOneFrozenEvidence`, or every resume yields a different fingerprint ⇒ permanent `content_divergence`. Also keep `campaignIntent`/`backgroundDirection` both inside the payload string and as explicit evidence fields (they are hashed twice; that is fine and expected).
3. **There is no exported read-only frozen-state reader.** `preflight.ts:133-176` is private and does not compare `operation_id`. `frozen-state.ts` must implement its own queries and must not modify `preflight.ts`/`persist-snapshot.ts`.
4. **One snapshot per campaign is a hard DB constraint.** A *different* `operationId` for the same campaign can never compose a second base. That is `bound_to_other_operation`, zero calls, no second binding — and the caller must open a new campaign. Do not "repair" by rebinding.
5. **`retrieveCompositionArtifact` collapses "row absent" and "object absent" into `absent`.** Always query the row first via `getArtifactByIdentity`, exactly as `probe.ts:139-189`. A row present + object gone is `row_object_missing` ⇒ **zero calls, never rewrite**.
6. **`persistCompositionArtifact` requires `source: { kind: "none" }` when `origin: "provider_generation"`** (`persist.ts:139-148`). Passing any source ⇒ `invalid_input`. Provenance must be `{}` (unknown keys silently dropped by the allowlist).
7. **`persistProductOneToOneSnapshot` can throw, not return.** All outcomes are exceptions (`ProductOneToOneSnapshotPersistError`) — wrap in try/catch and map codes to `snapshot_failed.reason`. It is also the *repair* path; do not write evidence manually.
8. **`resizeToJpeg1024` letterboxes non-square input** (`fit: "contain"`, white background). The provider must return a 1024×1024 square; if it returns another aspect, the result is a valid JPEG 1024 with white bars — still passes F60.1 but is an art defect. Validate provider bytes before resize (dimensions/aspect) and return `invalid_output` instead of silently persisting bars — mirror `output.ts:96-174`'s metadata-first validation, but with a **1024×1024** contract.
9. **`UpstreamImagesAdapter` throws if `request.quality` is blank** (`upstream-images.ts:145-156`) and dedupes repeated primary data URLs (`:171-175`). Pass the frozen target quality and keep identity distinct from references. Body is `{model, image, prompt, size: "1024x1024", quality, n: 1}`.

**Cache + in-flight dedupe by epoch + explicit invalidation** (analog L51-113) — copy verbatim, changing only the table/scope:

```typescript
export class ImageModelPairConfigService {
  private cache: { expiresAt: number; row: ImageModelPairConfigRow | null } | null = null;
  private inFlight: { epoch: number; promise: Promise<ImageModelPairConfigRow | null> } | null = null;
  private invalidationEpoch = 0;

  constructor(
    private readonly client: SupabaseClient = supabaseAdmin,
    private readonly ttlMs = 30_000,
    private readonly now: () => number = () => Date.now(),
  ) {}

  async getImageModelPairConfig(): Promise<ImageModelPairConfigRow | null> {
    if (this.cache && this.cache.expiresAt > this.now()) return this.cache.row;
    const epoch = this.invalidationEpoch;
    if (this.inFlight?.epoch === epoch) return this.inFlight.promise;
    const promise = this.loadConfigRow();
    this.inFlight = { epoch, promise };
    try {
      const row = await promise;
      if (epoch === this.invalidationEpoch && this.inFlight?.promise === promise) {
        this.cache = { row, expiresAt: this.now() + this.ttlMs };
      }
      return row;
    } finally {
      if (this.inFlight?.promise === promise) this.inFlight = null;
    }
  }

  invalidateImageModelPairConfigCache(): void {
    this.invalidationEpoch += 1;
    this.cache = null;
    this.inFlight = null;
  }

  private async loadConfigRow(): Promise<ImageModelPairConfigRow | null> {
    const { data, error } = await this.client
      .from("image_model_pair_config")
      .select("*")
      .eq("scope", "new_flow")
      .maybeSingle();
    if (error) throw new ImageModelPairConfigReadError(error.message);
    return (data as ImageModelPairConfigRow | null) ?? null;
  }
}

export const imageModelPairConfigService = new ImageModelPairConfigService();
```

**Required signature for F60.6** (tasks 1.2 / 6.1): a strict read that returns a discriminated result, not `row | null`:

```typescript
type NineSixteenExpansionConfigReadResult =
  | { kind: "found"; selection: ExpansionSelection }
  | { kind: "absent" }
  | { kind: "read_failed"; reason: string };
```

plus a strict resolver that additionally validates the closed lists (row present but invalid ⇒ `absent`-equivalent fail-closed **distinct** from `read_failed`).

**Constraints / landmines**
- `.maybeSingle()` (analog L107): `data === null && error === null` is **absent**; `error` is **read_failed**. Never `?? null` an `error`.
- TTL is short (30 s precedent) + explicit invalidation on PUT (design risk row "Cache administrativo defasado").
- The cache is only for the **genuinely new generation** path. Continuation/retry/replay MUST NOT call this service (spec `product-9-16-two-stage-orchestration` last paragraph).
- Do not add a `DELETE`/reset path: absence is failure (design D1).

RETURNS JSONB
LANGUAGE plpgsql
SECURITY DEFINER
SET search_path = ''

**F60.6 deltas required by spec (do not invent beyond them):**
1. Revalidate the actor **inside** the RPC against `admin_users` before any write/audit (F56.1 does **not** do this; tasks 2.2). Rejected ⇒ `missing_actor_id` / `actor_not_admin`, zero config write, zero audit.
2. Idempotency is **strict on content**, not only on `operation_id`: same `operation_id` + same `{model, quality, reason}` ⇒ replay; different content ⇒ `operation_id_conflict` with **no** write, **no** new version, **no** extra audit. The F56.1 code returns replay on `operation_id` alone (L110-115) — that is insufficient here and is the single biggest migration landmine.
3. Explicit idempotent provisioning, never overwriting a human choice (task 2.4):

INSERT INTO public.nine_sixteen_expansion_model_config (

## Cross-Cutting Landmines (apply to every plan)

1. **Do not apply the migration.** Author + static test only. No `supabase db push`, `migration up`, reset, Docker, or data write. Rollback is documented/commented, operational, non-destructive.
2. **Absent ≠ read-failed.** Every layer (service, view, preflight, RPC envelope) must keep them distinct. A `catch → null` or `catch → default` anywhere is a defect against spec req 3 and D5.
3. **New generation fail-closed, zero spend.** Any configuration/model/pricing failure ⇒ no `reserveOperationOnce`, no `acquire`, no provider, no attempt, no refund. Assert with call-count tests (analog: `run-nine-sixteen.contract.test.ts` L262-365).
4. **Indeterminate ⇒ recoverable, never terminal.** Continuation: `processing`/`canContinue: true`, no `recordOutcome`, no refund, no `acquire`. Proven-invalid: definitive per stage (refund only where base is pending).
5. **Freeze is write-once.** Selection only in the v2 `INSERT`; `service_role` has no UPDATE on operations; trigger rejects changes. Reopening/retry returns the frozen value and must not overwrite it.
6. **One selection, one transaction.** Concurrent opens of `(campaign_id, operation_id)` converge to one reserve + one operation + one selection; a divergent selection is rejected (`operation_config_conflict`) and never overwrites the winner.
7. **Legacy v1 is explicit, not absent.** `contract_version = 1` ⇒ `legacy_sunburst_low` (`gpt-image-2.5-sunburst`/`low`), origin recorded in telemetry/evidence. No backfill, no UPDATE of history, no synthesis of a fake `configVersionId`.
8. **One `images.edit` per attempt.** `maxRetries: 0`, no fallback, no loop, timeout ≤ 180 s, size `1152x2048`, output validation 9:16 and JPEG 1080×1920 unchanged.
9. **Do not touch the 1:1 / base / legacy state.** `image_model_pair_config`, `ai_model_selection`, `image_generation_config_snapshots`, `campaigns`, credit, Storage, prompt, preparation, export, delivery are read-only references here.
10. **Replay / query / deliver never read config.** No preflight, no admin read, no pricing read — even after an admin change (task 6.4).
11. **Pricing coverage is usage-based.** `image_unit_usd` absent ⇒ estimate `null`, coverage still `complete`; missing usage rates block before spend; unknown post-call cost is `null`/`not_available`, never `0`.
12. **No new public error code.** Internal taxonomy only (`configuration_missing`, `configuration_read_failed`, `model_unavailable`, `pricing_unavailable`); see `docs/convencoes/codigos-de-erro-suporte.md`.
13. **Gates:** `npm run typecheck`, `npm run lint`, `npm run build`, `git diff --check`, `openspec validate --strict`. Tests offline only (DB/Storage/provider faked). No homolog, paid proof, balance, visual approval, activation, merge, push, deploy.

## Decisions Made

- Chaves de lista (`campaignFormats`, `formats`) invalidam o snapshot com `unsupported_format` antes de qualquer delegação; `campaignFormat` continua sendo a única chave de formato.
- Para `9:16`, `deliveryOperationId` deve ser igual a `operationId` (identidade de controle e financeira do vertical); para `1:1`, deve ser distinta (identidade financeira própria do quadrado).
- Linha de artefato é obrigatória para `delivered`; ausência/leitura falha/incompatibilidade vira `unknown` com referência de suporte `two_format:<campaignId>:<format>`, sem detalhe técnico.
- `campaignFormat` ausente/inválido na declaração estrita mapeia para `unsupported_format`; versões para `unsupported_version`; origem para `unsupported_origin`; chave não reconhecida para `unexpected_field`.
- `resolveTwoFormatAccess` aceita um segundo argumento opcional de dependências para permitir testar o ramo `thumbnailPlaceholder: true` (ver Desvios).

## 2. Contratos

### `preflightJointSelection(deps)` — `src/lib/product-two-format/orchestration/preflight.ts`

```ts
type JointPreflightResult =
  | { ok: true; selection: TwoFormatSelectionInput } // model, quality, configVersionId: string
  | { ok: false; kind: "absent" | "invalid" | "indeterminate";
      reason: string; missing: readonly string[] };

interface JointPreflightDeps {
  readConfiguration(): Promise<NineSixteenExpansionConfigReadResult>;
  preflightSelection(selection: ExpansionSelection): Promise<ExpansionPreflightResult>;
}
```

- **Nunca lança.** Exceção de qualquer costura ⇒ `indeterminate`.
- `read_failed` ⇒ `indeterminate`; **nunca** `absent`.
- `absent` ⇒ `absent`; `invalid` ⇒ `invalid`.
- `found` exige `origin === "configured"` e `configVersionId` não nulo; legado/`null` ⇒ `invalid` (`expansion_selection_not_configured`).
- Preflight `ok:false`:
  - `configuration_read_failed` (`catalog_read_failed`/`pricing_read_failed`) ⇒ `indeterminate`;
  - `model_unavailable`/`pricing_unavailable` ⇒ `invalid`.
- Fábrica default (`createDefaultJointPreflightDeps`) delega aos serviços F60.6 reais; é a única parte que toca código server-only.

### `openJointOperation(input, deps)` — `src/lib/product-two-format/orchestration/joint-operation-service.ts`

```ts
type JointOpenOutcome =
  | { kind: "opened"; idempotent; squareDeliveryId; verticalDeliveryOperationId;
      frozenSelection; steps; creditStatus; squareCreditStatus }
  | { kind: "business"; reason: TwoFormatOpenReason }
  | { kind: "contract_invalid"; reason: string }
  | { kind: "failed"; code: TwoFormatDeliveryErrorCode };
```

- Ordem: `classifyTwoFormatCampaign(inputSnapshot)` → só então `openJointDelivery`.
- `not_two_format`/`inconsistent` ⇒ `contract_invalid` com **zero** RPC.
- Identidades: `operationId` = controle/vertical; `squareDeliveryId` = financeira do quadrado. O serviço **não gera** UUID.
- `success:false` da abertura ⇒ `business` (allowlist do cliente: `joint_contract_required`, `operation_origin_conflict`, `operation_identity_conflict`, `operation_config_conflict`, `operation_in_progress`, `delivery_link_incomplete`, `joint_open_failed`).
- `TwoFormatDeliveryError` ⇒ `failed` com código preservado (`invalid_envelope`, `unknown`, `shared_operation_not_final`, `delivery_links_inconsistent`, `identity_mismatch`, `delivery_identity_conflict`, ...). Nunca converte exceção em negócio.
- Pré-validação local (UUID, `squareDeliveryId !== operationId`, seleção fechada) antes da RPC; o cliente continua sendo a última barreira.

## 2. Contratos

### Sonda `square_original` — `square-probe.ts`

```ts
type JointSquareProbeResult =
  | { kind:"integral"; storagePath; artifactId; width:1024; height:1024; mimeType:"image/jpeg" }
  | { kind:"absent" } | { kind:"invalid"; reason } | { kind:"indeterminate" };

interface JointSquareProbe {
  probeSquareOriginal(input:{ storeId; campaignId; operationId }): Promise<JointSquareProbeResult>;

```

- Linha antes do objeto; objeto sem linha ⇒ `invalid`; linha sem objeto ⇒ `absent`/`invalid`, nunca `integral`.

- `retrieveCompositionArtifact` sozinho não substitui a evidência; a sonda não é mais permissiva que o gate da base.

### Entrega do quadrado — `deliver-square.ts`

```ts
input: { storeId; campaignId; operationId /* controle */; deliveryOperationId /* quadrado */ }
outcome: delivered | publication_pending | artifact_absent | artifact_incompatible |
         indeterminate | terminal_conflict | failed
```

Ordem: `probeSquareOriginal` → `beginPublication(deliveryOperationId)` → `deliverFormat("1:1")` → miniatura best-effort.
- Arte incompatível/ausente ⇒ zero token/entrega/estorno.
- `operation_terminal` (crédito já delivered/refunded) ⇒ `terminal_conflict`; replay pós-entrega usa `projectCampaign` (plano 07), não readquire token.
- Falha definitiva após token ⇒ abort **somente** na allowlist comprovadamente sem confirmação (`missing_publication_token`, `artifact_incompatible`, `delivery_link_missing`, `credit_operation_missing`, `invalid_transition`), best-effort. `invalid_envelope`, `unknown`, `publication_not_owner`, `publication_in_progress`, `operation_in_progress`, `delivery_links_inconsistent`, transporte ou resposta ambígua ⇒ **não abortar**; fence preservado para reconciliação. `before_upload` é transição financeira e não apaga o artefato.
- Sem projeção no app, sem upload/cópia/segunda arte.

## 2. Contratos

### Sonda `square_original` — `square-probe.ts`

```ts
type JointSquareProbeResult =
  | { kind:"integral"; storagePath; artifactId; width:1024; height:1024; mimeType:"image/jpeg" }
  | { kind:"absent" } | { kind:"invalid"; reason } | { kind:"indeterminate" };

interface JointSquareProbe {
  probeSquareOriginal(input:{ storeId; campaignId; operationId }): Promise<JointSquareProbeResult>;
```

- Linha antes do objeto; objeto sem linha ⇒ `invalid`; linha sem objeto ⇒ `absent`/`invalid`, nunca `integral`.
- Integridade conferida por `retrieveCompositionArtifact` (path/bucket/dimensão/MIME/checksum) + `ROLE_POLICY.square_original` + `SQUARE_BASE_ORIGIN`.
- `invalid`/`indeterminate` nunca autorizam entrega.

```ts

outcome: delivered | publication_pending | artifact_absent | artifact_incompatible |
```

Seção 4 — helper `public.trial_offer_calendar_reaches_total(p_release_frequency text, p_credits_per_release integer, p_max_total_credits integer, p_duration_days integer) RETURNS boolean`, `LANGUAGE sql IMMUTABLE SECURITY INVOKER SET search_path = ''` (SECURITY INVOKER explícito; NÃO usar SECURITY DEFINER): argumento nulo/fora do domínio, duração <=0 ou total <=0 → false; `once` → true; recorrente com créditos nulos/<=0 → false; `v_releases = ceil(total::numeric / credits)`; intervalo conservador 1/7/31 para daily/weekly/monthly; retornar `((v_releases - 1) * v_interval) < p_duration_days`. Comentar que 31 dias/mês é limite superior para qualquer início e que 30 dias fixos é proibido. O trigger de versão chama o helper como service_role; por isso o EXECUTE é concedido a service_role mesmo com SECURITY INVOKER.

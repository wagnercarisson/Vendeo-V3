# Quick Task 260730-o30: Hotfix admin_get_metrics UUID vs TEXT + dead code grant_monthly_credits

## Contexto

A função `public.admin_get_metrics` falha no Supabase com erro `42883: operator does not exist: uuid = text`. A function compara `credit_transactions.id` (UUID) com `credit_transactions.reference` (TEXT) em 7 locais dentro da lógica de classificação de refunds.

A função `public.grant_monthly_credits` (versão em `20260731000001_admin_test_store_filter.sql`) declara `v_new_balance INTEGER` e faz SELECT ao final do loop referenciando `v_store.id` — dead code que quebra se nenhuma loja for elegível (v_store não inicializado).

## Tarefas

### Tarefa 1: Migration hotfix

**Arquivo:** `supabase/migrations/20260731000003_fix_admin_get_metrics_uuid_text.sql`

**O que faz:**

1. `CREATE OR REPLACE FUNCTION public.admin_get_metrics(...)` — sem DROP (assinatura inalterada):
   - CTE `window_deductions`: adiciona `d.campaign_id` na projeção (era `d.id, d.metadata`, agora `d.id, d.metadata, d.campaign_id`) — sem isso, `wd2.campaign_id` falha
   - 7 casts `::text` nas comparações UUID vs TEXT:
     - `wd.id::text = wr.reference`
     - `ct.id::text IN (SELECT or2.reference FROM orphan_refunds or2)`
     - `wd.id::text = wr.reference` (3 ocorrências em subqueries EXISTS)
     - `wd2.id::text = wr.reference`
     - `cwd.id::text = wr.reference` (2 ocorrências)

2. `CREATE OR REPLACE FUNCTION public.grant_monthly_credits(...)` — sem DROP (assinatura inalterada):
   - Remove declaração `v_new_balance INTEGER`
   - Remove bloco `SELECT COALESCE(bonus_balance, 0) INTO v_new_balance ...`

**Não altera:** assinatura, lógica de negócio, tipos de coluna.

## Contratos propostos (v1)

Nada é persistido nesta fatia. Todos os valores são `readonly`, serializáveis, sem I/O, e
materializados como **objetos novos e congelados** (sem referência compartilhada com entradas).

### `MarketProfile` (dado de referência, não autorização)

| Campo | BR | PY |
|---|---|---|
| `market` | `"BR"` | `"PY"` |
| `profileVersion` | `1` | `1` |
| `defaultContentLocale` | `"pt-BR"` | `"es-PY"` |
| `defaultCurrency` | `"BRL"` | `"PYG"` |
| `defaultTimeZone` | `"America/Sao_Paulo"` | `"America/Asuncion"` |

Registry `MARKET_PROFILES` congelado recursivamente, indexado por mercado. Adicionar mercado =
adicionar perfil + casos de teste.

### `StoreMarketConfigInput` (entrada de configuração — parcial permitida)

```ts
type StoreMarketConfigInput =
  | { kind: "legacy" }                       // ausência TOTAL, declarada pelo chamador
  | { kind: "configured";                    // `country` obrigatório; preferências opcionais
      country: unknown;
      defaultCampaignMarket?: unknown;
      defaultContentLocale?: unknown;
      defaultCurrency?: unknown;
      timeZone?: unknown };
```

Resolução (`resolveStoreMarketContext`):

| Campo | Regra |
|---|---|
| `country` | obrigatório e suportado; ausente ⇒ `missing_country` |
| `defaultCampaignMarket` | explícito → `country` |
| `defaultContentLocale` | explícito → `profile(defaultCampaignMarket).defaultContentLocale` |
| `defaultCurrency` | explícito → `profile(defaultCampaignMarket).defaultCurrency` |
| `timeZone` | explícito → `profile(country).defaultTimeZone` |

Consequência exigida: loja BR com `defaultCampaignMarket: "PY"` recebe `es-PY` e `PYG`, mantendo
`country: "BR"` e fuso `America/Sao_Paulo`.

`{ kind: "legacy" }` ⇒ `country: "BR"`, mercado `BR`, `pt-BR`, `BRL`, `America/Sao_Paulo` com
proveniência `legacy_br`. `legacy` nunca é inferido: é declaração explícita do chamador.

### `StoreMarketContext` (valor resolvido — completo e estrito)

`contextVersion: 1`, `country`, `defaultCampaignMarket`, `defaultContentLocale`,
`defaultCurrency`, `timeZone` — **todos obrigatórios**.

`parseStoreMarketContext(value)` (leitura de valor já resolvido/persistido) **não aplica
padrões**: objeto ausente, vazio, incompleto, com campo desconhecido ou versão ≠ 1 ⇒ erro
tipado. Não existe "meio contexto" válido.

### `UserLocalePreference` (idioma do aplicativo)

`resolveUiLocale({ kind: "explicit", uiLocale } | { kind: "legacy" })` → `uiLocale` + proveniência
`explicit` / `legacy_br`. Regra dura: **nunca** recebe `StoreMarketContext`, `market` ou país;
mercado não escolhe idioma de app.

### `CampaignMarketConfig` + `CampaignMarketContext`

Valor resolvido: `contextVersion: 1`, `market`, `contentLocale`, `currency` — todos obrigatórios.

`resolveCampaignMarketContext({ store, overrides? })`:

| Campo | Precedência |
|---|---|
| `market` | `overrides.market` → `store.defaultCampaignMarket` |
| `contentLocale` | `overrides.contentLocale` → (`market === store.defaultCampaignMarket` ? `store.defaultContentLocale` : `profile(market).defaultContentLocale`) |
| `currency` | `overrides.currency` → (`market === store.defaultCampaignMarket` ? `store.defaultCurrency` : `profile(market).defaultCurrency`) |

Ao trocar o destino, os padrões do destino são sugeridos; override explícito sempre vence.
Resultado: `{ context, sources }` com `"campaign_override" | "store_default" |
"market_profile_default" | "legacy_br"` por campo.

`readCampaignMarketContext(value)`:

| Entrada | Resultado |
|---|---|
| `null` / `undefined` | `{ kind: "missing_legacy" }` — ausência real em campanha antiga |
| `{}`, contexto incompleto, versão ≠ 1, campo desconhecido, não-objeto | `{ kind: "invalid", error }` com `reason: "not_an_object" \| "incomplete" \| "unsupported_version" \| "invalid_field"` |
| objeto completo e válido | `{ kind: "present", context }` — cópia nova e congelada |

Nunca consulta loja/usuário, nunca preenche defaults, nunca converte. `parseCampaignMarketContext`
é o parser estrito reutilizado; não faz backfill.

### Erros tipados

`unsupported_market`, `unsupported_locale`, `unsupported_currency`, `unsupported_time_zone`,
`unsupported_context_version`, `missing_country`, `invalid_input`, `invalid_profile_registry` —
com `field` e, quando aplicável, valor recebido. Entrada de usuário nunca lança; o registry pode
falhar alto apenas em inconsistência estática coberta por teste.

<layout_spec>
## Especificação de layout

### Sidebar desktop (≥ 768 px)
| Item | Especificação |
|---|---|
| Largura | `w-56` = 224 px; área interna 192 px (`px-4`) |
| Estrutura | `<aside>` passa a `flex flex-col`; mantém `sticky top-0 h-dvh overflow-y-auto bg-bg-surface` |
| Header | `h-14`, `px-4`, `border-b`; logo alinhado à esquerda; `shrink-0` |
| Logo | `h-8` (32 px), ~150 px de largura, `max-w-[168px]`; link para `/dashboard` |
| Navegação | Inalterada e **sem encolhimento** (`shrink-0` no wrapper); 5 links, `gap-1`, `p-4` |
| Assinatura | largura `SIGNATURE_WIDTH_PX` (118 px), altura `× 923/1256` (≈86,7 px), centralizada, **opacidade original**, `pt-[16px]`, `pb-[20px]` |
| Rodapé | `mt-auto`, `shrink-0`, sem `absolute`/`sticky`; nunca sobrepõe a navegação |
| Visibilidade | `hidden` por padrão; `flex` somente quando `shouldShowSignature` retorna `true` |

**Regra de visibilidade (autoritativa, medida):**
```
piso: asideHeight >= 560
available = asideHeight - headerHeight - navHeight
bloco = 16 + SIGNATURE_HEIGHT_PX + 20
mostrar = available >= bloco + 16
```
- `asideHeight` = `aside.clientHeight`;
- `headerHeight` e `navHeight` = `offsetHeight` medidos em runtime (não constantes);
- `bloco` e paddings em **px** para não escalarem com o tamanho de fonte raiz;
- `ResizeObserver` observa `aside`, `header` e `nav` e é **obrigatório para exibir** a assinatura;
- se `ResizeObserver` não existir, a assinatura permanece **oculta**; o listener de `resize`
  apenas complementa a medição quando o observer está disponível (não o substitui);
- `nav` e `header` recebem `shrink-0`; a assinatura nunca encolhe a navegação.

**Por que não apenas `min-height: 560px`:** o piso de 560 px é uma proteção inicial, mas não
detecta texto ampliado, quebra de linha ou novos itens. A guarda medida usa a altura real da
navegação e do header; com texto ampliado, `navHeight` cresce e a assinatura é ocultada se não
couber.

**Estrutura conceitual:**
```tsx
<aside ref={asideRef} className="sticky top-0 hidden h-dvh w-56 flex-shrink-0 flex-col overflow-y-auto border-r border-border bg-bg-surface md:flex">
  <div ref={headerRef} className="flex h-14 shrink-0 items-center border-b border-border px-4">
    <VendeoBrandLink variant="logo" />
  </div>
  <div ref={navRef} className="shrink-0">
    <Sidebar latestEntryId={latestEntryId} />
  </div>
  <VendeoSignature asideRef={asideRef} headerRef={headerRef} navRef={navRef} />
</aside>
```

**Objetivo:** substituir **somente** a entrega externa do Google Fonts por arquivos WOFF2 versionados em `public/fonts/`, com `@font-face` local, preservando exatamente a tipografia e o comportamento atuais.

**Escopo autorizado:** remover os 2 `preconnect` e o `<link rel="stylesheet">` de `src/app/layout.tsx`, adicionar `@font-face` local, versionar os assets + licenças + procedência, criar teste focado. **Nada além disso.**

**Fora de escopo (proibido nesta quick):** `next/font`; qualquer dependência nova; download em build/runtime/postinstall; subsetting artesanal, compactação extra ou troca para fonte variável alternativa; `preload` sem medição; alteração de `tailwind.config.ts`, `globals.css` (regras existentes), componentes, tema, tamanhos, espaçamentos; migração para outra família; merge, push, deploy, tag ou alteração de banco.

**Baseline:** `HEAD = b898f5817de88354698ff8b03f358136570fb922`, branch `perf/fontes-locais`, `git status` limpo.

**Requisitos desta quick (contrato de preservação):**

## Contrato tipográfico preservado

| Família | Pesos | Estilo | Subsets | Arquivos |
|---------|-------|--------|---------|----------|
| Poppins v24 (estática, um arquivo por peso) | 400, 500, 600, 700 | normal | latin, latin-ext | 8 |
| Open Sans v44 (**variável** — mesmo arquivo por subset para todos os pesos) | 300, 400, 500, 600, 700 | normal | latin, latin-ext | 2 |

- **18 declarações `@font-face`**, `font-display: swap`, `src: url(...) format('woff2')`, `font-weight` **exato** (valor único, nunca `300 800`), `font-style: normal`.
- Open Sans: as 5 declarações apontam para o **mesmo** WOFF2 oficial por subset. Isso **é** o que o Google serve hoje (o CSS oficial traz `font-weight: 300`…`700` em blocos separados com a mesma URL para 300/400/500/600/700). Declarar peso exato evita expor o eixo 800 e preserva o download único por URL.
- Open Sans mantém `font-stretch: 100%` (existe no CSS oficial); Poppins **não** tem `font-stretch` (não existe no CSS oficial) — espelhar cada bloco fielmente.
- `unicode-range` copiado **verbatim** do CSS oficial por subset (latin e latin-ext), garantindo cobertura de `ç/ñ/¿/¡` e de símbolos monetários como `₲` (U+20B2, dentro de `U+20AD-20C4` do latin-ext).

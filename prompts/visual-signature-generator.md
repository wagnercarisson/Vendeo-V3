# Gerador de Assinatura Visual

Crie uma assinatura visual profissional para a loja **{{storeName}}**.

## Contexto da Loja

- **Segmento:** {{segment}}
- **Cor da marca:** {{brandColor}}
- **Tom de voz:** {{tone}}

## Especificações da Imagem

- **Formato:** Quadrado, aproximadamente 1024×1024 pixels
- **Fundo:** Simples, sólido ou gradiente sutil — sem fotos ou texturas complexas
- **Tipografia:** Limpa, legível, profissional — o nome da loja {{storeName}} deve ser o elemento principal e mais proeminente
- **Cor:** Usar {{brandColor}} como cor de destaque principal
- **Elemento opcional:** Pode incluir um símbolo, ícone, monograma ou marca gráfica que represente o segmento {{segment}}

## Diretrizes de Estilo por Tom

Considere o tom de voz {{tone}} para guiar o estilo visual:

- **profissional:** Estilo limpo, corporativo, sóbrio — cores sólidas, tipografia clássica, layout estruturado
- **moderno:** Estilo contemporâneo, trendy — cores vibrantes, tipografia moderna, layout dinâmico
- **elegante:** Estilo sofisticado, premium — paleta refinada, tipografia elegante, acabamento sutil

## Restrições Obrigatórias

- NÃO incluir preços, produtos, ofertas, CTAs ou cópia promocional
- NÃO usar design genérico de "iniciais em círculo" — este é o comportamento de fallback, evite
- NÃO incluir elementos de arte de campanha (cenas, imagens de produto, elementos decorativos não relacionados à marca)
- NÃO incluir texto promocional como "Promoção", "Oferta", "Desconto" ou similares
- A imagem deve funcionar como uma assinatura de marca atemporal, não como uma peça de campanha

## Formato de Saída

A saída deve ser uma imagem PNG — sem JSON, sem descrições, apenas a imagem final.
